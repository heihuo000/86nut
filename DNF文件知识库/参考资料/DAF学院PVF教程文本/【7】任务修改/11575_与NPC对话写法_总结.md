# 11575_与NPC对话写法 - 内容总结

## 主要内容
本文介绍了与NPC对话类任务的编写方法和参数配置。

## 任务结构模板
```
#PVF_File
[grade]
 `[任务类别]`

[npc index]
 接受NPC代码

[complete npc index]
 -1

[job]
 `[all]`

[grow type]
 -1

[level]
 1 99

[type]
 `[meet npc]`

[sub type]
 -1

[int data]
 要找的NPC代码
[/int data]

[reward type]
 `[item]`

[reward int data]
 奖励道具 数量
[/reward int data]

[name]
 `任务名稱`

[depend message]
 `接受對話`

[condition message]
 `任務提示`

[solve message]
 `完成對話`
```

## 核心参数说明

### 基础配置
- [grade]: 任务类别（日常、重复、普通等）
- [npc index]: 接受任务的NPC代码
- [complete npc index]: 完成任务NPC代码（-1表示任意NPC）
- [job]: 适用职业（[all]表示所有职业）
- [grow type]: 成长类型（默认-1）
- [level]: 任务等级范围（1-99表示所有等级）

### 任务类型配置
- [type]: 任务类型（[meet npc]表示与NPC对话）
- [sub type]: 附加类型（默认-1）

### 任务需求配置
- [int data]: 任务需求
  - 要找的NPC代码：指定需要对话的目标NPC

### 奖励配置
- [reward type]: 奖励类型（[item]表示物品奖励）
- [reward int data]: 奖励具体内容
  - 奖励道具 数量

### 文本信息
- [name]: 任务名称
- [depend message]: 接受任务时的对话
- [condition message]: 任务进行中的提示
- [solve message]: 完成任务时的对话

## 应用场景
- 创建寻找特定NPC的任务
- 设计引导类任务（如新手引导）
- 制作剧情推进任务
- 设置NPC互动成就

## 重要说明
- 任务类型为[meet npc]表示与NPC对话
- [int data]中填写目标NPC的代码
- 可用于制作简单的寻人任务
- 适合用于剧情衔接和任务引导
