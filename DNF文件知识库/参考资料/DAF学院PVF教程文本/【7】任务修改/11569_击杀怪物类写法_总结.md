# 11569_击杀怪物类写法 - 内容总结

## 主要内容
本文介绍了击杀怪物类任务的编写方法和参数配置。

## 任务结构模板
```
#PVF_File
[grade]
 `[任务类型]`

[npc index]
 接受NPC代码

[complete npc index]
 -1

[job]
 `[all]`

[grow type]
 -1

[level]
 1 99

[type]
 `[hunt monster]`

[sub type]
 -1

[int data]
 副本代码 难度 击杀怪物代码 击杀数量
[/int data]

[dungeon info]
 副本代码 难度
[/dungeon info]

[reward type]
 `[item]`

[reward int data]
 奖励代码 数量
[/reward int data]

[name]
 `任務名稱`

[depend message]
 `接受對話`

[condition message]
 `任務提示`

[solve message]
 `完成對話`
```

## 核心参数说明

### 基础配置
- [grade]: 任务类型（日常、重复等）
- [npc index]: 接受任务的NPC代码
- [complete npc index]: 完成任务NPC代码（-1表示任意NPC）
- [job]: 适用职业（[all]表示所有职业）
- [grow type]: 成长类型（默认-1）
- [level]: 任务等级范围（1-99表示所有等级）

### 任务类型配置
- [type]: 任务类型（[hunt monster]表示击杀怪物）
- [sub type]: 附加类型（默认-1）
- [int data]: 任务具体数据
  - 副本代码
  - 难度
  - 击杀怪物代码
  - 击杀数量

### 副本信息
- [dungeon info]: 副本信息（副本代码 难度）

### 奖励配置
- [reward type]: 奖励类型（[item]表示物品奖励）
- [reward int data]: 奖励具体内容（奖励代码 数量）

### 文本信息
- [name]: 任务名称
- [depend message]: 接受任务时的对话
- [condition message]: 任务进行中的提示
- [solve message]: 完成任务时的对话

## 应用场景
- 创建击杀指定怪物的任务
- 设置副本内杀怪任务
- 设计日常杀怪任务
- 制作团队副本杀怪成就
