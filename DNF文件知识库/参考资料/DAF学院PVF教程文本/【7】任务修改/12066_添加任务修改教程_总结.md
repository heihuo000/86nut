## 任务文件结构
### 文件路径格式
```
代码 `common/requiem/文件名.qst`
```

### 命名规则
- 自行编写代码和文件名
- 需要确保代码唯一性

## 任务类型代码

### 每日任务
```
[grade]
 `[daily]`
```

### 重复任务
```
[grade]
 `[normaly repeat]`
```

### 普通任务
```
[grade]
 `[common unique]`
```

### 成就任务
```
[grade]
 `[achievement]`
```

## 特殊奖励设置

### QP点奖励
- 用于奖励QP点数
- 代码需放在接任务等级代码下方
- 只能加到普通任务或重复任务上

### 配置代码
```
[quest point]
 8888
```

## 操作要点
1. 确定任务类型和文件命名
2. 编写对应的任务代码
3. 设置合适的任务参数
4. 添加奖励配置（如需要）
5. 测试任务功能是否正常

## 重要说明
- 任务文件采用.qst格式
- 不同任务类型有不同的特点和用途
- QP点奖励有使用限制
- 建议参考提供的资源进行深入学习
