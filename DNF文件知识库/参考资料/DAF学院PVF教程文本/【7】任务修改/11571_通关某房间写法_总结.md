# 11571_通关某房间写法 - 内容总结

## 主要内容
本文介绍了通关指定房间类任务的编写方法和参数配置。

## 任务结构模板
```
#PVF_File
[grade]
 `[任务类别]`

[npc index]
 接取NPC代码

[complete npc index]
 -1

[job]
 `[all]`

[grow type]
 -1

[level]
 1 99

[type]
 `[clear map]`

[sub type]
 -1

[int data]
 map房间代码
[/int data]

[reward type]
 `[item]`

[reward int data]
 奖励代码 数量
[/reward int data]

[name]
 `任務名稱`

[depend message]
 `接受對話`

[condition message]
 `任務提示`

[solve message]
 `完成對話`
```

## 核心参数说明

### 基础配置
- [grade]: 任务类别（日常、重复等）
- [npc index]: 接取任务的NPC代码
- [complete npc index]: 完成任务NPC代码（-1表示任意NPC）
- [job]: 适用职业（[all]表示所有职业）
- [grow type]: 成长类型（默认-1）
- [level]: 任务等级范围（1-99表示所有等级）

### 任务类型配置
- [type]: 任务类型（[clear map]表示通关地图）
- [sub type]: 附加类型（默认-1）

### 任务需求配置
- [int data]: 任务需求
  - map房间代码：指定需要通关的房间代码

### 奖励配置
- [reward type]: 奖励类型（[item]表示物品奖励）
- [reward int data]: 奖励具体内容
  - 奖励代码 数量

### 文本信息
- [name]: 任务名称
- [depend message]: 接受任务时的对话
- [condition message]: 任务进行中的提示
- [solve message]: 完成任务时的对话

## 应用场景
- 创建通关指定房间的任务
- 设计副本内特定房间挑战
- 制作探索类成就任务
- 设置隐藏房间通关任务

## 重要说明
- 需要准确获取目标房间的代码
- 任务类型为[clear map]表示通关地图
- 可结合其他任务类型创建复合任务
