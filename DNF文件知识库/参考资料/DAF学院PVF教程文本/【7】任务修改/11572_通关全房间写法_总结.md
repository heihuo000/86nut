# 11572_通关全房间写法 - 内容总结

## 主要内容
本文介绍了通关副本所有房间类任务的编写方法和参数配置。

## 任务结构模板
```
#PVF_File
[grade]
 `[任务类别]`

[npc index]
 接取NPC代码

[complete npc index]
 -1

[job]
 `[all]`

[grow type]
 -1

[level]
 10 99

[type]
 `[condition under clear]`

[sub type]
 11

[int data]
 副本代码 难度 通关房间数（自己去副本文件数）
[/int data]

[reward type]
 `[item]`

[reward int data]
 奖励代码 数量
[/reward int data]

[name]
 `任務名稱`

[depend message]
 `接受對話`

[condition message]
 `任務提示`

[solve message]
 `完成對話`
```

## 核心参数说明

### 基础配置
- [grade]: 任务类别（日常、重复等）
- [npc index]: 接取任务的NPC代码
- [complete npc index]: 完成任务NPC代码（-1表示任意NPC）
- [job]: 适用职业（[all]表示所有职业）
- [grow type]: 成长类型（默认-1）
- [level]: 任务等级范围（10-99表示10级以上）

### 任务类型配置
- [type]: 任务类型（[condition under clear]表示条件通关）
- [sub type]: 附加类型（11表示通关所有房间）

### 任务需求配置
- [int data]: 任务需求
  - 副本代码
  - 难度
  - 通关房间数（需要从副本文件中获取具体房间数量）

### 奖励配置
- [reward type]: 奖励类型（[item]表示物品奖励）
- [reward int data]: 奖励具体内容
  - 奖励代码 数量

### 文本信息
- [name]: 任务名称
- [depend message]: 接受任务时的对话
- [condition message]: 任务进行中的提示
- [solve message]: 完成任务时的对话

## 应用场景
- 创建通关副本所有房间的任务
- 设计副本完成度挑战任务
- 制作副本全通成就
- 设置高难度副本通关任务

## 重要说明
- [type]设置为[condition under clear]表示条件通关
- [sub type]设置为11表示通关所有房间
- 需要准确获取副本的房间总数
- 适用于需要完成整个副本流程的任务
