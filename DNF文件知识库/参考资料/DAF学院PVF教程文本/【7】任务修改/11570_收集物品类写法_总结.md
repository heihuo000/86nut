# 11570_收集物品类写法 - 内容总结

## 主要内容
本文介绍了收集物品类任务的编写方法和参数配置。

## 任务结构模板
```
#PVF_File
[grade]
 `[任务类型]`

[npc index]
 接取NPC代码

[complete npc index]
 -1

[job]
 `[all]`

[grow type]
 -1

[level]
 1 99

[type]
 `[seeking]`

[sub type]
 -1

[int data]
 任务需求代码1 数量
[/int data]

[reward type]
 `[item]`

[reward int data]
 奖励道具代码1 数量
[/reward int data]

[name]
 `任務名稱`

[depend message]
 `接受對話`

[condition message]
 `任務提示`

[solve message]
 `完成對話`
```

## 核心参数说明

### 基础配置
- [grade]: 任务类型（日常、重复等）
- [npc index]: 接取任务的NPC代码
- [complete npc index]: 完成任务NPC代码（-1表示任意NPC）
- [job]: 适用职业（[all]表示所有职业）
- [grow type]: 成长类型（默认-1）
- [level]: 任务等级范围（1-99表示所有等级）

### 任务类型配置
- [type]: 任务类型（[seeking]表示收集物品）
- [sub type]: 附加类型（默认-1）

### 任务需求配置
- [int data]: 任务需求
  - 任务需求代码1 数量
  - 可设置多个物品需求

### 奖励配置
- [reward type]: 奖励类型（[item]表示物品奖励）
- [reward int data]: 奖励具体内容
  - 奖励道具代码1 数量
  - 可设置多个奖励物品

### 文本信息
- [name]: 任务名称
- [depend message]: 接受任务时的对话
- [condition message]: 任务进行中的提示
- [solve message]: 完成任务时的对话

## 应用场景
- 创建收集指定物品的任务
- 设计日常收集任务
- 制作材料收集类成就
- 设置节日活动收集任务

## 重要说明
- 可以同时设置多个物品需求
- 奖励物品也可以设置多个
- 需要确保物品代码的准确性
- 任务提示信息要清晰明确
