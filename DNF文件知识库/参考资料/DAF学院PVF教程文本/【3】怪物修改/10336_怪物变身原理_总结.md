# 10336_怪物变身原理 - 内容总结

## 主要内容
本文详细介绍了DNF中怪物变身原理的实现机制，以铁鳞海贼团副本中的变身效果为例进行说明。

## 实现步骤

### 1. 查找副本文件
- 定位铁鳞海贼团副本文件：dungeon/quest/steelscales.dgn

### 2. 搜索地图配置
- 根据调用的map编号，搜索map.lst文件
- 跳转到start map文件：map/steelscales/15097(0,0)start.map

### 3. 定位变身对象
- 在[passive object]段落中查找变身相关配置：
```
10383 520 248 0
```
- 其中10383是让人变身的OBJ代码

### 4. 查找OBJ文件
- 到passiveobject.lst里搜索10383
- 找到对应文件：passiveobject/actionobject/monster/quest_masa.obj

### 5. 分析ACT文件
- 打开对应的act文件
- 找到变身相关代码：
```
[BEHAVIOR]
[CHANGE DISGUISER]
61249 10000000
[/BEHAVIOR]
```

### 6. 确定变身目标
- 代码61249对应马萨乔怪物
- 到monster.lst里搜索可得到文件：
- monster/newmonsters/riding/masaccio_quest/masaccio_quest.mob

## 重要说明
- 马萨乔是怪物，因此在monster目录下
- 这个变身后的马萨乔文件与普通副本中的绿名马萨乔不共用
- 该变身文件与其他文件结构有差异
- 删除10383这一行后，进入地图将不会触发变身效果
