# 10339_怪物属性免疫 - 内容总结

## 主要内容
本文介绍了如何让怪物免疫某种属性攻击的方法，通过提取树精的被动技能并转化出更多写法。

## 核心代码示例
```
[TRIGGER]
[ON DAMAGE]
[WHICH]
[ME]
[IS_WATER_DAMAGE]
[DO PROC BEHAVIOR]
[ME]
0
[/TRIGGER]

[BEHAVIOR]
[RESTORE]
[HP]
99999999
[POINT]
[/BEHAVIOR]
```

## 代码含义
- 当怪物受到冰属性攻击时，回复99999999血量
- 通过这种机制实现对特定属性攻击的免疫

## 扩展应用
- 可以将冰属性改为光、暗和火属性，实现对相应属性攻击的回复
- 针对某种属性攻击时回复血量

## 更多写法示例
可以通过组合多个触发条件来实现对多种属性攻击的免疫或回复，如：
- [IS_WATER_DAMAGE] - 冰属性攻击
- [IS_FIRE_DAMAGE] - 火属性攻击
- [IS_LIGHT_DAMAGE] - 光属性攻击
- [IS_DARK_DAMAGE] - 暗属性攻击

## 通用属性免疫方法
通过[ON DAMAGE]触发器来处理受到的所有伤害，并根据伤害类型进行不同的响应。
