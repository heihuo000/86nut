# 10327_pvf的怪物属性数据 - 内容总结

## 主要内容
本文提供了PVF中monsterapcdifficultybonus.tbl文件的怪物属性数据对照表，详细列出了各项属性在不同难度下的数值。

## 核心文件
- monster/monsterapcdifficultybonus.tbl

## 属性数据详解

### 回避率
- 未知：0, 40, 80, 120, 120
- 该数据组对应不同难度下的回避率参数

### 血量
- 参数：1, 2, 2.5, 5, 5
- 血量倍率：分别对应普通、一般、困难、英雄难度以及额外难度

### 攻击速度
- 参数：1, 1, 1, 1, 1
- 攻击速度倍率保持一致（各难度下无变化）

### 移动速度
- 未知：0, 50, 100, 180, 180
- 该数据组对应不同难度下的移动速度参数

### 攻击力
- 参数：1, 1.1, 1.2, 2, 2
- 攻击力倍率：随着难度递增而增强

### 防御力
- 参数：1, 1.1, 1.2, 1.4, 1.4
- 防御力倍率：随着难度递增而增强

## 重要说明
- 这些数据是基于monster/monsterapcdifficultybonus.tbl文件
- 数据按照副本难度分组：普通、一般、困难、英雄以及额外
- float数据是按组分配的，对应不同难度的同属性
- int数据直接按不同难度分开了，可用int修改根据怪物等级调整属性
- 该文件还包含攻击性、回避率、伤害等数据
