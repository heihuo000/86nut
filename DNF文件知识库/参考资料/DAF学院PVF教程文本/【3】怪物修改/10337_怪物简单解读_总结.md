# 10337_怪物简单解读 - 内容总结

## 主要内容
本文提供了怪物属性修改教程，对怪物文件进行整体翻译和解读，主要针对怪物属性修改。

## 核心信息
- 怪物列表信息文件路径：monster/monster.lst

## 重要提醒
- 怪物属性修改涉及很多内容
- 如果只是修改怪物属性，而不是增加攻击效果或特效，通常只需要修改一些固定内容
- 尽量不要修改其他内容，否则可能导致客户端崩溃或无限avg
- 如果仅修改怪物的攻击力、防御、血量、属性抗性等，请务必不要改动其他内容

## 怪物属性详解

### [ability category] 段落
- 表头开始标记
- 包含以下属性：

#### 血量
- `[HP MAX]` * 54950

#### 物理攻击
- `[EQUIPMENT_PHYSICAL_ATTACK]` * 1300

#### 物理防御
- `[EQUIPMENT_PHYSICAL_DEFENSE]` * 330

#### 魔法攻击
- `[EQUIPMENT_MAGICAL_ATTACK]` * 1100

#### 魔法防御
- `[EQUIPMENT_MAGICAL_DEFENSE]` * 300

#### 物理攻击属性
- `[EQUIPMENT_PHYSICAL_ATTACK_ATTRIBUTE]` `%` 0

#### 属性抗性
- `[FIRE_RESISTANCE]` % 350 (火抗)
- `[WATER_RESISTANCE]` % 350 (冰抗/水抗 - 台服叫水抗)
- `[LIGHT_RESISTANCE]` % 350 (光抗)
- `[DARK_RESISTANCE]` % 350 (暗抗)

#### 状态抗性
- `[STUN_RESISTANCE]` % 100 (眩晕抗性)
- `[FREEZE_RESISTANCE]` % 100 (冰冻抗性)
- `[BURNING_RESISTANCE]` % 100 (燃烧抗性)
- `[BLIND_RESISTANCE]` % 100 (失明抗性)
- `[CURSE_RESISTANCE]` % 100 (诅咒抗性)
- `[DOT_RESISTANCE]` % 100 (持续伤害抗性)
- `[SLOW_RESISTANCE]` % 100 (减速抗性)
- `[SEAL_RESISTANCE]` % 100 (封印抗性)
- `[BANISHMENT_RESISTANCE]` % 100 (放逐抗性)
