# 11826_怪物随机说话 - 内容总结

## 主要内容
本文介绍了如何让怪物在特定情况下随机说话的方法，通过在怪物文件中添加特定代码实现怪物对话功能。

## 核心代码
```
[speech on situation]
    [on revenge]    `有人砸場子啦！！`    0    
    [on revenge]    `兄弟們抄家伙啊！`    0    
    [on etc]    `哼！ 好哥布林不吃眼前虧！`    0    
    [on etc]    `只剩我了? 撤！`    0    
    [on etc]    `啊啊......我要全部......殺掉！！！`    0    
    [on etc]    `我熱血沸騰了......`    0    
    [on village]    `哥布林不發威，就當我是牛頭怪？`    0    
    [on village]    `這是哪里？我又是誰？`    0    
    [on village]    `這里也沒什么特別的嘛~`    0    
    [on village]    `我有點后悔了……`    0    
    [on village]    `別打我！`    0    
    [on village]    `我只是來散步的！`    0    
    [on village]    `嘿嘿，給你添麻煩了，對不起啊！`    0    
    [on village]    `這只是個卑鄙的藉口！`    0    
[/speech on situation]
```

## 功能说明
- 通过[speech on situation]段落定义怪物说话内容
- 包含不同情境下的对话内容
- 每条对话后跟一个数字（通常是0），表示相关参数

## 情境分类
- [on revenge]: 复仇/战斗时的情境
- [on village]: 在村庄或特定环境时的情境
- [on etc]: 其他一般情况

## 重要说明
- 可以根据需要自定义不同情境下的对话内容
- 通过添加多条语句可以实现随机说话效果
- 适用于让怪物更加生动有趣，增加游戏体验
