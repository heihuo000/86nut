# 10340_怪物AI简单解读 - 内容总结

## 主要内容
本文介绍了怪物AI代码的基本概念，通过在怪物文件中添加特定代码让怪物变得更聪明，研究怪物AI代码和攻击机制。

## 核心AI代码
```
[sight]
5000
[targeting time term]
100
[targeting nearest]
1
[warlike]
1000
[attack delay]
100
[superarmor on attack]
1 50
```

## 参数详解

### [sight] - 视野范围
- 数值：5000
- 作用：设定怪物的视野范围

### [targeting time term] - 发现目标所需时间
- 数值：100
- 作用：设定怪物发现目标所需时间

### [warlike] - 好战性
- 数值：1000
- 说明：默认Boss一般为80，小怪20-30不等，精英怪50
- 效果：实际作用可能有限

### [attack delay] - 攻击延时
- 数值：100
- 作用：设定攻击前的延时时间

### [superarmor on attack] - 攻击时霸体
- 数值：1 50
- 作用：怪物攻击时具有霸体效果

### [targeting nearest] - 靠近目标
- 数值：1
- 作用：使怪物靠近目标

## 代码机制说明
- 整体含义：视野范围5000内出现目标
- 发现目标需要0.1秒时间
- 然后靠近目标
- AI代码发现目标后进行攻击或释放技能
- 降低部分怪物的技能CD会使Boss类怪物更活跃

## 其他AI代码
- 还有其他代码如：跟紧目标范围内
- 个别怪物和Boss的技能释放顺序较难理解
- 理论上能够添加或移除怪物技能
- 可控制怪物释放技能的时机和种类
