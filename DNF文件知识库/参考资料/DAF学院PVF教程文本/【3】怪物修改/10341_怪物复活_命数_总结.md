# 10341_怪物复活_命数 - 内容总结

## 主要内容
本文介绍了如何让怪物具有复活能力的方法，通过在怪物文件中添加特定代码实现怪物死亡后复活的功能。

## 核心代码
```
[life max]
50
```

## 功能说明
- 该代码可以设置怪物复活次数
- 怪物死亡后会立即恢复原有血量
- 数值50代表怪物可以复活50次

## 使用方法
- 直接将代码写入怪物文件中
- 修改[life max]后的数值可以调整复活次数
- 例如，设置为1则怪物只能复活1次，设置为100则可复活100次

## 重要说明
- 这个功能可以让怪物在被杀死后立即复活
- 适用于需要高耐久性怪物的场景
- 复活后怪物恢复到原始血量状态
