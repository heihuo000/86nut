# 12082_ 单个怪物经验官方化(繁琐版) - 内容总结

## 主要内容
本文介绍了单个怪物经验官方化的繁琐版操作方法，通过直接修改数据库中的monster_reward_ref表来实现。

## 问题背景
- 原版5.2G版本中，杀死一个怪物可以获得好几千经验
- 例如洛兰出来都可以升10多级
- 加上经验倍数是10倍，总经验更多

## 修改步骤

### 1. 确定修改位置
- DXF服务端中有很多可以修改经验的地方
- 在杀死怪物后获得的经验值可以通过修改数据库实现

### 2. 数据库操作
- 打开192.168.1.160数据库
- 找到taiwan_cain数据库
- 找到monster_reward_ref表
- 右键删除monster_reward_ref表(D)

### 3. 创建新表并插入数据
```

-- Table structure for monster_reward_ref
-- ----------------------------

CREATE TABLE `monster_reward_ref` (
`level` smallint(11) NOT NULL DEFAULT '0',
```
