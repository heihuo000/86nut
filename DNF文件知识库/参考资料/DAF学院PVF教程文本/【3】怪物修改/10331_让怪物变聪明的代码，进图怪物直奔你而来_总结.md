# 10331_让怪物变聪明的代码，进图怪物直奔你而来 - 内容总结

## 主要内容
本文介绍了如何通过在怪物文件中添加特定代码来让怪物变得更聪明，实现怪物进入地图后直接朝玩家方向移动的效果。

## 核心代码
```
[sight]
5000
[targeting time term]
100
[targeting nearest]
1
[warlike]
1000
[attack delay]
100
[superarmor on attack]
1 50
```

## 参数详解

### [sight] 视野范围
- 数值：5000
- 作用：设定怪物视野范围，单位为范围值

### [targeting time term] 发现目标所需时间
- 数值：100
- 作用：设定怪物发现目标所需的时间（大约0.1秒）

### [warlike] 好战性
- 数值：1000
- 说明：虽然设定为高数值，但实际效果有限
- 默认的Boss一般为80，小怪为20-30不等，精英怪为50

### [attack delay] 攻击延时
- 数值：100
- 作用：设定怪物攻击前的延时时间

### [superarmor on attack] 攻击时霸体
- 数值：1 50
- 作用：怪物在攻击时具有霸体效果

### [targeting nearest] 靠近目标
- 数值：1
- 作用：让怪物靠近目标玩家

## 代码作用机制
- 总体含义：视野范围5000内出现目标
- 发现目标需要0.1秒
- 然后靠近目标
- AI代码中发现目标后进行攻击或释放技能
- 部分怪物通过降低技能CD可使其更活跃

## 其他AI优化建议
- 部分怪物和Boss的技能释放顺序较难理解
- 有可能移除或添加怪物的技能
- 可以控制怪物释放特定技能的时机
