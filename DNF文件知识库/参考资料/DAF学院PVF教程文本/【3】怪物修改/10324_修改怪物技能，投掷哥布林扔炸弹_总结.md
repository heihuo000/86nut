# 10324_修改怪物技能，投掷哥布林扔炸弹 - 内容总结

## 主要内容
本文介绍了如何修改投掷哥布林的技能，让其投掷走狗Boss的炸弹，实现哥布林丢走狗Boss炸弹的效果。

## 修改原理
- 投掷哥布林的投掷技能代码是30001，对应投掷石头
- 走狗的炸弹技能代码是8225
- 将投掷哥布林文件中的30001改为8225，即可使其投掷炸弹

## 修改步骤

### 1. 定位投掷哥布林文件
找到投掷哥布林的怪物文件，查找[throw attack]段落
```
[throw attack]
'[attack index]' 0 '[passive object number]' 1 '[passive object filename]' 'Particle/ThrowStone.ptl' '[object type]' 1 '
[passive object index]' 30001 '[power]' 0 '[throw frame]' 2 '[passive object start x cood]' 20 '[passive object start y cood]' 0 '
[passive object start z cood]' 60 '[attack number]' 1 '[throw sound]' 'THROW_STONE'
[/throw attack]
```

### 2. 查找走狗炸弹代码
- 在走狗怪物文件中搜索代码8225，这是走狗的炸弹代码
- 找到走狗投掷炸弹的技能.ptl文件，通常是'ActionObject/Monster/Jeff/Jeff_FrontMissile.obj'

### 3. 替换技能文件
- 将走狗的炸弹技能.ptl文件复制并重命名为throwstone
- 覆盖到投掷哥布林相应的技能文件位置

### 4. 修改索引代码
- 将投掷哥布林文件中的30001改为8225
- 投掷哥布林的文件也需要写入修改

## 炸弹属性修改
炸弹的属性可以进一步修改，包括：
- 炸弹飞行距离
- 持续时间
- 飞行速度
- 伤害
- 爆炸范围
