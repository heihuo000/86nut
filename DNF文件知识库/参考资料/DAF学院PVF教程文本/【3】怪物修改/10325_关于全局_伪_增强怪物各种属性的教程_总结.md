# 10325_关于"全局（伪）"增强怪物各种属性的教程 - 内容总结

## 主要内容
本文介绍了一种通过称号添加属性的方式来"全局（伪）"增强怪物各种属性的方法，提供了一种简单的增强怪物能力的思路。

## 核心思路
- 作者原本想通过修改全局参数来简单增强怪物能力，但因计算机配置限制而放弃
- 在给称号添加属性时突发奇想，想到了通过称号系统来增强怪物能力的方法

## 实现代码示例
```
[if]
[start cooltime]
100
[change status]
'hp' '>' '%' 0 'end'
[/if]

[then]
[target]
'all enemy' 500
[stat by condition]
'equipment physical defense' '%' +188888
[stat by condition]
'equipment magical defense' '%' +188888
```

## 代码说明
- 进入地图0.1秒后（100/1000秒）
- 当自身血量大于0时
- 选定500码内所有敌人
- 使其物防和魔防增强188.888倍

## 其他属性增强示例
作者提供了进一步的代码示例，可以同时增强物理攻击、魔法攻击等其他属性：
```
[if]
[start cooltime]
100
[change status]
'hp' '>' '%' 0 'end'
[if]
[start cooltime]
100
[change status]
'hp' '>' '%' 0 'end'
[/if]
[then]
[target]
'all enemy' 500
[stat by condition]
'equipment physical defense' '%' +188888
[stat by condition]
'equipment magical defense' '%' +188888
[stat by condition]
'equipment physical attack' '%' +188888
[stat by condition]
'equipment magical attack' '%' +188888
```

## 重要说明
- 此方法是"伪"全局增强，是通过称号系统实现的
- 测试显示增强了188.888倍防御后，玩家对怪物的伤害明显降低
- 这种方法相比直接修改全局参数可能更加安全
