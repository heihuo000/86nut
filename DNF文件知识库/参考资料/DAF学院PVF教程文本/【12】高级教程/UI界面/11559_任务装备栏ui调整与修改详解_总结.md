# 11559_任务装备栏ui调整与修改详解 - 内容总结

## 主要内容
本文详细介绍了如何调整和修改DNF游戏中的任务装备栏UI位置。

## 核心文件
- ui/inventory/inventory_item.ui

## 重要说明
- 此路径仅调整装备界面的UI位置，而非NPK补丁位置
- UI位置是指装备后显示的位置
- 贴图需要单独修改图框

## UI配置详解
### 装备栏背景图案配置
```
[ui controls]
  [image]
  -1  -3  42  1
  `Interface/newstyle/windows/Inventory/Inventory.img`  1  0
[/ui controls]
```

### 装备框体图标配置
```
[ui controls]
  [image]
  -1  -1  44  1
  `Interface/newstyle/windows/Inventory/Inventory.img`  1  21
[/ui controls]
```

## 参数说明
- 第1、2个数字: X、Y坐标位置
- 第3个数字: 图像索引
- 第4个数字: 透明度或状态
- 文件路径: 图像资源路径
- 后面的数字: 图像ID或状态

## 应用方法
- 通过修改坐标值调整UI元素位置
- 通过修改图像ID更换UI元素外观
- 需要配合NPK文件中的实际贴图修改
