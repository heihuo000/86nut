# 11348_DAF卡技能代码 - 内容总结

## 主要内容
本文档详细列出了DAF卡技能的代码对照表，包括各职业通过卡技能可以获得的其他职业技能。

## 核心机制说明
1. 卡出技能后，只能按照职业顺序转职
2. 例如：狂战士在鬼剑士里是第三职业，就只能转成男枪手的机械师（也是第三职业）
3. 如果转成弹药专家，也会变成机械师，反之亦然
4. 使用商城自带的职业书转职后，可以随意转职
5. 但卡出技能后又不能随意转职了

## 重要说明
1. 卡技能机制是按照职业在职业体系中的位置进行映射的
2. 不同职业间的技能映射关系是固定的
3. 使用商城职业书可以临时解除转职限制
4. 卡技能后会重新锁定转职路径
