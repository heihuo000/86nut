# 11342_轮回几多忆乌山-四鬼合一篇 - 内容总结

## 主要内容
本文介绍了通过PVF修改实现四鬼剑技能合一的方法，使玩家可以在技能面板上学习其他转职职业的技能。

## 实现方法

### 方法一：修改技能树文件
1. 打开clientonly文件夹，再打开skilltree文件夹
2. 打开swordman_sp.co文件（鬼剑士技能树文件）
3. 在相应转职职业的位置添加代码来添加其他职业的技能
4. 例如：添加光剑精通技能给阿修罗职业
5. 代码格式：技能编号 + icon pos（技能图标在技能表中的位置）

### 方法二：修改角色文件
1. 修改swordman.chr文件
2. 该文件记录着转职时自动学会的技能
3. 可以让角色在转职时直接学习其他职业的技能
4. 该文件还包含人物的各种属性信息

## 技能编号查询
- 各种鬼剑士技能的编号存储在skill文件夹里的swordmanskill.lst文件中
- 如果看不懂英文可以参考skiil.kor.str文件

## 实际案例
- 通过修改实现了血之狂暴技能的学习和使用
- 但需要注意技能描述消失后可能没有伤害的问题

## 测试结果与建议

### 注意事项
1. 直接删除前置技能代码段会导致技能选项消失，容易造成技能没伤害或者出错
2. 建议通过修改数值的方法，比如将前置技能修改为短剑精通+1
3. skill class和fitness growtype没必要改，改下growtype maximum就可以
4. 建议采用替换的方法，将一些不常用的技能替换为想要的技能

### 操作建议
1. 直接添加技能是可以的，但替换可以减少错误
2. 学习技能时不要贪心，避免超过技能限制
3. 修改技能信息时要注意同步修改相关文件

## 重要说明
- 通过PVF修改可以实现真正的四鬼剑技能合一
- 修改后可以在技能面板上学习到其他转职职业的技能
- 修改技能时需要特别注意前置技能和技能描述的关联
