# 11733_剑魂（剑圣）太刀出血姨妈流削弱方法 - 内容总结

## 主要内容
本文介绍了如何通过PVF文件修改来削弱剑魂（剑圣）太刀出血姨妈流的强度，主要针对太刀精通减少出血伤害和减少拔刀斩追击伤害。

## 修改文件路径

### 核心技能文件
1. 太刀精通：skill/swordman/blademastery.skl
2. 幻影剑舞：skill/swordman/illusionslash.skl
3. 强化-幻影剑舞：skill/swordman/illusionslashexp.skl
4. 拔刀斩：skill/swordman/momentaryslash.skl
5. 强化-拔刀斩：skill/swordman/momentaryslashex.skl

## 削弱修改代码

### 修改目标
- 太刀精通：减少出血伤害
- 拔刀斩：减少追击伤害

## 属性对应关系

### 太刀精通属性
1. 物攻增加比率：0.1
2. 魔攻增加比率：0.1
3. 物理命中增加比率：0.1
4. 剑魂出血几率：0.1
5. 剑魂出血等级：1.0
6. 剑魂出血持续时间：0.001
7. **剑魂出血伤害：0.1**（重点削弱项）
8. 空中连斩附加物理攻击力：1.0
9. 空中连斩对出血状态敌人的攻击力增加率：1.0
10. 拔刀斩追击时物理攻击力：1.0
11. 拔刀斩追击时出血几率：0.1
12. 拔刀斩出血等级：1.0
13. 拔刀斩出血持续时间：0.001
14. **拔刀斩出血伤害：1.0**（重点削弱项）

## 修改思路
1. 找到每个技能最底部的`[level property]`代码段区间
2. 根据附加属性数量对应每个技能或精通技能的附加属性
3. 通过对比技能附加属性找到该属性的排序
4. 每个属性都已注释说明，便于理解
5. 想要加强或削弱技能属性按照需求修改相应数值
6. "0.1、1.0"之类的数值代表基础属性加强比率

## 应用价值
1. 平衡剑魂职业强度
2. 削弱过于强势的出血流玩法
3. 维护游戏职业平衡性
4. 提升游戏竞技公平性

## 注意事项
1. 修改前务必备份原文件
2. 理解各属性的具体含义和作用
3. 削弱幅度需要适度，避免影响正常游戏体验
4. 测试修改效果后再正式应用
