# 12015_添加偷学技能教程 - 内容总结

## 主要内容
本文介绍了如何添加偷学技能的详细教程。

## 修改步骤

### 1. 修改技能文件
- 找到想要偷学的技能文件
- 示例：狂战士双刀技能 - skill\swordman目录下的frenzy
- 在技能代码中添加：
```
[steel learning skill]
1501000
```
此代码表示这个技能可以被偷学

### 2. 修改最大等级
- 修改[growtype maximum level]参数
- 将中间四个数字改成一样的值
- 表示四个转职职业都可以学到的最高等级
- 示例：双刀设为最高20级

### 3. 修改NPC列表
- 找到albert和albert_fairpvp两个NPC文件
- 将原来的技能ID替换成想要修改的技能ID

## 重要说明
- 完成修改后保存并上传到服务端
- 重新跑一次五国（重新初始化）
- 即可学到相应技能

## 限制条件
- 只能偷学50级以下的技能
- 觉醒技无法通过此方法修改，可能是EXE中写死的限制
- 作者研究多日未成功修改觉醒技能
