# 11735_召唤师的召唤兽添加扩展技能小白篇（@后李绑银） - 内容总结

## 主要内容
本文介绍了如何为召唤师的召唤兽添加被击自动使用技能反击敌人的扩展技能，以犬人哈多和哥布林赫德尔为例进行详细说明。

## 核心功能
实现召唤兽被攻击后自动使用指定技能反击敌人，增强召唤兽的战斗智能和主动性。

## 实现方法

### 1. 犬人哈多示例
在犬人哈多（代码50084）的mod文件最下方添加以下代码：
```
[counter attack] //代码开头不可修改
    1
`[probability]`30 //被击后使用自身技能反击的几率
`[attack index]`3 //使用[attack motion]中的第3号位技能反击敌人；
`[damage type]` //触发反击的条件
`[all attack]` //只要被击就触发技能反击敌人
[/counter attack] //代码结尾不可修改；
```

### 2. 哥布林赫德尔示例
想要让哥布林赫德尔被击后用丢炸弹反击敌人，可按以下方法修改：

#### 步骤一：添加反击代码
在赫德尔mod文件的最下方复制并粘贴以下代码：
```
[counter attack]
    1
`[probability]` 100 //被击后必然触发技能反击；
`[attack index]` 6 //在赫尔德[attack motion]中丢炸弹为第6号位技能，这里改成6；
`[damage type]`
`[all attack]`
[/counter attack]
```

#### 步骤二：确认技能索引
在老牌怪物中mod文件中的[attack motion]下的代码就是技能所用的ani，以赫尔德mod文件为例：
```
[attack motion] //代码开头不可修改
`Animation_Hodor/Attack1.ani` //普通棒子攻击；0号位技能
`Animation_Hodor/Throw.ani` //丢石头；1号位技能
`Animation_Hodor/ChargeAttack.ani` //棒子重击，有几率眩晕敌人可在atk中修改；2号位技能
`Animation_Hodor/Throw.ani` //给自身上加速BUFF
`Animation_Hodor/TripleThrow.ani` //石头三连投掷
`Animation_Hodor/FiveThrow.ani` //石头五连投掷
`Animation_Hodor/Throw.ani` //丢炸弹；6号位技能
[/attack motion]
```

### 3. 技能释放几率控制
通过修改[attack kind]下的代码控制技能释放几率，以赫尔德mod文件为例：
```
[attack kind]
100.00.0100.0180000200200 //第一个100为释放棒子攻击的几率，100代表只要不在CD就必然释放
100.00.00.015000500030003000 //丢石头的释放
100.00.0100.0180000200200 //对应技能解释
100.00.0100.0140020000500500 //对应技能解释
100.00.0100.0140020000500500 //对应技能解释
100.00.0100.0140020000500500 //对应技能解释
100.00.00.014001000010001000 //对应技能解释
[/attack kind]
```

## 参数详解

### [counter attack] 段落
- 用于定义召唤兽被攻击后自动反击的机制
- 开头和结尾代码不可修改

### probability 参数
- 被击后使用自身技能反击的几率
- 数值范围：0-100
- 100表示必然触发反击

### attack index 参数
- 指定使用[attack motion]中的第几号位技能进行反击
- 根据技能在[attack motion]中的位置确定编号

### damage type 参数
- 触发反击的条件
- 可设置不同类型的伤害触发条件

### all attack 参数
- 表示只要被击就触发技能反击敌人
- 最简单的触发条件设置

## 应用价值
1. 提高召唤兽战斗智能
2. 增强召唤师职业的游戏体验
3. 使召唤兽更具主动性
4. 丰富召唤师技能策略

## 注意事项
1. 修改前务必备份原文件
2. 确认技能在[attack motion]中的正确位置
3. 合理设置反击几率，避免过于频繁
4. 测试修改效果后再正式应用
