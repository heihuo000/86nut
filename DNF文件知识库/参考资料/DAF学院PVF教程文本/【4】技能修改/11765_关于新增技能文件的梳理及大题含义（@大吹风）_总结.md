# 11765_关于新增技能文件的梳理及大题含义 - 内容总结

## 主要内容
本文详细梳理了新增技能文件的完整流程和各组件之间的关系，以魔法旋风为例进行说明。

## 技能组成要素
一个完整的主动技能应包含以下文件：
1. 技能参数文件(skl)
2. 技能所调用的特效(obj)
3. 技能和谐执行文件(nut)
4. 人物技能动作(ani)
5. 放技能时对应动作的时装(equ)
6. 技能树配置

## 技能开发流程

### 1. 基础技能创建
- 建立skl文件并写好相关数据
- 配置技能树
- 重跑五国（数据同步）
- 技能能学上且进图不灰即为成功

### 2. NUT文件配置

#### Header部分配置
- skill编号（对应skl技能编号）
- state编号（随意，不重复即可）
- ani编号
- chr里面ani文件的编号（从第一个ani为0开始计数）
- atk编号（同理ani）

#### Load部分配置
- 声明格式职业
- 文件路径
- header里面的skill、state
- 技能名（同技能skl名，同时也是nut函数名，严格区分大小写）

### 3. NUT主文件结构
一个完整的技能nut分为四个阶段：
1. 检测按键是否可用（可用则亮按键）
2. 检测状态是否满足技能释放
3. 按下按键后执行函数(onstart)
4. 技能执行结束后执行函数(onend)

## 参数传递机制

### PO函数作用
PO在技能中起到skl到特效atk的参数传递作用

#### 配置步骤
1. 在load里面声明po路径
2. 实现传递的obj编号
3. **特殊要求**：技能obj编号必须为242xx-243xx之间，否则参数传递失败

#### 数据写入流程
1. 在nut主文件定义一个量：local attack
2. 获取skl参数赋值给attack
3. 开始写入startwrite
4. writedword的位置是0,1，按写入顺序排列

#### 数据读取流程
1. 在po创建一个量：local attact
2. 读取刚刚写入的参数赋值给这个量
3. 获取atk，设置攻击

### 数据传输过程
skl参数 → nut获取到attack量 → 写入dword → po读取到attact量 → 通过load编号传递 → 对应obj编号的atk

## 重要注意事项
1. **命名一致性**：po的参数名字必须与obj命名一致
2. **编号范围**：obj编号必须为242xx到243xx，否则数据传递失败
3. **顺序要求**：数据写入和读取顺序必须一致

## 技能百分比设置

### 普通attack info设置
```lua
local attackInfo = sq_GetCurrentAttackInfo(obj); 
sq_SetCurrentAttackBonusRate(attackInfo, bonus);
```

### ETC attack info设置
```lua
local attackInfo = sq_GetCustomAttackInfo(obj, 0); 
sq_SetCurrentAttackBonusRate(attackInfo, bonus); 
sq_SetCurrentAttackInfo(obj, attackInfo);
```

## 区分方法
通过打开obj的atk栏位可以区分是普通attack info还是etc attack info
