# 11546_觉醒插画 - 内容总结

## 主要内容
本文介绍了如何为二觉技能添加插画，方法与一觉插画添加方式相同。

## 核心文件
- 文件路径：ultimateskillcutscene.etc
- 该文件包含了使用什么技能调用什么动画等内容

## 文件结构说明

### 基本格式
```
[SKILL INDEX]
1        4        227
[FLIP TYPE]
1
[START POSITION]
0        0
[ANI FILE]
`etc/UltimateSkillAni/FighterGrappler2nd.ani`
[MOVE DIR]
0        0        2000
[/MOVE DIR]
```

### 参数解释
1. **[SKILL INDEX]**：技能索引
   - 第一个数字：职业编号（如女格斗为1）
   - 第二个数字：转职编号（如风暴女皇为4）
   - 第三个数字：技能ID（如227）

2. **[FLIP TYPE]**：特效使用方式

3. **[START POSITION]**：起始位置坐标

4. **[ANI FILE]**：动画文件路径

5. **[MOVE DIR]**：移动方向参数

## 职业编号对照
- 鬼剑士：0
- 白手：0 1
- 红眼：0 2
- 其他职业有各自对应的编号

## 操作要点
1. 确定准确的职业转职编号和技能ID
2. 可以查阅官方文件进行比对确认
3. 理解各参数的基本含义和作用
4. 二觉插画添加方式与一觉相同

## 应用价值
1. 为自制二觉技能添加配套插画
2. 完善技能的视觉效果
3. 提升游戏体验的完整性
4. 使自定义技能更加专业

## 注意事项
1. 需要具备一定的PVF基础知识
2. 对特效参数理解要求较高
3. 建议参考官方文件进行编号确认
4. 修改前务必备份原文件
