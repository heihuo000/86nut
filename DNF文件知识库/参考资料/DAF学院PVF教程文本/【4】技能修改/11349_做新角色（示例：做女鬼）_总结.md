# 11349_做新角色（示例：做女鬼） - 内容总结

## 主要内容
本文介绍了如何通过PVF修改制作新角色的方法，以制作女鬼角色为例进行详细说明。

## 制作背景
- 作者被邀请参与黑岩项目制作二觉技能
- 由于承诺在2.1版本发布前保密，现在版本已发布故公开制作方法
- 本教程需要一定的PVF基础知识，新手可能难以理解

## 核心方法

### 1. 技能修改方法
- 使用现有的技能修改成二觉技能
- 通过对比和修改技能文件实现技能转换
- 示例：将冰阵改成刀阵

### 2. 技能特效修改
1. 使用pvftool打开指定路径
2. 打开需要修改的技能OBJ文件（控制技能特效的文件）
3. 对文件进行比对然后修改
4. 反复尝试，遇到问题继续调试

### 3. 人物技能动作修改
1. 修改人物技能动作需要打开特定文件
2. 通过对比和替换实现动作修改
3. 需要耐心调试，可能会出现错误但可以重新开始

### 4. 特效文件处理
- 特效文件有固定位置
- 可以在网上下载二觉文件放入相应目录
- 压杆文件由大神整合过，可以寻找使用

### 5. 攻击信息修改
- 还需要修改ATK攻击信息等细节
- 相关教程可参考豆腐百科
- 大致方法已经涵盖核心内容

### 6. 人物皮肤制作
- 制作人物皮肤是另一个重要内容
- 需要专门的皮肤制作技术

## 制作要点
1. 需要具备PVF基础知识
2. 要有耐心，反复尝试和调试
3. 遇到错误不要气馁，可以重新开始
4. 做出好作品要记得分享
5. 参考网上已有资源，如大神整合的压杆文件

## 重要说明
- 本教程只是一个大致方法指引，无法做到手把手教学
- 需要制作者有一定的技术基础和实践能力
- 鼓励制作者分享自己的作品，为单机社区做贡献
- 制作过程需要不断尝试和纠错

## 应用价值
- 为想要制作新角色的玩家提供技术指导
- 推动单机社区的MOD创作发展
- 分享专业技术经验，促进技术交流
