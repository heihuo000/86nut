# 11777_狂战觉醒拍完就起身（@Fisky） - 内容总结

## 主要内容
本文介绍了如何通过修改ANI文件让狂战觉醒拍击动作完成后立即起身，提升技能连击流畅度。

## 实现原理
- 狂战觉醒拍击动作完成后仍有后续动作
- 通过修改动作持续时间参数实现快速起身
- 将拍击动作的持续时间改为0或极小值

## 修改方法

### 核心文件
- 定位到狂战觉醒拍击动作对应的.ANI文件
- 文件中包含多个动作序列和延迟参数

### 操作步骤
1. 打开指定的.ANI文件
2. 查找[DELAY]标签下的数值参数
3. 将该数值修改为极小值（如1）
4. 保存文件并测试效果

### 技术要点
- [DELAY]数值控制动作持续时间
- 数值越小，动作持续时间越短
- 将数值改为1可实现几乎瞬间起身效果
- 文件中可能包含多个DELAY参数

### 参数识别
- 文件中包含多个DELAY数值
- 需要确定哪些是拍击完成后的动作延迟
- 可通过NPK文件内的[IMAGE]路径进行确认
- 精确定位目标参数以避免误修改

## 应用效果
- 狂战觉醒拍击动作完成后立即起身
- 提升技能连击流畅性和战斗节奏
- 减少动作僵直时间
- 增强技能实用性

## 注意事项
1. 修改前务必备份原文件
2. 精确定位目标DELAY参数
3. 数值调整需要适度，避免过于突兀
4. 测试修改效果后再正式应用
5. 注意与其他动作的协调性
