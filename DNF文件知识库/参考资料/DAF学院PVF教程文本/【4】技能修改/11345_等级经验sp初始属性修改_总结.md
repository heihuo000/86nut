# 11345_等级经验sp初始属性修改 - 内容总结

## 主要内容
本文介绍了DNF游戏中等级经验、SP点数和角色初始属性的修改方法。

## 修改内容详解

### 1. 等级经验表修改
- 文件路径：character/exptable.tbl
- 算法说明：下一级减去当前级别的需求经验等于下一级的真实需求经验
- 示例：5543(3级)-2653(2级)=2890(3级真实需求经验)

### 2. SP点数表修改
- 文件路径：etc/sptable.etc
- 用途：修改每级获得的SP点数
- 技巧：可以在1级直接改为20000，省去吃书的烦恼
- 注意：TP点数暂未找到修改位置

### 3. QP点数修改
- 文件路径：etc/questshop.etc
- 修改位置：[quest point]段落
- 限制：不能改为0，最低为1

### 4. 角色初始属性修改
- 文件路径：character/各职业文件夹里的.chr文件
- 注意事项：
  - 必须上传到服务端才能生效
  - 只有修改后的新建角色和怪物享有这些属性
  - 已有的角色不受影响

## 重要说明
1. 等级经验表的计算方式需要特别注意，是累减算法
2. SP点数修改可以大幅简化角色升级过程
3. QP点数修改有最低限制，不能设为0
4. 角色初始属性修改只对新创建的角色有效

## 应用场景
- 服务器端经验调整
- 快速升级设置
- 自定义服务器配置
- 角色平衡性调整
