# 11351_教你如何查看技能文件各数据的意思 - 内容总结

## 主要内容
本文详细介绍了如何理解和查看DNF技能文件中[static data]和[level info]各数据的具体含义，以盲人(瞎子)一觉技能为例进行说明。

## 核心概念

### 1. 数据结构说明
- **[static data]**：静态数据，不随技能等级变化
- **[level info]**：等级信息数据，随技能等级变化
- 数据编号从0开始计算

### 2. 数据分组规则
- level info中第一个数值表示后面有多少个数据为一组
- 例如：第一个数值为14，表示后面14个数据为一组
- static data中所有数据为一组

## 分析方法

### 1. 定位数据解释
在技能文件中向下查找，会发现对技能数据的详细解释，包括：
- 数据描述（如："持續時間 : <float1>秒"）
- 数据对应关系（如："-1 13 0.001000"）

### 2. 数据解析规则
1. 描述中的"<float1>"表示浮点数据
2. 数据组中的三个数值含义：
   - 第一个数值：数据来源标识（-1表示来自[level info]，正数表示来自[static data]）
   - 第二个数值：数据编号
   - 第三个数值：倍率系数

### 3. 计算公式
最终数值 = 原始数据值 × 倍率系数

## 实例分析（以盲人一觉技能为例）

### 示例1：持续时间解析
- 描述："持續時間 : <float1>秒"
- 对应数据："-1 13 0.001000"
- 解析过程：
  1. 第一个数值-1表示来自[level info]
  2. 第二个数值13表示编号为13的数据
  3. 在[level info]中找到编号为13的数据为40000
  4. 第三个数值0.001000为倍率系数
  5. 最终结果：40000 × 0.001000 = 40秒

### 示例2：技能冷却时间解析
- 描述："波動眼·天照冷卻時間 : <float1>秒"
- 对应数据："6 6 0.001000"
- 解析过程：
  1. 第一个数值6表示来自[static data]（与-1不同）
  2. 第二个数值6表示[static data]中编号为6的数据
  3. 在[static data]中找到编号为6的数据为3500
  4. 第三个数值0.001000为倍率系数
  5. 最终结果：3500 × 0.001000 = 3.5秒

## 应用价值
1. 帮助理解技能文件中各数据的具体含义
2. 指导技能修改时的精准定位
3. 提高PVF技能修改的成功率
4. 减少盲目修改导致的错误

## 注意事项
1. 不同技能的数据结构可能略有差异
2. 需要结合具体技能文件进行分析
3. 建议修改前备份原文件
4. 修改后需要重启游戏验证效果
