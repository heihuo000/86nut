# 10298_释放技能会喊话 - 内容总结

## 主要内容
本文档介绍了如何在角色释放技能时添加喊话效果的方法。

## 详细信息

### 实现效果
当角色释放特定技能时，会在屏幕上显示自定义的喊话文字。

### 核心代码
```
[@05][if]
[@05][event use skill]
[@07]swordman
[@02]74
[@05][/if]
[@05][then]
[@05][target]
[@07]myself
[@02]-1
[@05][speech on]
[@02]0
[@02]2000
[@09]3
[@0A]speech_1
[@05][/speech on]
[@05][/then]
```

### 代码说明

#### 1. 技能触发条件
```
[event use skill]
[swordman] 74
```
- `[event use skill]`：技能使用事件
- `[swordman]`：鬼剑士职业
- `74`：技能编号（崩山击）

#### 2. 喊话效果设置
```
[speech on]
0           // 未知参数
2000        // 显示持续时间（毫秒）
3           // 文字类型？
speech_1    // 喊话内容标识
[/speech on]
```

### 修改方法

#### 1. 文件位置
- 主文件：`\\stackable\\stackable.kor`
- 喊话内容：修改`speech_1`相关内容

#### 2. 自定义喊话
在`stackable.kor.str`文件中添加自定义喊话内容：
```
speech_1>你想要的喊话文字
```

### 技术要点
1. **职业代码**：不同职业有不同的代码标识
2. **技能编号**：需要准确填写技能的内部编号
3. **显示时间**：通过数值控制喊话显示的持续时间
4. **适用范围**：除PKC模式外，其他游戏模式均有效果

### 注意事项
1. 确保技能编号与实际技能对应
2. 测试时注意在不同游戏模式下的效果差异
3. PKC模式下该效果可能无法正常显示
4. 喊话内容需要在字符串文件中正确定义

### 扩展应用
- 可以为不同技能设置不同的喊话效果
- 结合条件判断实现更复杂的触发逻辑
- 用于技能说明或角色扮演增强沉浸感

通过这种方法可以为技能释放增加丰富的视觉和听觉反馈，提升游戏体验。
