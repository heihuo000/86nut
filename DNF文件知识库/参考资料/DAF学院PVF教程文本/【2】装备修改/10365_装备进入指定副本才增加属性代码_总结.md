# 10365_装备进入指定副本才增加属性代码 - 内容总结

## 主要内容
本文档介绍了如何设置装备只有在特定副本中才能触发属性加成效果的方法。

## 详细信息

### 核心功能
实现装备在指定副本中才生效的属性加成机制，增加游戏策略性和趣味性。

### 实现代码

#### 1. 基本触发条件
```
[if]
[dungeon check]
101 102 103 104  副本代码
[/dungeon check]
[cooltime]
5000          冷却时间
[attack success]
1
[/if]
```

#### 2. 触发效果
```
[then]           触发的属性
[target]
`myself` -1
[restore]
`hp`
`%` 10 0
[restore]
`mp`
`%` 10 0
[/then]
```

#### 3. 副本特定加成
```
[if]
[dungeon check]
101 102 103 104
[/dungeon check]
[change status]
`hp`
`>`
`%` 0
`end`
[/if]
[then]
[target]
`myself` -1
[stat by condition]
`physical attack`
`%` 500
[stat by condition]
`magical attack`
`%` 500
[/then]
```

### 代码说明

#### 1. 副本检测代码
```
[dungeon check]
101 102 103 104  副本代码
[/dungeon check]
```
- `[dungeon check]`：副本检测标识
- `101 102 103 104`：副本代码列表（可添加多个）
- `[/dungeon check]`：结束标识

#### 2. 冷却时间设置
```
[cooltime]
5000
```
- 单位为毫秒，5000表示5秒冷却

#### 3. 攻击成功检测
```
[attack success]
1
```
- `1`表示攻击成功时触发

#### 4. 目标设置
```
[target]
`myself` -1
```
- `myself`：目标为自己
- `-1`：影响范围（-1表示全身）

#### 5. 属性恢复效果
```
[restore]
`hp`
`%` 10 0
```
- `hp`：恢复生命值
- `%`：按百分比恢复
- `10`：恢复10%
- `0`：未知参数

#### 6. 属性加成效果
```
[stat by condition]
`physical attack`
`%` 500
```
- `physical attack`：物理攻击力
- `%`：按百分比增加
- `500`：增加500%

### 技术要点

#### 1. 副本代码说明
常用副本代码：
- `101`：格蓝迪
- `102`：悲鸣洞穴
- `103`：疑惑之村
- `104`：王的遗迹

#### 2. 套装要求
- 必须写在套装装备上
- 单件装备使用会出现各种BUG
- 套装组件需要协同工作

#### 3. 触发条件组合
可与其他条件组合使用：
- `[attack success]`：攻击成功时
- `[hit]`：被攻击时
- `[cooltime]`：冷却时间检测
- `[change status]`：状态变化检测

### 应用场景
1. 创建副本专属装备
2. 实现地域性属性加成
3. 设计副本挑战奖励装备
4. 增强特定副本的游戏体验

### 注意事项
1. 确保副本代码正确无误
2. 合理设置冷却时间，避免过于频繁触发
3. 必须在套装装备上使用，单件装备会出错
4. 测试时注意观察触发条件是否符合预期

### 扩展应用
1. 结合多种副本实现复合效果
2. 创建副本进度奖励系统
3. 设计副本挑战成就装备
4. 实现副本差异化游戏机制

通过这种方法可以为装备添加副本专属属性，增强游戏的策略性和可玩性。
