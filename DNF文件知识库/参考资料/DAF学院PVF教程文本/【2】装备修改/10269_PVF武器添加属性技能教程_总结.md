# 10269_PVF武器添加属性技能教程 - 内容总结

## 主要内容
本文介绍了在PVF中为武器添加各种属性和技能的详细教程。

## 1. 添加武器特效（残影）
### 方法
- 用Notepad++打开解压的武器文件
- 在cool time参数后添加以下代码：
```
[spectrum]
50 20 200 200 500
```
- 这样可以实现类似传承武器的行走残影效果

## 2. 添加攻击属性
### 方法
- 在武器文件中添加[elemental property]标签
- 攻击属性示例：
  - '[water element]': 冰属性
  - '[dark element]': 暗属性
- 可以从其他带有属性的武器中查找更多属性类型

## 3. 添加攻击特效
### 方法
- 找到已有特效的武器（如血光摄魂刃的十字斩特效）
- 提取其特效代码并应用到目标武器
- 可以通过复制粘贴特效代码实现

## 4. 添加技能等级提升
### 方法
- 添加以下代码实现1-65级技能+1效果：
```
[all skill item]
[item growtype]
'[swordman]' 0
[skill apply condition]
[skill group]
'[all]'
[lower bound level]
1
[upper bound level]
65
[value]
1
[extra condition]
'[except for ex skill]'
```

## 重要说明
- 修改后需用修改器写入PVF文件
- 然后替换到客户端中
- 各特效和属性均可从现有装备中提取
