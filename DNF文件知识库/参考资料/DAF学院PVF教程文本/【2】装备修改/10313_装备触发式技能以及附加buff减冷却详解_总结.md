#### 1. 数字结尾代码格式
```
每逢添加数字结尾的代码按一下Tab键再写下一行。
```

#### 2. 吞代码问题解决
```
吞代码的原因就是如果它的规则判断你的数字后面没有空格就会认为你还有附加条件没写完，
会默认在你代码结尾加上``或者其他的符号，字母结尾的代码结尾则不需要添加空格，
之所以让你按Tab键没让你按空格键是因为这样代码写起来整齐好认。
```

#### 3. 代码格式规范
