# 10304_称号簿属性修改 - 内容总结

## 主要内容
本文档介绍了如何修改称号簿（Title Book）属性的方法。

## 详细信息

### 文件路径
```
etc/titlebook
```

### 修改方法

#### 1. 基本操作
- 可以任意修改现有属性的数值
- 可以增加或删除属性条目
- 使用文本编辑器打开文件进行修改

#### 2. 属性添加示例
以增加"所有异常状态抗性"属性为例：
```
[all activestatus resistance]
'+' 1888
```

将以上代码添加到文件末尾即可。

#### 3. 属性修改说明
- 使用加号（'+'）增加属性
- 使用减号（'-'）减少属性
- 数值可根据需要自由调整

### 技术要点

#### 1. 属性格式
```
[属性名称]
'运算符' 数值
```

#### 2. 常用运算符
- `'+'`：增加属性
- `'-'`：减少属性
- `'*'`：乘法运算
- `'/'`：除法运算
- `'%'`：百分比运算

#### 3. 属性类型
- 基础属性：力量、智力、体力、精神等
- 攻击属性：物理攻击、魔法攻击、独立攻击等
- 防御属性：物理防御、魔法防御等
- 特殊属性：暴击率、命中率、回避率等
- 抗性属性：各项异常状态抗性等

### 应用场景
1. 自定义称号簿属性组合
2. 增强称号簿的实用性
3. 创建特色称号簿满足特定需求
4. 平衡不同称号簿之间的属性差异

### 注意事项
1. 确保属性名称拼写正确
2. 合理设置属性数值，避免过于强大
3. 测试时注意观察属性变化效果
4. 备份原文件以防修改错误

### 扩展应用
1. 创建职业专属称号簿
2. 设计PVP/PVE专用称号簿
3. 实现称号簿属性的差异化配置
4. 结合其他系统实现复合效果

### 示例代码
```
// 增加力量属性
[physical attack]
'+' 50

// 增加所有异常状态抗性
[all activestatus resistance]
'+' 100

// 增加移动速度
[move speed]
'+' 20

// 增加攻击速度
[attack speed]
'+' 15
```

通过这种方法可以灵活定制称号簿的属性，为玩家提供更加个性化的游戏体验。
