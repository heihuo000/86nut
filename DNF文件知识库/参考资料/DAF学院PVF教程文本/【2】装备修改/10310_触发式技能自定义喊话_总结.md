# 10310_触发式技能自定义喊话 - 内容总结

## 主要内容
本文档介绍了如何为装备添加触发式技能释放时的自定义喊话效果。

## 详细信息

### 实现效果
当释放特定技能时，在屏幕上显示自定义的喊话文字。

### 核心代码
```
[if]
[event use skill]
`swordman`
86   
[/if]
[then]
[target]
`myself`
-1   
[speech on]
0   3000   <3::speech_25`死在我的剑下吧！啊哈哈哈！你这只辣鸡！`>
[/speech on]
[/then]
```

### 代码说明

#### 1. 技能触发条件
```
[if]
[event use skill]
`swordman`
86   
[/if]
```
- `[event use skill]`：技能使用事件
- `[swordman]`：鬼剑士职业
- `86`：技能编号（剑圣觉醒技能）

#### 2. 喊话效果设置
```
[speech on]
0   3000   <3::speech_25`死在我的剑下吧！啊哈哈哈！你这只辣鸡！`>
[/speech on]
```
- `0`：未知参数
- `3000`：显示持续时间（毫秒）
- `<3::speech_25`死在我的剑下吧！啊哈哈哈！你这只辣鸡！`>`：喊话内容

### 修改步骤

#### 1. 基本操作
1. 解压`equipment.kor`文件
2. 解压需要添加特效的装备文件
3. 复制触发代码到装备文件中
4. 保存并测试效果

#### 2. 触发方式自定义
- 攻击时几率触发
- 释放技能时触发
- 暴击时触发
- 可根据需要修改触发条件

#### 3. 喊话内容添加
1. 打开`equipment.kor`文件
2. 查找`speech_`字段
3. 按照格式添加自定义喊话内容

### 技术要点

#### 1. 触发条件设置
```
[event use skill] [职业] [技能编号]
[attack success] [概率]
[hit] [次数]
```

#### 2. 目标设置
```
[target]
`myself` -1  // 自身
`party` -1   // 队伍成员
`enemy` -1   // 敌人
`all enemy` 范围  // 所有敌人
```

#### 3. 喊话格式
```
<3::speech_编号`喊话内容`>
```

#### 4. 显示时间控制
```
[持续时间] [显示时间]
```

### 应用场景
1. 为觉醒技能添加个性化喊话
2. 创建角色扮演增强效果
3. 实现技能说明提示功能
4. 增加战斗过程的趣味性

### 注意事项
1. 确保技能编号与实际技能对应
2. 测试时注意观察喊话显示效果
3. 合理设置显示时间，避免影响游戏体验
4. 备份原文件以防修改错误

### 扩展应用
1. 为不同技能设置不同喊话内容
2. 结合条件判断实现动态喊话
3. 创建连击组合技的连续喊话
4. 实现根据战斗情况变化的智能喊话

### 使用技巧
1. 可以同时为多个技能添加喊话效果
2. 喊话内容可以包含特殊字符和表情符号
3. 通过修改持续时间控制喊话显示时长
4. 结合其他特效实现综合视觉效果

通过这种方法可以为技能释放增加丰富的文字效果，提升游戏的沉浸感和个性化程度。
