# 10271_传承的残影添加和颜色修改 - 内容总结

## 主要内容
本文档介绍了如何通过修改PVF来为武器添加残影效果以及修改残影颜色的方法。

## 详细信息

### 添加残影效果
通过在武器装备文件中添加以下代码来实现残影效果：
```
[spectrum]
255 0 0 200 500
```

### 修改残影颜色
通过修改代码中的RGB数值来改变残影颜色：
- 前三个数值代表RGB颜色值（红、绿、蓝）
- 可通过画图工具中的颜色编辑器获取目标颜色的RGB值
- 示例代码：
```
[spectrum avatar]
255 255 255 120 500 0
```

### 参数说明
- 前三个数值：颜色RGB值
- 第四个数值：残影产生间隔
- 第五个数值：残影残留时间

文中提供了多种颜色残影的效果图示例，包括红、橙、黄、绿、青、蓝、紫等颜色的残影效果。
