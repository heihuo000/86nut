# 10279_轮回几多忆乌山-装备篇 - 内容总结

## 主要内容
本文档系统介绍了DNF装备修改的相关知识，包括装备数据修改、属性攻击设置、技能属性调整等方面的内容。

## 详细信息

### 装备基础修改
1. **名称和描述修改**：
   - 文件位置：`equipment/equipment.kor.str`
   - 作用：修改装备显示名称和描述信息

2. **装备数据修改路径**：
   - 主目录：`equipment/character`
   - 职业分类：SWORDMAN（鬼剑士）
   - 装备类型：avatar（时装）、growtype（职业特征）、weapon（武器）
   - 武器分类：光剑、钝器、巨剑、太刀、短剑等

### 核心修改技术

#### 1. 属性攻击设置
```
[elemental property]
'[light element]'
```
支持的属性类型：
- 光属性：light
- 暗属性：dark
- 冰属性：water
- 火属性：fire

#### 2. 技能属性修改
- `[skill up]`：提升技能等级
- `[skill data up]`：修改技能相关属性（如GSD的究极波动刃无限觉醒效果）

#### 3. 附加伤害属性
```
[if]
[attack success]
1
[/if]
[then]
[target]
'enemy' -1
[add absolute damage]
'all' '%' 100
[/then]
```
实现附加100%伤害效果

#### 4. 特效添加
通过passiveobject实现各种特效：
- 施放技能时出现剑舞剑气
- 直接触发觉醒效果等

### 杂项修改技巧
1. **防止活动道具消失**：
   - 修改`[expiration date]`参数值为0
   - 防止重新登录后道具消失

2. **代码查找方法**：
   - 使用GM工具的国服/台服代码列表
   - 查阅script文件夹中的lst、string文件
   - 参考其他装备的写法进行修改

### 注意事项
- 修改时容易出错，建议做好备份
- 冰属性在代码中表示为water
- 每行代码后通常需要保留一个空格，否则可能出错
