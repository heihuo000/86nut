# 10358_攻击换装 - 内容总结

## 主要内容
本文档介绍了如何实现攻击时触发换装效果的技术方法。

## 详细信息

### 实现效果
当角色进行攻击时，触发装备外观的临时变换效果，包括武器、时装等外观的改变。

### 代码说明

#### 1. 触发条件设置
```
[if]
[use command]
1 
[cooltime]
20000 
[/if]
```
- `[use command] 1`：使用命令触发，命令代码为1
- `[cooltime] 20000`：冷却时间20秒（单位：毫秒）

#### 2. 效果设置
```
[then]
[target]
`myself`
-1 
[consume item]
3033 2 
[duration]
20000 
```
- `[target] `myself` -1`：目标为自己，范围为-1
- `[consume item] 3033 2`：消耗物品代码3033，数量2个
- `[duration] 20000`：效果持续时间20秒（单位：毫秒）

#### 3. 喊话效果
```
[speech on]
0 4000 `<3::speech_25`屠戮加連發，一套八萬八！！`>`
[/speech on]
```
- `[speech on]`：开启喊话效果
- `0 4000`：未知参数和显示时间（4秒）
- `<3::speech_25`屠戮加連發，一套八萬八！！`>`：喊话内容

#### 4. 特效对象
```
[passive object]
140076 0 0 0 -1 0 ``
[/passive object]
```
- `[passive object]`：被动对象特效
- `140076`：特效代码
- 其他参数：坐标、等级等设置

- 对应数字：新外观的代码

### 技术要点

#### 1. 触发方式
```
[use command] 1  // 命令触发
[attack success] 1  // 攻击成功触发

```

#### 2. 目标设置
```
[target]
`myself` -1  // 目标为自己，范围-1
```

#### 3. 消耗设置
```
[consume item]
3033 2  // 消耗物品代码和数量
```

#### 4. 持续时间
```
[duration]
20000  // 持续时间20秒（毫秒）
```

#### 5. 外观替换
```
[replace avatar ani]

```
