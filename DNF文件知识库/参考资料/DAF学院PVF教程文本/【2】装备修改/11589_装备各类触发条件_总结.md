# 11589_装备各类触发条件 - 内容总结

## 主要内容
本文档整理了DNF装备中各种触发条件的代码实现方法。

## 详细信息

### 触发条件分类

#### 1. 攻击成功触发
```
[if]
    [module]
        `[dungeon type]`
    [/module]
    [attack success effect animation]
        2
        `Common/Etc/Animation/chn_2014summer_normal.ani`    0    -160
        `Common/Etc/Animation/chn_2014summer_Linear Dodge.ani`    0    -160
    [attack success]
        1
    [cooltime]
        50000
[/if]
```

#### 2. 装备强化/增幅触发
```
[if]
    [equipment upgrade]
        `upgrade`
        `<`    1    0
        `amplify`
        `<`    1    0
    [/equipment upgrade]
    [change status]
        `hp`
        `>`
        `%`    0
        `end`
[/if]

[then]
    [target]
        `myself`    -1
    [stat]
        `attack speed`
        `+`    30
    [stat]
        `cast speed`
        `+`    30
    [stat]
        `move speed`
        `+`    30
    [stat]
        `light attack`
        `+`    10
    [stat]
        `fire attack`
        `+`    10
    [stat]
        `water attack`
        `+`    10
    [stat]
        `dark attack`
        `+`    10
[/then]
```

#### 3. 地下城环境触发
```
[if]
    [module]
        `[dungeon]`
    [/module]
    [attack success] 
        1
[/if]
```

地图类型代码：
- 普通地图：`dungeon`
- 地下城类型：`dungeon type`
- 锦标赛地图：`tournament dungeon`
- 死亡之塔系列地图：`dead tower`
- 战场类地图：`war room`
- 无尽的祭坛类：`blood system`
- 怪物攻城地图：`assault`
- 竞技场：`pvp`

#### 4. 敌人类型触发
```
[if]
    [target grade]
        `common`
    [attack success] 
        1
[/if]
```

敌人等级代码：
- 普通怪物：`common`
- 精英怪物：`champion`
- 深渊怪物：`named`
- 领主怪物：`boss`

#### 5. 敌人种族触发
```
[if]
    [target type]
        `beast`
    [attack success] 
        1
[/if]
```

敌人种族代码：
- 兽族：`beast`
- 植物族：`plant`
- 昆虫族：`insect`
- 不死族：`undead`
- 恶魔族：`devil`
- 精灵族：`spirit`
- 龙族：`dragon`
- 组合体：`hybrid`
- 人型：`human`
- 机械：`machine`
- 建筑：`fort armor`

### 技术要点

#### 1. 条件组合
多个条件可以组合使用，例如：
```
[if]
    [module]
        `[dungeon]`
    [/module]
    [attack success] 
        1
[/if]
```

#### 2. 模块检测
```
[module]
`[dungeon type]`
[/module]
```

#### 3. 冷却时间设置
```
[cooltime]
50000
```
单位为毫秒

#### 4. 攻击成功检测
```
[attack success]
1
```

### 应用场景
1. 创建环境感知型装备
2. 设计敌人类型专精装备
3. 实现副本专属属性加成
4. 开发种族克制类装备

### 注意事项
1. 确保触发条件代码拼写正确
2. 合理设置冷却时间避免过于频繁触发
3. 测试时注意观察不同环境下触发效果
4. 备份原文件以防修改错误

### 扩展应用
1. 结合多种触发条件实现复合效果
2. 创建动态属性变化装备
3. 设计自适应战斗环境装备
4. 实现智能化战斗辅助系统

通过这些触发条件可以为装备添加丰富的环境交互功能，提升游戏的策略性和可玩性。
