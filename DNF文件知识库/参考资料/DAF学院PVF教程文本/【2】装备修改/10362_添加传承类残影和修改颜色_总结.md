# 10362_添加传承类残影和修改颜色 - 内容总结

## 主要内容
本文档介绍了如何为装备添加传承类残影效果以及修改残影颜色的方法。

## 详细信息

### 残影效果实现

#### 1. 基本残影添加
在装备主文件中加入以下代码：
```
[spectrum]
255 0 0 200 500
```

#### 2. 代码参数说明
```
[spectrum]
R G B 间隔 持续时间
```
- `R`：红色分量（0-255）
- `G`：绿色分量（0-255）
- `B`：蓝色分量（0-255）
- `间隔`：残影产生间隔时间
- `持续时间`：残影残留时间

#### 3. 参数详解
- RGB值：0-255的整数，表示颜色分量
- 间隔：残影出现的时间间隔（单位：毫秒）
- 持续时间：残影在屏幕上的停留时间（单位：毫秒）

### 颜色修改方法

#### 1. 基本颜色修改
```
[spectrum]
255 0 0 200 500  // 红色残影
0 255 0 200 500  // 绿色残影
0 0 255 200 500  // 蓝色残影
255 255 255 200 500  // 白色残影
```

#### 2. 自定义颜色
通过RGB值组合实现任意颜色：
- 红色：255 0 0
- 绿色：0 255 0
- 蓝色：0 0 255
- 黄色：255 255 0
- 紫色：255 0 255
- 青色：0 255 255
- 白色：255 255 255
- 黑色：0 0 0

#### 3. 获取RGB值方法
使用Windows系统自带的画图工具：
1. 打开画图程序
2. 点击"编辑颜色"
3. 选择目标颜色
4. 查看左下角的RGB数值

### 时装和皮肤应用

#### 1. 时装残影添加
```
[spectrum avatar]
255 255 255 120 500 0
```

#### 2. 参数说明
```
[spectrum avatar]
R G B 间隔 持续时间 未知参数
```
- 前5个参数与装备残影相同
- 最后一个参数：未知用途，通常设为0

#### 3. 应用部位
可应用于以下时装部位：
- `[hat avatar]`：帽子
- `[hair avatar]`：头发
- `[face avatar]`：脸部
- `[breast avatar]`：胸部
- `[coat avatar]`：上衣
- `[pants avatar]`：下装
- `[waist avatar]`：腰带
- `[shoes avatar]`：鞋子

### 技术要点

#### 1. RGB颜色原理
- RGB色彩模式：通过红、绿、蓝三色光的不同强度混合产生各种颜色
- 数值范围：0-255，0表示无光，255表示最亮
- 颜色混合：R+G+B可产生1677万种颜色

#### 2. 时间参数设置
- 间隔：建议设置在100-500毫秒之间
- 持续时间：建议设置在300-1000毫秒之间
- 根据装备品质调整数值，史诗装备可设置更短间隔和更长持续时间

#### 3. 性能考虑
- 过多的残影效果可能影响游戏性能
- 建议合理控制残影密度和持续时间
- 高端装备可适当增加视觉效果

4. 备份原文件以防修改错误
