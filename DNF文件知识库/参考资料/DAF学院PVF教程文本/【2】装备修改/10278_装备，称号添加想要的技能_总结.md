# 10278_装备，称号添加想要的技能 - 内容总结

## 主要内容
本文详细介绍了如何给装备或称号添加技能的方法和步骤。

## 准备工具
1. Decrypt.exe - PVF专业工具
2. 台服物品代码
3. Notepad++ - 用于修改和定位文件

## 修改步骤

### 1. 环境准备
- 将Decrypt和PVF文件放在同一目录
- 解包后的文件目录结构应便于Decrypt直接写入PVF文件

### 2. 找到目标装备
- 确定要修改的装备
- 在代码中找到该装备的代码

### 3. 定位文件
- 使用Notepad++的文件查找功能(Ctrl+F)
- 搜索目录格式：解包路径\equipment\character\职业
- 通用装备在common目录下
- 按装备分类进一步细化(如ring、jacket等)

### 4. 添加技能代码
在定位的文件中，在icon之前插入技能代码：
```
[skill levelup]
'[职业]' 技能ID 等级
[/skill levelup]
```

### 代码解析
- [skill levelup]: 技能等级提升标签
- 职业: 如priest(圣职者)等
- 技能ID: 技能的代码
- 等级: 技能提升的等级

## 重要说明
- 可以给装备或称号添加想要的技能
- 需要先查找职业和技能代码
- 修改后需要用Decrypt写入到PVF文件中
