# 10354_称号时间限制消失 - 内容总结

## 主要内容
本文档介绍了如何通过修改PVF文件去除称号的时间限制，使其成为永久性称号。

## 详细信息

### 时间限制代码

#### 1. 使用期限限制代码
```
[usable period]
1 天数
```
- `[usable period]`：使用期限限制代码
- `1`：标识符（固定值）
- `天数`：限制使用的天数

#### 2. 到期时间限制代码
```
[expiration date]
1356966000 
```
- `[expiration date]`：到期时间限制代码
- `1356966000`：Unix时间戳格式的到期时间

### 代码说明

#### 1. [usable period] 参数
```
[usable period]
1 天数
```
- 作用：限制称号只能使用多少天
- 特点：相对时间限制（从获得称号开始计算）
- 示例：`[usable period] 1 30` 表示称号只能使用30天

#### 2. [expiration date] 参数
```
[expiration date]
1356966000
```
- 作用：设置称号的具体到期时间
- 特点：绝对时间限制（Unix时间戳格式）
- 示例：`[expiration date] 1356966000` 表示在该时间戳对应的时间到期

### 去除时间限制的方法

#### 1. 删除 [usable period] 代码段
```
// 删除以下代码段：
[usable period]
1 天数
```

#### 2. 删除 [expiration date] 代码段
```
// 删除以下代码段：
```

### Unix时间戳转换

#### 1. 时间戳含义
- Unix时间戳是从1970年1月1日00:00:00 UTC开始计算的秒数
- 例如：1356966000 对应 2012年12月31日 23:59:59

#### 2. 转换方法
- 在线转换工具：https://www.unixtimestamp.com/
- 编程转换：使用编程语言的时间函数进行转换
- 手动计算：根据基准时间进行加减计算
