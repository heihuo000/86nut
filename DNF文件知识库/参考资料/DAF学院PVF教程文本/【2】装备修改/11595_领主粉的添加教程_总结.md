# 11595_领主粉的添加教程 - 内容总结

## 主要内容
本文详细介绍了如何添加领主粉（史诗装备）到游戏中的方法。

## 核心配置文件

### 1. 装备词典
文件：etc/itemdictionary/(r)itemdictionary.etc
格式：代码 品级 最小等级 最大等级 0 副本掉落 0 0 0 0 0 0 `装备名称`
注意：品级需设为神器或领主神器，否则副本不会显示

### 2. 独立掉落
文件：etc/independent_drop.etc
掉落信息添加到[/independent drop]以上
注意：黄金哥布林掉落代码(61726)有异常，需要补全或跳过

### 3. 掉落权重
文件：etc/itemdictionary/(r)independentdropinfo.etc
格式：
```
[item table]
    100320618   （装备代码）
    [list]
        288     （指定怪物行数）
[/item table]

[monster table]
0    56735    0    0    1    1    1    1    0    `盜墓王`
```
怪物行数：从0开始计数

### 4. 副本名称
文件：etc/itemdictionary/(r)dungeon_name.etc
格式：0 怪物代码 最小等级 最高等级 未知 副本编号
怪物ID后的两个数字需写"0""0"，否则副本右上角没有小图标

## 重要说明
- 装备主文件可设定品级，但词典中需设为神器或领主神器
- 如需避免UI显示问题，可在词典中写两份：一份正常史诗品级，一份神器品级
- 可将材料也添加到副本UI显示
