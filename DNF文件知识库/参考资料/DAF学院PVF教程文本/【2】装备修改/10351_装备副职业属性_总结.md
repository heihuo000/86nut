# 10351_装备副职业属性 - 内容总结

## 主要内容
本文档介绍了如何为装备添加副职业属性，包括分解师、解体师和炼金师三种职业的属性加成。

## 详细信息

### 副职业系统概述
副职业系统允许玩家在主职业之外选择一项副职业，通过完成相关任务可以获得额外的属性加成。

### 三种副职业及其属性

#### 1. 分解师（doll_controller）
##### 等级要求：9级
##### 效果：5%机率获得物品数量2倍
```
[expertjob only]
'doll_controller' 9
[/expertjob only]
[prof result variation]
5 200
[possible kiri protect]
```

#### 2. 解体师（disjointer）
##### 等级要求：9级
##### 效果：5%机率获得物品数量增加10%
```
[expertjob only]
'disjointer' 9
[/expertjob only]
[prof disjoint result variation]
10
[possible kiri protect]
```

#### 3. 炼金师（alchemist）
##### 等级要求：9级
##### 效果：5%机率获得物品数量2倍
```
[expertjob only]
'alchemist' 9
[/expertjob only]
[prof result variation]
5 200
[possible kiri protect]
```

### 代码说明

#### 1. 副职业限定代码
```
[expertjob only]
'副职业代码' 等级要求
[/expertjob only]
```

#### 2. 属性效果代码
```
[prof result variation]
概率 倍数
```
或
```
[prof disjoint result variation]
增加百分比
```

#### 3. 保护代码
```
[possible kiri protect]
```

### 技术要点

#### 1. 副职业代码表
- 分解师：doll_controller
- 解体师：disjointer
- 炼金师：alchemist

#### 2. 属性数值设置
- 概率：以百分比形式表示（如5表示5%）
- 倍数：以整数形式表示（如200表示2倍）
- 增加百分比：以整数形式表示（如10表示增加10%）

#### 3. 等级要求
- 通常设置为9级（副职业满级）
- 可根据需要调整等级要求

### 应用场景
1. 制作副职业专属装备
2. 增强副职业玩家的游戏体验
3. 创建职业特色装备系统
4. 实现副职业属性加成装备

### 注意事项
1. 确保副职业代码拼写正确
2. 合理设置概率和倍数，避免游戏平衡性问题
3. 测试时注意观察属性加成效果
4. 备份原文件以防修改错误

### 扩展应用
1. 创建多副职业属性装备
2. 设计副职业等级递进加成
3. 结合其他属性实现复合效果
4. 开发副职业技能相关装备

通过这种方法可以为装备添加丰富的副职业属性，增强游戏的职业深度和玩法多样性。
