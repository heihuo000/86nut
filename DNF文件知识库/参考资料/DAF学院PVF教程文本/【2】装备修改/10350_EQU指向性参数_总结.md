### 技术要点

#### 1. 编号范围
- 1-25：武器分类
- 26-50：各职业外观分类
- 51-58：70大改后新增装备分类
- 1000-1012：物品种类分类

#### 2. 数据结构
```
编号  `参数名称`
```

#### 3. 应用方法
在equ文件中调用时，可以使用：
```
[part set index]
编号
```

或者在其他需要装备分类判断的地方使用对应参数名称。

### 应用实例

#### 1. 装备分类设置
```
[part set index]
25  // 镰刀
```

#### 2. 职业装备适配
```
[usable job]
'[swordman]'  // 适用于鬼剑士
[/usable job]
```

#### 3. 物品类型判断
```
[item group name]
`food`  // 食物类型
```

### 注意事项
1. 确保参数编号与实际装备类型匹配
2. 注意区分相似装备类型的编号差异
3. 新增装备类型需遵循现有编号规则
4. 修改参数时注意维护编号的一致性
