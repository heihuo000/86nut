# 11591_关于武器装扮不显示强化特效的解决办法 - 内容总结

## 主要内容
本文档介绍了如何解决武器装扮不显示强化特效的问题。

## 详细信息

### 问题描述
在使用武器装扮时，强化特效可能不会正常显示，需要通过调整图层优先级来解决。

### 解决方法

#### 1. 调整图层优先级
在武器装扮文件中将图层优先数值调低：
```
图层优先级降低，比如武器图层651，装扮要用650
```

#### 2. 具体操作步骤
1. 打开武器装扮文件
2. 找到图层优先级设置
3. 将数值调低以确保强化特效正常显示

### 技术要点

#### 1. 图层优先级说明
```
图层优先级降低，比如武器图层651，装扮要用650
```
- 数值越小，图层越靠前显示
- 武器图层：651
- 装扮图层：650（应小于武器图层）

#### 2. 装扮文件路径
```
sprite/character/mage/equipment/weapon/spear/mg_spear6300d.img
```
- 各职业武器装扮路径不同
- 需要根据具体职业调整路径

#### 3. 图层设置参数
```
[layer variation]
2790 `broomc`
[equipment ani script]
`equipment/character/mage.lay`

[layer variation]
650 `broomd`
[equipment ani script]
`equipment/character/mage.lay`
```
- `[layer variation]`：图层变化设置
- `2790`：贴图算法
- `broomc`：对应装备动画文件所在的文件夹
- `[equipment ani script]`：装备动画脚本路径

### 注意事项

#### 1. 数值调整范围
- 不要调得过低以免武器被手和时装挡住
- 可以只调剑身不调剑柄
- 建议逐步调整测试效果

#### 2. 装扮部位选择
```
第二个调低了 时装会挡住武器
```
- 需要合理选择调整的装扮部位
- 避免调整后被其他装备遮挡

#### 3. 职业差异
不同职业的武器装扮路径和代码可能不同：
- 鬼剑士：swordman
- 神枪手：gunner
- 格斗家：fighter
- 魔法师：mage
- 圣职者：priest
- 暗夜使者：thief
- 缔造者：creator
