# 11590_装备各类触发内容 - 内容总结

## 主要内容
本文档整理了DNF装备中各种触发内容的代码实现方法。

## 详细信息

### 触发内容分类

#### 1. 消耗品触发
```
[then]
    [target]
        `myself`    -1
    [consume item]
        3037    1
    [speech on]
        0    2000
        `好吃……哈哈~吃飽后就充滿了力量！`
    [/speech on]
[/then]
```

#### 2. 召唤怪物触发
```
[then]
    [target]
        `myself`    -1
    [summon monster]
    56123    -1    90000    1
[/then]
```

#### 3. 召唤APC触发
```
[then]
    [target]
        `myself`    -1
    [summon apc]
    11128    -1    90000    1
[/then]
```

#### 4. Buff状态触发
```
[then]
    [target]
        `myself`    -1
    [probability]
        30
    [duration]
        5000
    [buff]
        `superarmor`
[/then]
```

常用Buff状态代码：
- 霸体：`superarmor`
- 无敌：`unbreakable`
- 伪装：`camoflage`

#### 5. 元素武器触发
```
[then]
    [target]
        `party`    500
    [duration]
        20000
    [elemental weapon]
        `light`
[/then]
```

#### 6. 团队光环触发
```
[aura active]
`physical attack`    `+`    45    300
```

#### 7. 加速状态触发
```
[active status]
    'haste' 40 16 16
第一个数值：加速Lv：Lv40
第二个数值：攻击速度增加：16%
第三个数值：移动速度增加：16%
```

#### 8. 减速状态触发
```
[active status]
    `slow` 55 14 14 
第一个数值：加速Lv：Lv55
第二个数值：移动速度减少：14%
第三个数值：攻击速度减少：14%
```

#### 9. 祝福状态触发
```
[active status]
    `bless` 22 13 13 13 13 
第一个数值：加速Lv：Lv22
第二个数值：力量增加：13
第三个数值：体力增加：13
第四个数值：智力增加：13
第五个数值：精神增加：13
```

### 代码说明

#### 1. 消耗物品代码
```
[consume item]
    3037    1
```
- `3037`：物品代码（无色小晶块）
- `1`：消耗数量

#### 2. 喊话代码
```
[speech on]
    0    2000
    `喊话内容`
[/speech on]
```
- `0`：未知参数
- `2000`：显示时间（毫秒）
- `喊话内容`：显示文字

#### 3. 召唤怪物代码
```
[summon monster]
56123    -1    90000    1
```
- `56123`：怪物代码
- `-1`：怪物等级（-1表示与玩家等级相同）
- `90000`：持续时间（毫秒）
- `1`：召唤数量

#### 4. 召唤APC代码
```
[summon apc]
11128    -1    90000    1
```
- `11128`：APC代码
- `-1`：APC等级（-1表示与玩家等级相同）
- `90000`：持续时间（毫秒）
- `1`：召唤数量

#### 5. 概率设置代码
```
[probability]
    30
```
- `30`：触发概率（30%）

#### 6. 持续时间代码
```
[duration]
    5000
```
- `5000`：持续时间（毫秒）

#### 7. Buff状态代码
```
[buff]
    `superarmor`
```
- `superarmor`：霸体状态

#### 8. 团队光环代码
```
[aura active]
`physical attack`    `+`    45    300
```
- `physical attack`：物理攻击力
- `+`：增加
- `45`：增加数值
- `300`：影响范围（像素）

### 技术要点

#### 1. 目标设置
```
[target]
    `myself`    -1
```
- `myself`：自己
- `-1`：影响范围

#### 2. 团队目标
```
[target]
    `party`    500
```
- `party`：队伍成员
- `500`：影响范围（像素）

#### 3. 敌人目标
```
[target]
    `enemy`    -1
```
- `enemy`：敌人
- `-1`：影响范围

#### 4. 所有敌人目标
```
[target]
    `all enemy`    300
```
- `all enemy`：所有敌人
- `300`：影响范围（像素）

### 应用场景
1. 创建消耗品触发类装备
2. 设计召唤类技能装备
3. 实现状态增益装备
4. 开发团队辅助型装备

2. 合理设置触发概率和持续时间
3. 测试时注意观察各种触发效果
4. 备份原文件以防修改错误

1. 结合多种触发内容实现复合效果
2. 创建动态属性变化装备

4. 实现智能化装备效果
