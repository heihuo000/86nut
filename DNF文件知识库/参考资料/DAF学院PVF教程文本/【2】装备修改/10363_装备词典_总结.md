# 10363_装备词典 - 内容总结

## 主要内容
本文档介绍了DNF中装备词典文件的结构和修改方法。

## 详细信息

### 装备词典文件信息

#### 1. 文件路径
```
etc/itemdictionary/(r)itemdictionary.etc
```

#### 2. 文件格式
使用PVFUtility2018版，竖向格式！

### 装备词典数据结构

#### 1. 基本格式
```
装备代码    品级    最小等级    最大等级    0    副本掉落    0    0    0    0    0    `装备名称`
```

#### 2. 参数说明
- `装备代码`：装备的唯一标识码
- `品级`：装备稀有度等级
  - 0：普通级
  - 1：蓝色级
  - 2：紫色级
  - 3：粉色级
  - 4：史诗级
  - 5：勇者级
- `最小等级`：装备可穿戴的最低等级
- `最大等级`：装备可穿戴的最高等级
- `0`：未知参数（固定为0）
- `副本掉落`：副本掉落标识
  - 0：非副本掉落
  - 1：副本掉落
- 后续的多个`0`：其他未知参数
- `装备名称`：装备显示名称

```

`盜墓王的彌留之戒`  // 装备名称
```

### 品级说明

#### 1. 稀有度等级
```
0：普通级（白装）
1：蓝色级（蓝装）
2：紫色级（紫装）
3：粉色级（粉装）
4：史诗级（史诗）
5：勇者级（勇者）
```

#### 2. 副本掉落标识
```
0：非副本掉落（普通掉落、商店购买等）
1：副本掉落（地下城、深渊等）
```

### 技术要点

#### 1. 品级设置注意事项
```
备注：这里的品级的选择神器或者领主神器不然副本不会显示，
（装备主文件可以自己设定你设定他是史诗品级副本UI显示的就是史诗品级，
你设定他是异界品级它显示的就是异界品级）
```

#### 2. 副本显示问题
```
这个属于弟弟玩法这样做的话如果你设定副本UI显示为史诗品级，
但是词典文件那里必须为神器或者领主神器就会造成词典里面神器或者领主神器里面出现史诗！！！！
```

#### 3. 解决方法
```
解决方法：你词典里里面可以写两份一份正常史诗品级，
一份神器品级然后写进冷门职业的武器类型，
列如盗贼的双剑之类的一般的人也不会去翻那种职业的词典
```

### 独立掉落设置

#### 1. 文件路径
```
etc/independent_drop.etc
```

#### 2. 添加位置
```
掉落信息添加到[/independent drop]以上，
最后一排黄金哥布林掉落代码有异常，补全它不然不掉粉，
或是跳过它，在黄金哥布林代码"61726"的掉落以上加入独立掉落信息。
```

### 掉落权重设置

#### 1. 文件路径
```
etc/itemdictionary/(r)independentdropinfo.etc
```

#### 2. 添加位置
```
掉落权重加到[/item table]之前，
最下面[/monster table]前要加怪物列表。
```

#### 3. 示例代码
```
[item table]
    100320618   （装备代码）
    [list]
        288     （指定怪物行数）下面讲解
[/item table]

[monster table]
0    56735    0    0    1    1    1    1    0    `盜墓王`

（0 怪物  1 APC）    怪物代码    最小等级    最高等级    
普通级别掉落    冒险级别掉落    王者级别掉落    地狱级别掉落    
未知    `盜墓王`
[/monster table]
```

### 副本UI显示设置

#### 1. 文件路径
```
etc/itemdictionary/(r)dungeon_name.etc
```

#### 2. 设置方法
```
"020011"，怪物ID"2"后面两个数字要写"0""0"
不然副本提示右上角没有小图标。
```

#### 3. 示例代码
```
[dungeon name]
    0    1072    0    0    1    171

    （0 怪物  1 APC）    怪物代码    应该是最小等级    最高等级    
    未知    副本编号
[/dungeon name]
```

### 应用场景
1. 自定义装备在词典中的显示
2. 设置装备的副本掉落标识
3. 调整装备的稀有度等级显示
4. 控制装备在不同职业词典中的出现位置

### 注意事项
1. 确保装备代码与实际装备文件对应
2. 合理设置品级和等级范围
3. 注意副本掉落标识与实际掉落方式匹配
4. 备份原文件以防修改错误

### 扩展应用
1. 创建自定义装备词典系统
2. 实现装备分类管理
3. 设计职业专属装备词典
4. 开发装备查询功能

通过修改装备词典文件可以灵活控制装备在游戏中的显示和分类，为装备系统管理提供便利。
