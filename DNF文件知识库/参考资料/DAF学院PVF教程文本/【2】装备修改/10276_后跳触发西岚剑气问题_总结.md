# 10276_后跳触发西岚剑气问题 - 内容总结

## 主要内容
本文档介绍了如何解决后跳触发西岚剑气时剑气不会移动的问题，通过修改PTL文件实现剑气的正常移动效果。

## 详细信息

### 问题描述
在修改后跳触发西岚剑气时，虽然能够成功触发剑气特效（代码20065），但剑气不会移动，停留在原地。

### 解决方案
1. **关键发现**：通过研究西岚技能代码，发现在key文件夹中存在特效配置文件（.key文件）
2. **技术要点**：
   - 剑气代码：20065
   - PTL文件：控制特效移动的关键文件
   - 关键文件位置：key/quadruple_backstepcutter.key

### 实现步骤
1. 研究西岚技能代码，找到关键的.key文件
2. 发现剑气代码20065需要配合PTL文件才能正常移动
3. 由于equipment\character\particle目录下缺少grandwave.ptl文件，直接添加会报错
4. 采用替换现有PTL文件的方法：
   - 使用光炎剑的PTL文件（DragonHeadEnergyBall.ptl）替换内容
   - 修改代码为：`20065 0 0 0 0 0 'DragonHeadEnergyBall.ptl'`

### 技术原理
- 剑气特效不仅需要代码触发，还需要PTL文件控制移动轨迹
- 通过替换现有PTL文件内容实现剑气移动效果
- 可以举一反三应用到其他技能（如阿甘左等）

这种方法能够有效解决剑气特效不会移动的问题，提升视觉效果和游戏体验。
