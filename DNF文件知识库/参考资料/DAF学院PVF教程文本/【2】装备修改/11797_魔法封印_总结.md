# 11797_魔法封印 - 内容总结

## 主要内容
本文档介绍了如何为装备添加魔法封印属性的方法。

## 详细信息

### 魔法封印功能

#### 1. 基本实现方法
在装备文件中添加以下代码：
```
[random option]
1
[Force Result Item Rule]
1 0
 
etc/randomoption/optiontext.etc
```

#### 2. 代码说明
```
[random option]
1
```
- `[random option]`：随机选项标识
- `1`：启用魔法封印功能

```
[Force Result Item Rule]
1 0
```
- `[Force Result Item Rule]`：强制结果物品规则
- `1`：规则代码
- `0`：未知参数

```
etc/randomoption/optiontext.etc
```
- 魔法封印文本文件路径

### 实现步骤

#### 1. 添加魔法封印代码
在装备文件中添加：
```
[random option]
1
[Force Result Item Rule]
1 0
 
etc/randomoption/optiontext.etc
```

#### 2. 删除魔法封印
删除以下代码即可取消魔法封印：
```
[random option]
1
```

### 技术要点

#### 1. 文件路径
```
etc/randomoption/options/randomoptions_15_physicalattack.etc
```
- 魔法封印选项文件路径
- `15_physicalattack`：物理攻击类型封印
- 可根据需要修改为其他类型

#### 2. 代码格式
```
#PVF_File

[name]
    `randomoptions_15_physicalattack`

[basic explain]
    `[randomoptions_15_physicalattack]`

[grade]
    15

[rarity]
    4

[part set index]
    15

[usable job]
    `[all]`
[/usable job]

[attach type]
    `[trade]`

[minimum level]
    1

[icon]
    `Item/common/randomoption.img`    15

[equipment type]
    `[random option]`  15

[animation job]
    `[all]`

[variation]
    15   0

[layer variation]
    2790 `randomoptionc`

[equipment ani script]
    `equipment/character/all.lay`

[layer variation]
    650 `randomoptionb`

[equipment ani script]
    `equipment/character/all.lay`

[/animation job]

[animation job]
    `[at fighter]`

[variation]
    15   0

[layer variation]
    2790 `randomoptionc`

[equipment ani script]
    `equipment/character/atfighter.lay`

[layer variation]
    650 `randomoptionb`

[equipment ani script]
    `equipment/character/atfighter.lay`

[/animation job]
```

#### 3. 参数说明
- `[grade]`：等级（15）
- `[rarity]`：稀有度（4）
- `[part set index]`：部件套装索引（15）
- `[usable job]`：可用职业（`[all]`表示所有职业）
- `[attach type]`：交易类型（`[trade]`表示可交易）
- `[minimum level]`：最低使用等级（1级）
- `[icon]`：图标路径和帧号
- `[equipment type]`：装备类型（`[random option]`表示随机选项）
- `[animation job]`：动画职业（`[all]`表示所有职业）
- `[variation]`：变化参数
- `[layer variation]`：图层变化参数
- `[equipment ani script]`：装备动画脚本路径
