# 10292_装备添加增加EX技能 by 骷髅兔兔子 - 内容总结

## 主要内容
本文档介绍了如何通过修改装备代码使装备能够增加EX技能等级，突破原有代码的限制。

## 详细信息

### 原始代码（所有技能+58级）
```
[all skill item]

[item growtype]
'[all]' 0
[skill apply condition]

[skill group]
'[all]'
[lower bound level]
1
[upper bound level]
70
[value]
58
[extra condition]
'[except for ex skill]'
[/extra condition]

[/skill apply condition]

[skill phase]
'[all]'
[/all skill item]
```

### 核心问题
原始代码中包含以下限制代码：
```
[extra condition]
'[except for ex skill]'
[/extra condition]
```
这段代码的作用是排除EX技能，使得装备只能增加普通技能等级，无法增加EX技能等级。

### 解决方案
删除以下代码段：
```
[extra condition]
'[except for ex skill]'
[/extra condition]
```

### 修改后效果
删除限制代码后，装备将能够同时增加：
1. 普通技能等级
2. EX技能等级

### 技术说明
- `[all skill item]`：作用于所有技能的物品
- `[item growtype]`：物品成长类型
- `[skill apply condition]`：技能应用条件
- `[skill group]`：技能组（'[all]'表示所有技能）
- `[lower bound level]`：等级下限
- `[upper bound level]`：等级上限
- `[value]`：增加的等级值
- `[skill phase]`：技能阶段

### 使用方法
1. 在装备文件中添加修改后的代码
2. 确保删除了`[extra condition]`限制段
3. 调整`[value]`参数来设置增加的技能等级
4. 保存文件并在游戏中测试效果

### 注意事项
- 删除限制代码后，装备将同时影响普通技能和EX技能
- 需要合理设置技能等级加成数值，避免游戏平衡性问题
- 修改前建议备份原文件
- 测试时注意观察是否对游戏稳定性造成影响

通过这种方法可以制作出真正全方位提升技能等级的装备，包括EX技能在内的所有技能都能获得等级加成。
