# 10300_锻造上限+10_不会失败_爆率修改教程 - 内容总结

## 主要内容
本文档介绍了如何修改装备锻造上限、成功率以及物品爆率的方法。

## 详细信息

### 锻造上限和成功率修改

#### 文件位置
```
etc/upgrade_separate.etc
```

#### 修改效果
- 锻造上限可达+10
- 锻造成功率可达100%

### 爆率修改

#### 相关文件
1. `etc/itemdropinfo_clearreward.etc` - 翻牌爆率
2. `etc/itemdropinfo_monseter.etc` - 白图爆率
3. `etc/itemdropinfo_monseter_extra.etc` - 白图额外爆率
4. `etc/itemdropinfo_monster_hell.etc` - 深渊爆率

#### 爆率计算原理
采用随机数区间计算方法：

##### 默认爆率示例（台服官方翻牌）
```
[basis of rarity dicision]
800000 989900 999900 1000000 1000001 1000002
```

- 0~800000：白装（80%）
- 800000~989900：蓝装（约18.99%）
- 989900~999900：紫装（约1%）
- 999900~1000000：粉装（约0.01%，万分之一）
- 1000000~1000001：史诗装（理论上出但实际不出）
- 1000001~1000002：其他

##### 粉装爆出概率计算
```
(1000000 - 999900) / 1000002 ≈ 0.00999%（约万分之一）
```

### 自定义爆率设置

#### 均等概率设置（1:1:1:1:1）
```
[basis of rarity dicision]
200000 400000 600000 800000 1000001 1000002
```

各品质装备爆出概率均为20%。

### 技术要点

#### 计算方法
1. 服务器生成0~最大值之间的随机整数
2. 根据数值所在区间判断爆出物品品质
3. 区间范围决定各品质爆出概率

#### 参数说明
- 第一个数值：白装上限
- 第二个数值：蓝装上限
- 第三个数值：紫装上限
- 第四个数值：粉装上限
- 第五个数值：史诗装上限
- 第六个数值：其他上限
