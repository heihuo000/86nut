# 10272_武器属性跟随人物等级提高而提高 - 内容总结

## 主要内容
本文档介绍了如何设置武器属性使其随着角色等级提升而增长，类似于成长型武器的实现方法。

## 详细信息

### 实现方法
在武器装备文件中添加以下代码段：
```
[level linear ability]
1 70
[grade]
5 71
[repair price]
6700 100000
[equipment physical attack]
103 65 1309 749
[equipment magical attack]
97 61 1307 562
[separate attack]
56 32 401 272
[physical attack]
8 47
[magical attack]
0 0
[/level linear ability]
```

### 使用说明
1. 需要删除武器原有的固定属性
2. 将上述代码添加到`cooltime10000`之后
3. 代码中的数值代表不同等级时的属性表现
4. 通过这种方式可以让武器属性随角色等级线性增长

这种方法可以让武器在玩家升级过程中持续变强，提供更好的游戏体验。
