# 10307_减少所有技能冷却时间 - 内容总结

## 主要内容
本文提供了减少所有技能冷却时间的代码，可以实现装备上附加减CD效果。

## 第一种方法
### 代码实现
```
[if]
[time]
300013000
[/if]

[then]
[target]
`party`
-1
[duration]
90000
[probability]
100
[stat]
`skill cool time`
`%`
-100
[/then]
```

### 功能说明
- 装备3秒后所有技能冷却时间减100%（即无冷却）
- 持续时间为90000毫秒（90秒）
- 触发概率为100%
- 对全队生效（party）

## 第二种方法
### 代码实现
```
[if]
[change status]
'hp' '>=' '%' 0 'end'
[/if]
[then]
[target]
'myself' -1
[stat by condition]
'skill cool time' '%' -100
[/then]
```

### 功能说明
- 基于HP状态的条件触发
- 对自己生效
- 同样减少100%技能冷却时间

## 重要说明
- 两种方法都实测可用，可加在任何装备上
- 可以修改时间参数和减CD百分比来调整效果
- 第一种方法由360972089提供，第二种方法由氢氧化肥提供
