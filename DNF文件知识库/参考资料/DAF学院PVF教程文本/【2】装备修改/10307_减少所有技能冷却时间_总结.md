# 10307_减少所有技能冷却时间 - 内容总结

## 主要内容
本文档介绍了两种减少所有技能冷却时间的方法，可以实现技能冷却时间减少100%的效果。

## 详细信息

### 方法一：时间触发减CD

#### 核心代码
```
[if]
[time]
300013000
[/if]
[then]
[target]
`party`
-1
[duration]
90000
[probability]
100
[stat]
`skill cool time`
`%`
-100
[/then]
```

#### 代码说明
- `[time] 300013000`：时间触发条件
- `[target] `party` -1`：目标为队伍成员，范围-1
- `[duration] 90000`：效果持续时间90秒
- `[probability] 100`：触发概率100%
- `[stat] `skill cool time` `%` -100`：技能冷却时间减少100%

#### 实现效果
装备3秒后所有技能冷却时间减少100%。

### 方法二：状态检测减CD

#### 核心代码
```
[if]
[change status]
'hp' '>=' '%' 0 'end'
[/if]
[then]
[target]
'myself' -1
[stat by condition]
'skill cool time' '%' -100
[/then]
```

#### 代码说明
- `[change status] 'hp' '>=' '%' 0 'end'`：当HP大于等于0%时触发
- `[target] 'myself' -1`：目标为自己，范围-1
- `[stat by condition] 'skill cool time' '%' -100`：技能冷却时间减少100%

### 技术要点

#### 1. 时间控制
- 可以自定义触发时间和效果持续时间
- 通过`[time]`和`[duration]`参数控制时机

#### 2. 目标选择
- `myself`：自己
- `party`：队伍成员
- `all enemy`：所有敌人
- `enemy near`：附近敌人

#### 3. 数值设置
- 使用`%`表示百分比减少
- `-100`表示减少100%冷却时间
- 可根据需要调整数值大小
