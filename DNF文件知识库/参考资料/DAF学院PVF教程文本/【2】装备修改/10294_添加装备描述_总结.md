# 10294_添加装备描述 - 内容总结

## 主要内容
本文介绍了如何为装备添加描述文字（白色字体描述）的方法。

## 修改步骤

### 1. 修改装备文件
- 使用SuperPVF打开装备文件
- 在grade参数前添加以下代码：
```
[@05][flavor text]
[@09]3
[@0A]flavor_text_100090009 （数字为物品代码）
```

### 2. 修改文本描述
- 用Notepad++打开equipment.kor.str文件
- 用物品代码查找对应的装备描述
- 在装备描述下方添加：
```
flavor_text_100090009>你想要的文字
```

## 功能说明
- 此功能为没有白色描述文字的装备增加描述
- 添加的白色文字会显示在装备信息底部
- 需要修改完后编译明文并更新封包

## 用途
- 为自定义装备添加特殊说明
- 增加装备背景故事或特殊效果说明
- 完善装备信息显示
