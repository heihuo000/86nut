# 10294_添加装备描述 - 内容总结

## 主要内容
本文档介绍了如何为装备添加描述文字（白字属性）的方法。

## 详细信息

### 实现步骤

#### 1. 添加装备描述代码
在装备文件的`[grade]`属性前添加以下代码：
```
[@05][flavor text]
[@09]3
[@0A]flavor_text_100090009 （数字为物品代码）
```

#### 2. 编译和更新
- 修改完成后直接编译明文
- 更新封包文件

#### 3. 添加描述内容
使用Notepad++打开`equipment.kor.str`文件：
- 使用物品代码直接查找装备描述
- 在装备描述下方添加：
```
flavor_text_100090009>你想要的文字
```

### 适用场景
此方法专门用于为原本没有描述文字的装备添加白字属性描述，丰富装备信息展示。

### 技术要点
1. **代码位置**：描述代码必须添加在`[grade]`属性之前
2. **物品代码**：需要使用装备的实际物品代码
3. **文件格式**：
   - PVF文件使用SuperPVF工具修改
   - STR文件使用Notepad++编辑
4. **描述格式**：
   - 使用`flavor_text_`前缀加物品代码作为标识
   - 描述文字可自定义

### 注意事项
1. 确保物品代码与装备实际代码一致
2. 修改后需要正确编译和封包
3. 备份原文件以防修改错误
4. 测试时注意检查描述是否正常显示

通过这种方法可以为任何缺少描述文字的装备添加详细的属性说明，提升用户体验。
