# 11615_【模板】打开后礼盒多个道具选择其中一个 - 内容总结

## 主要内容
本文提供了一个礼盒自选模板，玩家打开礼盒后可以从多个道具中选择其中一个。

## 模板结构

### 基础信息
```
#PVF_File

[name]
 `礼盒自选模板`

[explain]
 `礼盒蓝字描述`

[flavor text]
 `礼盒下方灰字秒速`

[grade]
 1

[attach type]
 `[account]`

[rarity]
 4

[usable job]
 `[all]`
[/usable job]

[minimum level]
 1

[icon]
 `Item/stackable/consumption_cn.img` 1385
```

### 核心配置
```
[stackable type]
 `[booster selection]` 0

[booster category num]
 0

[booster selection num]
 1
 //这里控制礼盒选择数量

[booster select category]
 0 0 
 [stackable]
  20190533 1
  20190534 1
  20190535 1
  //代码 数量（顺序往下写即可）
 [/stackable]
[/booster select category]

[move wav]
 `BONE_TOUCH`
```

## 参数说明

### 基础属性
- [name]: 礼盒名称显示
- [explain]: 蓝字描述信息
- [flavor text]: 灰字说明文字
- [grade]: 礼盒等级
- [attach type]: 交易类型（[account]表示账号绑定）
- [rarity]: 稀有度（4为史诗）
- [usable job]: 适用职业（[all]表示所有职业）
- [minimum level]: 最低使用等级
- [icon]: 图标路径和编号

### 核心功能
- [stackable type]: `[booster selection]`表示自选类型
- [booster selection num]: 控制可选择道具数量（示例为1个）
- [booster select category]: 自选分类配置
- [stackable]: 可选道具列表（道具代码 数量）

## 使用方法
1. 复制模板代码
2. 修改礼盒名称和描述
3. 设置图标路径和编号
4. 在[stackable]部分添加可选道具代码和数量
5. 调整[booster selection num]控制选择数量

## 应用场景
- 节日活动礼盒
- 职业自选礼包
- 时装自选礼盒
- 装备自选宝箱
- 宠物自选礼包

## 重要说明
- 可以添加任意数量的可选道具
- 道具代码和数量按顺序排列
- 选择数量通过[booster selection num]控制
- 礼盒使用后不消失（除非特别设置）
