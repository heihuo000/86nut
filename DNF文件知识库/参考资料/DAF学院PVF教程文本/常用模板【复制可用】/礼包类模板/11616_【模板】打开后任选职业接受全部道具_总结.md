# 11616_【模板】打开后任选职业接受全部道具 - 内容总结

## 主要内容
本文提供了一个职业自选礼盒模板，玩家打开礼盒后可以选择职业并获得对应的所有道具。

## 模板结构

### 基础信息
```
#PVF_File

[name]
 `装扮自选礼盒`

[explain]
 `蓝字描述`

[flavor text]
 `灰字描述`

[grade]
 1

[rarity]
 2

[usable job]
 `[all]`
[/usable job]

[attach type]
 `[trade]`

[minimum level]
 1

[icon]
 `item/avatar/swordman/sm_acap.img` 578

[stackable type]
 `[booster selection]` 0

[move wav]
 `BONE_TOUCH`
```

### 职业配置
```
[booster category num]
 1 9
//（里面放置的职业道具的数量，五个职业就是1-5，6个职业就1-6，9个职业就是1-9，别瞎写）

[booster selection num]
 0
// 如果想要在其中选择一个 请把这里 0 改为 1 即可实现选择一个获取！

[booster select category]
```

## 参数说明

### 基础属性
- [name]: 礼盒名称
- [explain]: 蓝字描述
- [flavor text]: 灰字说明
- [grade]: 等级
- [rarity]: 稀有度
- [usable job]: 适用职业
- [attach type]: 交易类型
- [minimum level]: 最低等级
- [icon]: 图标路径和编号

### 核心功能
- [booster category num]: 职业数量配置（1 9表示1个分类，9个职业）
- [booster selection num]: 选择数量（0表示全部获取，1表示选择一个）
- [booster select category]: 各职业道具配置
- [avatar]: 具体道具（道具代码 数量 类型等）
- [booster category name]: 分类名称（第一个为总标题，后面为各职业名称）

## 使用方法
1. 复制模板代码
2. 修改礼盒名称和描述
3. 设置图标路径和编号
4. 根据需要的职业数量调整[booster category num]
5. 添加各职业的道具配置
6. 设置[booster selection num]控制选择方式（0为全选，1为单选）
7. 配置职业名称列表

## 应用场景
- 职业自选装扮礼盒
- 节日活动职业礼包
- 新手职业体验包
- 转职庆祝礼包

## 重要说明
- 职业数量要与实际配置匹配
- 道具代码需要准确无误
- 选择数量通过[booster selection num]控制
- 职业名称列表要与配置一一对应

## 注意事项
- 注意职业编号的正确性
- 确保道具代码有效
- 测试不同职业的选择效果
- 验证获得道具的正确性
