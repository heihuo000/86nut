# 12078_游戏设置缺少开启扩展技能栏或技能栏上不显示快捷键名解决方法 - 内容总结

## 主要内容
本文提供了修复游戏设置中缺少开启扩展技能栏或技能栏上不显示快捷键名问题的解决方法。

## 问题现象
- 游戏设置中缺少开启扩展技能栏选项
- 技能栏上不显示快捷键名称
- 影响玩家游戏操作体验

## 解决方案

### 文件路径
```
ui/optionwindow/optionsystem.ui
```

### 修复方法
直接复制以下内容替换该文件中的原有内容：

### 核心配置代码
```
#PVF_File

[ui controls]
  `[board image]`
  `1003`  -6   0   1
  `Interface/WindowCommon.img`   11   216   209   213   214   215   216   217   218   219   220   221
[/ui controls]

[ui controls]
  `[stick vscroll]`
  `500`  -11   2   0   2   -2   0   
  [parent]
   `1003`
[/ui controls]

[ui controls]
  `[control]`

  [parent]

```

## 修复要点

### UI控件配置
1. `[board image]`: 界面板配置
2. `[stick vscroll]`: 垂直滚动条设置
3. `[control]`: 控制组件配置
4. `[text]`: 文本显示配置
5. `[line_dashdot]`: 分割线样式设置

### 父级关系
- 使用[parent]标签建立控件层级关系
- 确保界面元素正确显示和交互

### 坐标和尺寸
- 通过数字参数控制控件位置和大小
- 确保界面布局合理美观

## 应用场景
- 修复游戏设置界面显示异常
- 解决扩展技能栏选项缺失问题
- 恢复快捷键名称显示功能
- 优化游戏UI界面体验
