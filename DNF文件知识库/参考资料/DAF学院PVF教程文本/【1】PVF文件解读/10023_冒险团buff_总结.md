# 10023_冒险团buff - 内容总结

## 主要内容
本文分析了冒险团（Link System）中的经验与金币加成BUFF配置。

## 核心配置文件
- etc/linksystem/characlinksystem.etc

## 配置参数详解
- [link level]: 冒险团等级（文中提到50，具体含义不明）
- [low link character exp bonus]: 低等级角色经验加成
  - 配置格式：生效条件 等级界限 加成百分比 备用参数
  - 示例：1 70 10 0 表示低于70级有10%经验加成
- [high link character exp bonus]: 高等级角色经验加成
  - 示例：1 70 0 0 表示70级以上无经验加成
- [low link character gold bonus]: 低等级角色金币加成
  - 示例：1 70 10 0 表示低于70级有10%金币加成
- [high link character gold bonus]: 高等级角色金币加成
  - 示例：1 70 0 0 表示70级以上无金币加成
