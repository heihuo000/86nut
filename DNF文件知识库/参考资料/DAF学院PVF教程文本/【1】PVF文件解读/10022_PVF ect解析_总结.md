# 10022_PVF ect解析 - 内容总结

## 主要内容
本文详细解析了PVF中etc目录下各种配置文件的用途。

## 主要配置文件
- etc/accountcargo.etc: 账号金库相关信息，包含格子、存钱、材料、金币升级配置
- etc/auction_recommend_item.etc: 拍卖行职业装备推荐信息
- etc/channel_info.etc: 频道信息
- etc/craneminigameitem.etc: 工业区抓娃娃机相关
- etc/deathtowerdialog.etc: 死亡之塔对话
- etc/equipmentpartset.etc: 套装表
- etc/globaltutorialinfo/characterlist.lst: 创建角色职业体验信息，定义装备栏位
- etc/goldlimitbylevel.etc: 角色金币上限配置
- etc/growthpowernpcdialog.etc: 林纳斯的礼物对话
- etc/growthpowerrewardbuff.etc: 林纳斯的礼物奖励
- etc/guild.etc: 公会相关配置
- etc/hiddennpc.etc: 隐藏的NPC
- etc/independent_drop.etc: 独立掉落配置
- etc/independentdrop.lst: 独立掉落列表
