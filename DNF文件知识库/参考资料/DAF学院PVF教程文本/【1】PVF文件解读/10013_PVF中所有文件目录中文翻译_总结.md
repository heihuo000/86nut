# 10013_PVF中所有文件目录中文翻译 - 内容总结

## 主要内容
本文提供了PVF文件中各个目录的中文翻译和基本功能说明，帮助理解DNF游戏资源结构。

## 目录结构翻译
- aicharacter: 人工智能角色
- appendage: 附加状态
- aura: 光环
- cash shop: 现金店
- character: 角色
- chatemoticon: 聊天表情
- clientonly: 客户端专属功能
- common: 通用文件
- creature: 生物（宠物相关）
- data: 数据
- dungeon: 地下城
- equipment: 装备
- etc: 配置文件
- event: 活动
- item shop: 物品店
- map: 地图
- monster: 怪物
- n_quest: 任务
- nexon: Nexon相关
- npc: NPC
- passive object: 被动对象
- pet: 宠物
- pvp mission: PVP任务
- region: 区域
- skill: 技能
- sqr: 脚本
- stackable: 可堆叠物品
- stage map: 阶段图
- town: 城镇
- ui: 界面
- worldmap: 世界地图
