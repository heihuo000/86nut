## 主要内容
本文由老牛提供，详细解析了DAF爆率文件的结构和计算原理，是完全版的爆率分析教程。

## 核心爆率文件
PVF中与爆率直接相关的文件有四个，都位于/etc目录下：

### 1. 地下城通关结算爆率
```
etc/itemdropinfo_clearreward.etc
```
- 控制地下城通关结算时翻牌的爆率

### 2. 地下城怪物爆率1
```
etc/itemdropinfo_monseter.etc
```
- 控制地下城怪物的基础爆率

### 3. 地下城怪物爆率2
```
etc/itemdropinfo_monseter_extra.etc
```
- 控制地下城怪物的额外爆率

### 4. 深渊怪物爆率
```
etc/itemdropinfo_monster_hell.etc
```
- 控制深渊怪物的爆率

## 爆率计算原理

### 标准格式
每组数据有6个数，格式如下：
- 前5个数分别表示：白装、蓝装、紫装、粉装、史诗爆率参数
  - 用A、B、C、D、E表示
- 最后一个为爆率基数
  - 用X表示，X = E + 1

### 出货原理
产生一个X以内的随机整数n（0 < n ≤ X-1），判断规则：
```
n ≤ A，爆白装
A < n ≤ B，爆蓝装
B < n ≤ C，爆紫装
C < n ≤ D，爆粉装
D < n ≤ E，爆史诗
```

### 爆率计算公式
```
白装爆率 = A / (X-1)
蓝装爆率 = (B-A) / (X-1)
紫装爆率 = (C-B) / (X-1)
粉装爆率 = (D-C) / (X-1)
史诗爆率 = (E-D) / (X-1)
```

## 重要说明
- 爆率参数本位要大于等于前一位
- 当和前一个参数一样时，本品质装备爆率为0
- 单件装备的爆率计算方式
- 一般非常困难深渊是出9件装备

## 实践示例
将非常困难深渊的爆率参数改成：
```
0
0
0
0
1000000
1000001
```
那么一次就会出9件史诗
