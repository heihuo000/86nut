```
超级爆率 = PVF允许的最大爆率值
```

## 爆率数值标准

### 常见爆率数值
- 1000000 = 100%
- 500000 = 50%
- 100000 = 10%
- 50000 = 5%
- 10000 = 1%
- 5000 = 0.5%
- 1000 = 0.1%

### 不同文件的爆率标准
不同文件中100%对应的数值不同：
- 有的1000000 = 100%
- 有的100000 = 100%
- 有的10000 = 100%
- 有的1000 = 100%
- 有的100 = 100%
