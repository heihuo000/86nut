# 11982_深渊固定掉落几个装备 - 内容总结

## 主要内容
本文介绍了如何修改深渊副本的固定掉落装备数量的方法。

## 核心文件
```
etc/hellparty.etc
```

## 文件路径关联

### 1. DGN文件
- `[seal door map index]`词条指向深渊的map文件

### 2. Map文件
- 底部`[special passive object]`词条指向深渊组

### 3. Hellparty.etc文件
- `[group index]`代表深渊组
- 深渊组内X-0或者X-1为怪物和APC
  - 0为怪物
  - 1为APC

## 配置示例

### 原始配置
```
[difficulty]
    4
    `A`    8    5    3    60    0
    `B`    6    4    97    40    0
    `C`    4    3    0    0    0
    `D`    0    3    0    0    1
[/difficulty]
```
这里固定掉落信息

### 修改后配置
```
[difficulty]
    4
    `A`    1    1    60    60    0
    `B`    1    1    40    40    0
    `C`    1    1    1    0    0
    `D`    1    1    1    0    0
[/difficulty]
```
这是60版本固定掉落1个装备，无论什么颜色

## 参数详解

### Difficulty配置
- 4: 难度等级数量
- A/B/C/D: 四个难度等级
- 每行格式: 难度标识 最小数量 最大数量 普通掉率 冒险掉率 地狱掉率

### 数值说明
- 最小数量: 1（固定掉落至少1个）
- 最大数量: 1（固定掉落最多1个）
- 普通掉率: 60（60%概率）
- 冒险掉率: 60（60%概率）
- 地狱掉率: 0（0%概率）

## 操作步骤

### 1. 定位文件
1. 找到etc/hellparty.etc文件
2. 确定目标深渊副本组索引

### 2. 修改配置
1. 找到对应的[difficulty]标签
2. 修改各难度下的掉落数量
3. 调整掉率参数

### 3. 验证效果
1. 保存修改后的文件
2. 更新封包
3. 测试深渊副本掉落效果

## 应用场景
- 深渊副本固定掉落装备
- 调整深渊难度掉落平衡
- 创建自定义深渊副本
- 实现特殊掉落机制

## 重要说明
- 60版本固定掉落1个装备，无论什么颜色
- 可根据需要修改掉落数量和几率
- 支持不同难度独立配置
- 每个难度可设置不同掉率

## 注意事项
1. 确保文件路径正确
2. 注意数值格式和顺序
3. 测试不同难度下的掉落效果
4. 合理设置掉率避免过高或过低
5. 备份原始文件以防出错
