# 11525_商城解读1 - 内容总结

## 主要内容
本文详细解读了DNF商城系统的文件结构和配置方法。

## 核心文件
- etc/newcashshop.etc: 商城文件
- etc/newcashshop_restrict.etc: 商城补充文件

## 文件结构详解

### 主要标签
- [coin]: 复活币
- [item]: 商品
- [premium]: 限时商品
- [creature]: 宠物物品
- [package]: 礼包

### 商品配置格式
```
编码 物品代码 所需金币 所需胜点 所需点券 名称注释
示例：8000 976 100000 0 0 <13::name_976`大頭禮包A [女魔法師]`>
```

### 特殊属性标签
- [cart disallowance]: 不可以重复添加购物车（未测试）
- [gift disallowance]: 不可以赠送（未测试）
- [cerapoint disallowance]: 代币券禁止购买
- [gift only]: 只可以赠送（未测试）
- [max gift count]: 最大赠送次数（联动gift only）
- [not stackable buy]: 不可叠加购买

## 修改要点
- 可以通过修改etc/newcashshop.etc文件来调整商城物品
- 需要注意物品代码、价格和名称的对应关系
- 可以设置物品的各种限制属性

## 重要说明
- 文件结构清晰，便于理解和修改
- 包含了商城物品的各种配置选项
- 为商城自定义提供了详细指导
