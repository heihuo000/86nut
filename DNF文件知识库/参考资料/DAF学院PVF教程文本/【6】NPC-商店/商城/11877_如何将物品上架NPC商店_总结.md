# 11877_如何将物品上架NPC商店 - 内容总结

## 主要内容
本文介绍了如何将物品上架到NPC商店的方法，以无色小晶块为例进行说明。

## 核心文件
- 以赛丽亚商店为例：equipmentshop7.shp

## 商店配置详解

### [sell item] 标签
- 该标签之间为NPC出售的物品
- 物品按7个为一行排列
- 每7个物品组成一组

### 配置符号说明
1. **物品代码**：如3033-3262，代表具体的物品
   - 可从道具lst文件中查看具体物品代码对应的物品
   
2. **"-1"**：代表空白
   - 用于分隔售卖物品
   - 避免物品连接在一起显示

3. **箭头">"**：用于分隔代码
   - 如3033>3034，分隔不同物品代码
   - 编写时可直接复制使用

4. **"-2"**：代表分页
   - 用于在不同页面销售物品
   - 示例：第一页卖小晶块，第二页卖异界宝珠

### 分页设置
- 使用[tab name][/tab name]标签设置分页名称
- 必须设置分页名称，否则游戏打开商店会出错
- 示例：
```
[tab name]
       `商店`
       `異界寶珠`
[/tab name]
```

## 操作步骤
1. 打开目标NPC的商店文件
2. 在[sell item]标签中添加物品代码
3. 使用">"分隔不同物品
4. 使用"-2"实现分页功能
5. 设置对应的分页名称
6. 保存并替换服务端文件

## 重要说明
- 添加物品时要遵循既定格式
- 分页功能需要正确配置分页名称
- 注意物品代码的准确性
