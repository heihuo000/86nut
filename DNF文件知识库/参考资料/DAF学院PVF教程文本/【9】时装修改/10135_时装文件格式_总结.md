# 10135_时装文件格式 - 内容总结

## 主要内容
本文详细介绍了DNF中时装文件的格式和各参数的含义。

## 文件基本结构

### 共通部分
```
[name]
<3::name_2050009``>

[name2]
<3::name2_2050009``>

[explain]
<3::basic_explain_2050009``>

[grade]
3

[rarity]
2

[part set index]
3

[usable job]
`[at fighter]`
[/usable job]

[attach type]
`[free]`

[minimum level]
1

[icon]
`item/avatar/common/IconClone.img` 13

[equipment type]
`[coat avatar]` 0
```

### 参数说明
1. 前三项(name/name2/explain): 装备描述，调用kor内容
2. [grade]: 掉落等级
3. [rarity]: 稀有度
4. [part set index]: 套装文件编号
5. [usable job]: 适用职业
6. [attach type]: 交易类型
7. [minimum level]: 最低佩戴等级
8. [icon]: 图标路径和编号
9. [equipment type]: 装备类型

### Avatar类型选择
```
[avatar type select]
7 0 0 1500 0
30 0 0 3000 0
0 0 0 6000 0
0 0 0 6500 3 `[S socket]`
`[C socket]` `[C socket]`
[/avatar type select]
```

### 数值说明
- 第一个数值：时效天数（0为无期限限制）
- 第二个数值：未知
- 第三个数值：未知
- 第四个数值：出售价格（单位：D币或D点）
- 第五个数值：徽章镶嵌槽数量

### 能力选择
```
[avatar select ability]
`[SKILL_LEVEL]` `[at fighter]` 36 1
`[MAGICAL_ATTACK]` `+` 45
`[SKILL_LEVEL]` `[at fighter]` 88 1
[/avatar select ability]
```

### 技能提升
```
[skill levelup]
`[at fighter]` 5 1
`[at fighter]` 46 1
[/skill levelup]
```

### 其他参数
- [move wav]: 装备移动声音
- [animation job]: 职业动画

## 普通与稀有时装区别
- 外观部分有不同配置
- [variation]: 变化参数
- [layer variation]: 图层变化
- [equipment ani script]: 装备动画脚本

## 应用场景
- 制作自定义时装
- 修改现有时装属性
- 创建新的时装套装
- 调整时装的外观和功能

## 重要说明
- 各参数需要正确配置才能生效
- 套装编号需要与etc/equipmentpartset.etc文件对应
- 图标路径要确保正确
- 属性格式基本统一，便于批量修改
