# 10361_时装套装实现额外翅膀特效 - 内容总结

## 主要内容
本文介绍了如何通过时装套装实现额外翅膀特效的方法。

## 核心文件

### 1. etc/additionaleffectlist.etc
- 指向ANI文件，即贴图效果
- 控制特效的视觉表现

### 2. etc/equipmenteffectset.etc
- 指向套装文件，指定特效路径
- 控制套装与特效的关联关系

## 套装特效配置

### 时装文件中的指向设置
```
[effect part set index]
 13
```
- 数字13是指向的路径编号
- 在每件时装中指定此路径实现套装特效

### 特效列表配置
```
[effect]
 [index]
  61 套装指向
 [type]
  1   必须是1
 [animation]
  `Character/Common/Animation/chn_9thrare_effect/stand_red_normal.ani`
  `Character/Common/Animation/chn_9thrare_effect/stand_red_dodge.ani`
  `Character/Common/Animation/chn_9thrare_effect/walk_red_normal.ani`
  `Character/Common/Animation/chn_9thrare_effect/walk_red_dodge.ani`
 [/animation]
 [fix position x]
  -11  站街显示，走动不显示！
[/effect]
```

## 配置参数说明

### Index
- 套装指向编号
- 与套装文件中的编号对应

### Type
- 必须设置为1
- 控制特效类型

### Animation
- 动画文件路径列表
- 包括站立、闪避、行走等状态的动画
- 需要根据实际需求添加相应动画

### Fix Position X
- 控制特效显示位置
- 示例中的-11表示站街显示，走动时不显示

## 替代方法

### 直接在时装中添加特效代码
```
[effect]
 [type]
  `animation`
  ...
[/effect]
```

### 优点和缺点
- 优点：操作相对简单
- 缺点：被称为"垃圾办法"，可能不够稳定或规范

## 应用场景
- 为时装套装添加翅膀特效
- 实现特殊视觉效果
- 增强时装的观赏性
- 创建独特的外观展示

## 重要说明
- 需要正确配置路径和编号
- 特效文件必须存在且路径正确
- 注意不同类型动画的配置
- 建议使用标准方法而非替代方法

## 注意事项
- 备份原始文件
- 测试特效显示效果
- 确保文件路径准确性
- 注意特效性能影响
