# 10311_时装教程 - 内容总结

## 主要内容
本文通过自制23件套实例详细讲解了时装制作的完整流程。

## 单件时装配置

### 基础信息
```
#PVF_File
[name]
<3::name_40032``>

[name2]
<3::name2_40032``>

[grade]
3

[rarity]
2

[part set index]
3  // 套装调用代码
```

### 套装代码说明
- 1: 未知（好像没有这个代码）
- 2: 上级时装
- 3: 自制超级稀有套
- 4: 其他类型（后续说明）

### 特效设置
```

[reference effect part set index]
1  // 特效冲突：值为1的不触发
```

## 套装部分
- 相对简单易懂
- 通过part set index关联单件
- 可设置套装属性加成

## 文件路径
- etc/equipmentpartset.etc: 套装调用代码表
- etc/additionaleffectlist.etc: 天空套特效文件
- etc/equipmenteffectset.etc: 装备特效集合文件

## 制作流程
1. 确定时装类型和部位
2. 配置基础属性信息
3. 设置职业适配性
4. 配置外观和动画参数
5. 设置属性加成
6. 添加特效配置
7. 关联套装文件
8. 测试和调整

## 重要说明
- 时装制作涉及多个文件关联
- 需要理解各参数的具体含义
- 套装和单件需要协调配置
- 特效可能存在冲突需要处理

## 应用场景
- 制作原创时装套装
- 修改现有时装属性
- 添加新的时装类型
- 创建特殊效果的时装
