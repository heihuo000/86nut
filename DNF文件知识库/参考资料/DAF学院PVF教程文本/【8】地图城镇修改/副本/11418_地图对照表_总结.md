# 11418_地图对照表 - 内容总结

## 主要内容
本文提供了DNF中地图的对照表，包含TOWN对应文件、地图名称、NPC添加对应文件等信息。

## 表格结构
表格包含以下列信息：
1. TOWN对应文件：城镇对应的.twn文件名
2. 地图名称：游戏中显示的地图名称
3. NPC添加对应文件：添加NPC所需的文件
4. 区域说明：该区域的功能说明
5. 关于赛莉亚房间：赛莉亚房间的相关信息
