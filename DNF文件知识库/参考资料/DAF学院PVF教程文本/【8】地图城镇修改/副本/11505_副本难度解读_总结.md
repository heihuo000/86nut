# 11505_副本难度解读 - 内容总结

## 主要内容
本文详细解读了如何修改副本难度、增加怪物数量、调整怪物属性等方法。

## 用户需求
用户希望：
- 开放副本难度选择（冒险、王者、地狱等）
- 增加副本怪物数量
- 添加独立掉落（领主粉等）
- 修改怪物视野、好战度、技能CD
- 全局提升怪物血量、攻击、防御、攻速、硬直等属性
- 实现BOSS追着玩家打的刺激体验

## 难度选择设置

### 开放难度选择
1. 找到副本对应的DGN文件
2. 删除以下两行代码：
```
[designate dungeon difficulty]锁定难度
2
```

### 添加地狱难度
在etc/ultimatedungeonlist.etc文件中添加地狱难度：
- 添加副本编号到列表中
- 格式清晰明了，易于理解

## 增加怪物数量

### 操作方法
1. 找到目标房间的MAP文件
2. 从文件末尾开始查找怪物配置
3. 复制并粘贴怪物代码段：
```
[monster]
6180310862208011`[fixed]`
`[normal]`
[/monster]
```

### 格式说明
- 怪物编号开头-`[normal]`结尾
- 可复制多份实现增加怪物
- 增强怪物需要另外设置参数

## 独立掉落设置
- 掉落格式有两种：单一掉落/多种掉落
- 领主粉掉落属于多种掉落写法
- 配置文件：etc/independent_drop.etc

## 怪物属性修改

### 基础属性
在怪物文件(mob)中修改以下参数：
- [vision]视野：控制怪物视觉范围
- [warlike]好战度：影响怪物攻击欲望
- [cooltime]怪物技能CD：控制技能释放频率

### 批量修改方法
使用Notepad++的正则功能进行批量修改：
- 好战度修改：`\\[warlike\\]\\r\\n\\d+\\t\\r\\n` → `\\[warlike\\]\\r\\n1000\\t\\r\\n`
- 视野翻倍：`(\\[vision\\]\\r\\n)(\\d+\\t\\r\\n)` → `(\\[vision\\]\\r\\n1)(\\2)`

## 全局怪物属性提升

### 配置文件
monster/monsterapcdifficultybonus.tbl（怪物难度表）

### 属性对应关系
- 1-5：未知属性
- 6-10：未知属性
- 11-15：命中率
- 16-20：回避率
- 21-25：血量(HP)
- 26-30：攻速
- 31-35：移动速度
- 36-40：施放速度（猜测）
- 41-45：攻击伤害
- 46-50：防御
- 51-55：硬直
- 56-60：未知属性
- 61-65：未知属性
- 66-169：未知属性（4个数值一组）

### 修改说明
- 每个属性有5组数据分别对应：普通、冒险、王者、地狱、未知难度
- 数据为倍数修改：1.1→2.2为翻倍，1.1→3.3为翻3倍
- 注意血量过高可能导致怪物自杀

## 效果说明
修改后的怪物特点：
- 移动飞快
- 攻击像抽风
- 硬直超高（像霸体一样）
- 防御高（难以攻击）
- 回避高（满屏MISS）
- 血量高（看着就头痛）
