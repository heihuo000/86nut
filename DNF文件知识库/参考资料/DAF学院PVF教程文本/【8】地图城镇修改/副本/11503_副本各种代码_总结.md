# 11503_副本各种代码 - 内容总结

## 主要内容
本文介绍了副本相关的各种代码和配置参数。

## 核心代码说明

### 人员限制
```
[necessary party]
2
```
设置进入副本的最低人数要求

### 地图规格
```
[map specification]
1 0 18001
```
横1竖0，副本房间的ID是18001

### BOSS地图规格
```
[boss map specification]
4 1 18008
```
BOSS的副本房间为横4竖1，副本房间的ID是18008

### 起始地图
```
[start map]
0 0 0 1 0 2
```
起始点的副本房间坐标，可能是0 0或者0 1或者0 2

### 地狱副本设置
```
[hell dungeon]
1
```
启用地狱难度

### 封印门设置
```
[seal door map index]
60067

[seal door pos]
4 0
```
深渊BOSS的副本房间ID 60067和坐标4 0

## DGN文件说明

### 文件作用
DGN文件可以理解为副本的总成，包含副本的大致信息：
- 副本名称
- 难度设置
- 走向规划
- 模式配置
- 限制条件等

### 核心参数
- [background pos]: 调整原背景图片的像素，多数为80
- [name]: 副本名称
- [explain]: 副本说明
- [difficulty]: 难度等级
- [time limit]: 时间限制
- [player limit]: 玩家人数限制

## MAP文件说明

### 文件作用
MAP文件代表副本中的具体房间，包含：
- 房间的布局
- 怪物分布
- NPC位置
- 机关设置等

### 核心参数
- [monster]: 怪物配置
- [npc]: NPC配置
- [object]: 物品配置
- [trigger]: 触发器设置
- [door]: 门的设置

## 应用场景
- 修改现有副本参数
- 创建自定义副本
- 调整副本难度设置
- 优化副本体验

## 重要说明
- 需要理解各参数的具体含义
- 修改时要确保数据格式正确
- 建议备份原始文件
- 修改后需要进行功能测试
