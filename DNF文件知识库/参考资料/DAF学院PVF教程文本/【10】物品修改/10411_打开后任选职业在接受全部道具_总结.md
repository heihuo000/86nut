# 10411_打开后任选职业在接受全部道具 - 内容总结

## 主要内容
本文介绍了如何创建一个礼盒，打开后可以任选职业并获得该职业的全部道具。

## 核心配置
- [stackable type]: `booster selection` 0 - 定义为可选择类型
- [booster category num]: 1 3 - 表示职业道具数量（示例为3个职业，五个职业就是1-5，6个职业是1-6）
- [booster selection num]: 0 - 选择数量

## 选择配置
- [booster select category]: 定义可选择的职业
  - 第一个数字是顺序（从0开始），第二个数字固定为0
  - [equipment]: 在此标签内定义每个职业的道具
  - 格式：职业道具代码 数量

## 配置特点
- [usable job]: `[all]` 表示所有职业可用
- [attach type]: `[account]` 表示账号绑定
- [rarity]: 2 表示蓝色稀有度

## 说明
- 可以配置多个职业，每个职业对应一组道具
- 玩家打开礼盒时可选择职业，然后获得该职业对应的全部道具
- 需要按照职业数量正确设置[booster category num]
