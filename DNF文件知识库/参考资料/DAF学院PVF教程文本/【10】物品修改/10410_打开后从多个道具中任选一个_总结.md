# 10410_打开后从多个道具中任选一个 - 内容总结

## 主要内容
本文介绍了如何创建一个礼盒，打开后可以从多个道具中任选一个的功能。

## 核心配置
- [stackable type]: `booster selection` 0 - 定义为可选择类型
- [booster category num]: 0 - 选择类别数量
- [booster selection num]: 1 - 可选择数量（示例为1）

## 选择配置
- [booster select category]: 定义可选择的道具类别
- [stackable]: 在此标签内定义可选择的道具
- 格式：可选道具代码 数量

## 示例配置
```
[booster select category]
 0 0
 [stackable]
 可选道具1 数量 可选道具2 数量
 [/stackable]
[/booster select category]
```

## 其他参数
- [name]: 礼盒名称
- [explain]: 道具说明
- [attach type]: 绑定类型（如[account]账号绑定）
- [rarity]: 稀有度
- [icon]: 图标路径
