# 10369_修改CD药，可达成全技能无CD - 内容总结

## 主要内容
本文介绍了如何通过修改PVF文件实现全技能无CD效果的方法。

## 核心步骤
1. 找到stackable/event/callcomeback文件夹
2. 找到event_7823.stk文件
3. 修改其中的int数据，将-10和60000的值进行修改
4. -100等于无CD效果，但修改超过-100可能会导致不知名错误
5. 使用GM工具发送给角色，需要勾选封装选项才能接收邮件

## 重要说明
- 状态觉醒新增的技能不受此加成影响
- 修改精神刺激灵药时发现该物品没有相应的属性修改选项
- 可用于修改霸体药水时间，路径为stackable/professional/potion/ptn_superarmor.stk，修改最后一个数值60000可调整药水效果时间
