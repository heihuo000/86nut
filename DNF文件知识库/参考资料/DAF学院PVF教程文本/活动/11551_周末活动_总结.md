# 11551_周末活动 - 内容总结

## 主要内容
本文介绍了周末活动疲劳值和经验值加成的设置方法。

## 核心文件
```
etc/serverparameter.etc
```

## 配置参数

### 疲劳值加成
```
[weekend bonus fatigue]
        20
```

### 经验值加成
```
[weekend bonus exp]
        20
```

## 参数说明
- 上面是疲劳值加成
- 下面是经验值加成
- 数值20表示20%的加成率

## 应用场景
- 周末双倍活动
- 疲劳值加成设置
- 经验值加成调整
- 复古服特殊设置
- 服务器活动运营

## 重要说明
- 对于一些复古服的设置还是有意义的
- 这个参数是可以控制的
- 甚至是可以增加的
- 需要根据实际需求进行研究和调整

## 操作要点
1. 打开etc/serverparameter.etc文件
2. 找到weekend bonus相关参数
3. 根据需要调整疲劳值和经验值加成
4. 保存并重启服务器生效

## 扩展思考
- 参数不仅可以控制，还可以进行扩展
- 支持更高数值的加成设置
- 可根据不同时间段设置不同加成
- 可结合其他活动进行组合设置

## 注意事项
- 合理设置加成数值避免过高
- 考虑服务器负载和平衡性
- 测试不同加成效果
- 备份原始配置文件
