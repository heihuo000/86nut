# 11520_编号84-出席活动 - 内容总结

## 主要内容
本文介绍了如何修改编号84的出席活动（每日签到活动）的方法。

## 核心文件
```
event/ingameeventlist.evt
event/attendance.evt
```

## 修改步骤

### 1. 修改活动时间
打开event/ingameeventlist.evt目录，修改每日签到的活动开始时间和结束时间

#### 活动配置
```
[event]
[idx]
86 `Attendance.evt`//活动ID86
[record type]
1 
[start]//活动起始日期
20191221 
[end]//活动结束日期
20200319 
[state]
1 
[/event]
```

##### 注意事项
- 出席活动只有3个月的有效期
- 需要开启三个月的时间
- 确保起始和结束日期正确

### 2. 配置签到奖励
打开event/attendance.evt目录，添加签到活动物品的奖励代码，要添加90组

#### 奖励配置要点
- 需要准备90组奖励物品代码
- 每日奖励需要按顺序配置
- 物品代码要确保有效
- 数量设置要合理

## 应用场景
- 每日签到活动
- 连续签到奖励
- 月度签到福利
- 活动期限延长
- 自定义签到奖励

## 重要说明
- 活动ID为86
- 有效期只有3个月
- 需要设置正确的起始和结束时间
- 奖励物品需要添加90组数据

## 注意事项
- 确保日期格式正确
- 物品代码有效性检查
- 奖励数量合理性
- 活动配置完整性和准确性
- 备份原始文件以防出错
