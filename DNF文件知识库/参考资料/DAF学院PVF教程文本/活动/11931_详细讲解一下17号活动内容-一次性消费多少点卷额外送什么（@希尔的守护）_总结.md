# 11931_详细讲解一下17号活动内容-一次性消费多少点卷额外送什么（@希尔的守护） - 内容总结

## 主要内容
本文详细讲解了17号活动的配置方法，即一次性消费多少点卷额外送什么的活动机制。

## 活动本质
用通俗的话讲，17号活动就是：
- 一次性消费多少点卷
- 额外送什么物品

## 核心配置

### 活动参数设置
```
活动参数1要设为100
```

### 商场文件修改
需要修改经常使用的商场文件：
```
[newcashshop.etc]
```

### 配置示例
```
600~899点卷可以获得一个代号2749449的物品
后面的1-1000代表此物品出现的概率区间
```

## 参数详解

### 消费区间
- 600~899点卷：消费金额区间
- 对应获得的物品代码：2749449
- 概率区间：1-1000（表示100%概率）

### 概率计算
- 概率区间1-1000 = 100%概率
- 概率区间1-100 = 10%概率
- 实际测试：买了十几次才出来一次，平均概率接近10%

## 实现方法

### 必得物品设置
要实现买多少点卷必得什么物品：
1. 将活动参数1改为1000
2. PVF设置成1-1000
3. 效果：4楼展示的必得效果

### 概率调整
- 参数1设为100：约10%概率
- 参数1设为1000：100%概率（必得）

## 重要说明
- 是单次消费，不是累计消费
- 字面意思即为一次性的消费金额
- 不是多次消费的累计总额

## 补充说明
```
正解：
活动开启参数 1 <= 1000；
[bonus item info]词条中每组中各物品权重之和 = 1000
```

## 配置要点

### 活动开启参数
- 数值范围：1-1000
- 控制总体概率：数值越大概率越高
- 1000为必得，100为约10%概率

### 物品权重设置
- [bonus item info]词条
- 每组物品权重之和必须等于1000
- 确保概率计算准确性

## 应用场景
- 点卷充值活动
- 消费返利活动
- 限时促销活动
- 节日特殊活动
- 新服开业活动

## 操作步骤
1. 设置活动参数1为期望值（100或1000）
2. 修改newcashshop.etc文件
3. 配置消费区间和对应物品
4. 设置概率区间（1-1000为100%）
5. 测试消费返利效果

## 注意事项
- 区分单次消费和累计消费
- 确保物品代码有效性
- 合理设置消费金额区间
- 验证概率设置准确性
- 测试不同消费金额的效果
