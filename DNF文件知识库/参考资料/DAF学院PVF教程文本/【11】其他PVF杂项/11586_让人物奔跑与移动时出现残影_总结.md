# 11586_让人物奔跑与移动时出现残影 - 内容总结

## 主要内容
本文介绍了如何让人物在奔跑和移动时出现残影效果的配置方法。

## 核心配置参数
```
[SPECTRUM]
        1
        [SPECTRUM TERM]
                100
        [SPECTRUM LIFE TIME]
                500
        [SPECTRUM COLOR]
                255        255        255        255
        [SPECTRUM EFFECT]
                `NONE`
```

## 配置说明
- [SPECTRUM]: 开启残影效果（1为开启）
- [SPECTRUM TERM]: 残影间隔时间
- [SPECTRUM LIFE TIME]: 残影持续时间
- [SPECTRUM COLOR]: 残影颜色（RGBA值）
- [SPECTRUM EFFECT]: 残影特效

## 需要修改的文件路径
- character/swordman/animation/dash.ani (奔跑动画)
- character/swordman/animation/move.ani (移动动画)
