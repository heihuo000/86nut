## 🖥️ 服务器配置详解

### 🎮 游戏服务器基础配置
```ini
gc_no = 3011                    # 游戏SERVER分流(频道)编号
server_type = 0                 # 服务器类型
channel_no = 11                 # 分流(频道)编号
channel_name = ch.11            # 分流(频道)名称(在游戏中显示)
ip = 127.1.135.202             # 游戏SERVER IP地址
tcp_port = 10011               # game server使用的TCP端口
udp_port = 11011               # game server使用的UDP端口
```

**配置说明**:
- **gc_no**: 全局频道编号，用于区分不同的游戏频道
- **channel_no**: 频道编号，玩家在游戏中看到的频道号
- **channel_name**: 频道显示名称，可自定义
- **IP和端口**: 游戏服务器的网络连接配置
