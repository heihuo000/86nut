# 11547_佣兵系统 - 内容总结

## 主要内容
本文介绍了DNF冒险团佣兵系统的配置方法。

## 核心文件
- etc/linksystem/characlinksystem.etc

## 配置参数详解
### 经验加成配置
- [low link character exp bonus]: 低于70级角色的经验加成
  - 格式：生效条件 等级界限 加成百分比 备用参数
  - 示例：1 70 10 0 表示低于70级有10%经验加成
- [high link character exp bonus]: 70级以上角色的经验加成
  - 示例：1 70 0 0 表示70级以上无经验加成

### 金币加成配置
- [low link character gold bonus]: 低于70级角色的金币加成
  - 示例：1 70 10 0 表示低于70级有10%金币加成
- [high link character gold bonus]: 70级以上角色的金币加成
  - 示例：1 70 0 0 表示70级以上无加成

## 功能说明
- 佣兵系统可以为低等级角色提供经验加成
- 佣兵系统可以为低等级角色提供金币加成
- 配置分为高低等级两个部分，可以分别设置
