# 佣兵系统总结

## 主要内容

该教程详细介绍了DNF游戏中冒险团佣兵系统的PVF修改方法，包括文件位置和各项参数配置。

### 文件位置
- **主要文件**: `etc/linksystem/characlinksystem.etc`
- **文件说明**: 冒险团佣兵系统的配置文件

### 参数配置详解

#### 低等级佣兵经验加成
```
[low link character exp bonus]
1 70 10 0 //低于70级有10%经验加成
[/low link character exp bonus]
```
- 第一个数值：启用标识（1表示启用）
- 第二个数值：等级界限（70级）
- 第三个数值：经验加成百分比（10%）
- 第四个数值：保留参数（0）

#### 高等级佣兵经验加成
```
[high link character exp bonus]
1 70 0 0 //70级以上无加成
[/high link character exp bonus]
```
- 第一个数值：启用标识（1表示启用）
- 第二个数值：等级界限（70级）
- 第三个数值：经验加成百分比（0%，表示无加成）
- 第四个数值：保留参数（0）

#### 低等级佣兵金币加成
```
[low link character gold bonus]
1 70 10 0 //低于70级10%金币加成
[/low link character gold bonus]
```
- 第一个数值：启用标识（1表示启用）
- 第二个数值：等级界限（70级）
- 第三个数值：金币加成百分比（10%）
- 第四个数值：保留参数（0）

#### 高等级佣兵金币加成
```
[high link character gold bonus]
1 70 0 0 //70级以上无加成
[/high link character gold bonus]
```
- 第一个数值：启用标识（1表示启用）
- 第二个数值：等级界限（70级）
- 第三个数值：金币加成百分比（0%，表示无加成）
- 第四个数值：保留参数（0）

## 修改要点

1. 正确找到并编辑 `etc/linksystem/characlinksystem.etc` 文件
2. 根据需要调整经验加成和金币加成的等级界限
3. 合理设置加成百分比，避免过高或过低
4. 确保四个数值的完整性和正确性
5. 注意区分低等级和高等级的加成设置
6. 测试修改后的效果确保正常运行

## 应用场景

此修改方法适用于希望实现以下功能的PVF制作者：
- 调整佣兵系统的经验加成规则
- 修改佣兵系统的金币加成设置
- 创建不同等级佣兵的差异化加成
- 实现佣兵系统的个性化配置
- 优化佣兵系统的平衡性

通过调整佣兵系统的各项参数，可以为玩家提供更有吸引力的佣兵系统，提升冒险团的功能性和趣味性。
