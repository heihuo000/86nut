# 11998_[教程]开启公会告示栏

## 📋 基本信息
- **文件名**: 11998_[教程]开启公会告示栏.json
- **作者**: 学院搬运工
- **类型**: 其他PVF杂项修改
- **难度**: 中等

## 📝 功能描述
教程介绍如何开启DNF游戏中的公会告示栏功能，通过修改NUT脚本实现在打开公会信息栏时同时打开公会告示栏。

## 🔧 主要内容
通过修改onOpenPopupWindow相关函数，实现在打开公会信息栏（popupType == 42）时自动打开公会告示栏（窗口ID：217）。

## 📋 操作步骤
1. 找到文件：`sqr/extend_function/onopenpopupwindow.nut`
2. 将第一个函数`onOpenWindPopupWindows_All`粘贴进去
3. 将其余各职业的函数合并到现有函数中
4. 确保函数正确合并，避免重复定义

## 📁 相关文件
- `sqr/extend_function/onopenpopupwindow.nut`

## 💻 代码示例
```nut
//注意函数合并

function onOpenWindPopupWindows_All(obj, popupType, windowTileType)
{
    if (popupType == 42 )//打開公會信息欄時
    {
    sq_OpenPopupWindow(217, 0, 0, 0);//同時打開公會告示欄
    }
}

function onOpenPopupWindow_Swordman(obj, popupType, windowTileType)//每个职业打开窗口时执行的函数
{
    if(!obj) return;

onOpenWindPopupWindows_All(obj, popupType, windowTileType)
}
```

## ⚠️ 注意事项
- 需要注意函数合并，避免重复定义
- 确保所有职业的函数都正确调用通用函数
- 公会告示栏窗口ID为217
