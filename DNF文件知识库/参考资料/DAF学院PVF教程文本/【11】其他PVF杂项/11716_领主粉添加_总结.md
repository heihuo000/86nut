# 11716_领主粉添加 - 内容总结

## 主要内容
本文介绍了如何添加领主粉（史诗装备）的方法和相关配置文件。

## 核心配置文件
1. 装备辞典位置：etc/itemdictionary/(r)itemdictionary.etc
   - 根据装备不同出现情况内容也不一样

2. 独立掉落配置：etc/independent_drop.etc
   - 掉落信息添加到[/independent drop]以上
   - 黄金哥布林掉落代码(61726)有异常，需要补全，否则不掉落粉装
   - 可以跳过异常代码，在其以上加入独立掉落信息

3. 掉落权重配置：etc/itemdictionary/(r)independentdropinfo.etc
   - 掉落权重加到[/item table]之前
   - [/monster table]前需要加怪物列表

4. 副本名称配置：etc/itemdictionary/(r)dungeon_name.etc
   - 在020011怪物ID"2"后面的两个数字要写"0""0"
   - 否则副本提示右上角没有小图标

## 说明
- 用于添加新的史诗装备到游戏中
- 需要配置多个文件才能完整实现功能
- 涉及装备辞典、掉落、权重等多个系统
