# 11583_APD详解：装备、技能、状态、外观及增益效果 - 内容总结

## 主要内容
本文详细解释了DNF中APD（appendage）文件的作用和配置方法，包括装备、技能、状态、外观及增益效果。

## APD文件概述
- APD文件类似于宏或模块
- 具有改变状态和武器颜色等多种用途
- 在当前版本中调用已较少

## 核心配置参数
- [type]: 类型定义
- [duration]: 持续时间
- [buff]: 状态效果
- [icon image]: 图标路径
- [max overlap]: 最大叠加数
- [int data]: 整数运算数据
- [string data]: 数据串
- [float data]: 浮动运算数据

## 技能静态数据改变
- [type]: `skill data up`
- [string data]: 定义技能调用格式
- 示例：`[swordman]` `174` `[all]` `[level]` `0` `%` `300` 
  - 调用鬼剑士第174号技能，增加至300%（3倍）
  - [all]表示所有场景适用，包括PKC、地下城、死亡之塔等

## 状态改变
- [type]: `change status`
- 可修改角色的物理攻击力等属性
- 支持整数和浮点数数据配置

## 应用场景
- 装备附魔效果
- 技能增益效果
- 状态变化效果
- 外观改变效果
