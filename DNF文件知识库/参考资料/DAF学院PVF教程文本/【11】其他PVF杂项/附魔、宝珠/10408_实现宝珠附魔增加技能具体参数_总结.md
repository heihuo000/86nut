## 🔧 宝珠类型对比

### 📦 普通宝珠构成
```
普通宝珠 = 宝珠文件 + 卡片文件
```
- **宝珠文件**: 定义宝珠基本属性
- **卡片文件**: 定义附魔效果

### ⚔️ 技能宝珠构成（侍魂宝珠）
```
技能宝珠 = 宝珠文件 + 卡片文件 + APD文件
```
- **宝珠文件**: 定义宝珠基本属性
- **卡片文件**: 调用APD附加状态
- **APD文件**: 实现技能参数提升

## 📋 制作步骤

### 1️⃣ 卡片文件编写
卡片文件负责调用APD附加状态：

```ini
[enchant]
    [if]
        [change status]
            `hp`
            `>`
            `%`
            0 `end`
    [/if]
    [then]
        [target]
            `myself`
            -1
        [appendage]
            51  # APD编号，需要对应实际APD文件
    [/then]
[/enchant]
```

#### 🔑 关键参数说明
- **[if]条件**: 触发条件（这里是HP大于0%，即始终触发）
- **[target]**: 作用目标（myself = 自己）
- **[appendage]**: 调用的APD编号

### 2️⃣ APD文件编写
APD文件实现具体的技能参数提升：

```ini
#PVF_File

[type]
    `skill data up`

[duration]
    20000  # 持续时间（毫秒）

[buff]
    0  # 是否显示为BUFF

[icon image]
    `` 0  # 图标设置

[max overlap]
    1  # 最大叠加次数

[int data]
[/int data]

[string data]
    # 在这里编写技能参数提升代码
    # 例如：
    # `[skill data up]`
    # `技能编号` `参数类型` `提升数值`
[/string data]

[float data]
[/float data]
```

#### 🔑 核心参数详解
- **[type]**: 必须设置为 `skill data up`
- **[duration]**: 效果持续时间
- **[max overlap]**: 叠加次数限制
- **[string data]**: 技能参数提升的具体代码

### 3️⃣ 技能参数编写
在APD的 `[string data]` 部分编写技能提升参数：

```ini
[string data]
    `[skill data up]`
    `技能编号` `参数索引` `提升数值`
    `技能编号` `参数索引` `提升数值`
    # 可以添加多个技能的多个参数
[/string data]
```

## 💡 实现原理

### 🔄 工作流程
1. **装备宝珠**: 玩家装备技能宝珠
2. **触发条件**: 卡片的IF条件被满足
3. **调用APD**: 卡片调用指定的APD文件
4. **应用效果**: APD中的技能参数提升生效
5. **持续时间**: 效果按APD设定的时间持续

### ⚙️ 技术要点
- **条件触发**: 使用IF语句控制触发时机
- **状态附加**: 通过appendage调用APD
- **参数提升**: 在APD中定义具体的技能增强
