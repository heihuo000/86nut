# 11466_装备词典修改 - 内容总结

## 主要内容
本文详细解释了DNF中装备词典文件(itemdictionary.etc)的结构和修改方法。

## 文件路径
- etc/itemdictionary/(r)itemdictionary.etc

## 参数详解
以示例代码27601 0 3 3 10103 0 0 0 1 1 2 103 103 0 0为例：

- 第1个数值(27601): 装备代码
- 第2个数值(0): 装备稀有度分类
- 第3个数值(3): 装备佩戴等级
- 第4个数值(3): 装备文件里的grade参数（掉落等级）
- 第5个数值(10103): 装备分类代码

## 获取信息显示参数
- 第6个数值: 地图掉落信息（0为不显示，1为显示）
- 第7个数值: 是否指定怪物掉落（0为无，1为有）
- 第8个数值: 是否在加百列商店出售（0为无，1为有）
- 第9个数值: NPC出售（1为有，0为无）
- 第10个数值: NPC代码（1为林纳斯等）
- 第11个数值: 任务获得数（0为无，1为1个任务等）

## 后续参数
- 任务代码：根据前面任务数填写相应数量的任务代码
- 罐子数量：装备获取的罐子数量
