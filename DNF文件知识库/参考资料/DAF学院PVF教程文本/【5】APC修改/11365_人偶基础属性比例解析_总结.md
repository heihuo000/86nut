# 11365_人偶基础属性比例解析 - 内容总结

## 主要内容
本文详细解析了APC（人偶）基础属性比例的配置方法，以28号人偶为例进行说明。

- 文件：28.aic
- 参数：[character status rate]

- 修改时需要注意数值的平衡性
