# 11942_显示宠物等级 - 内容总结

## 主要内容
本文介绍了如何在宠物文件中添加等级显示功能的方法。

## 核心配置代码
```
[selective grow creature]
    [using exp item]
        1
    [grow Atype item index]
        778866
    [item count for levelup]
        10
[/selective grow creature]

[event evolute creature]
    1004
[/event evolute creature]
```

## 参数说明

### 选择性成长宠物配置
```
[selective grow creature]
    [using exp item]调用exe里的项目编码
        1
    [grow Atype item index]需要的消耗品编码(具体写法如下)
        778866
    [item count for levelup]在城镇吃多少个778866可以升级
        10
[/selective grow creature]
```

### 宠物进化事件配置
```
[event evolute creature]升到多少级之后可以变成下面这个宠物不可缺少（测试为不生效）
    1004
[/event evolute creature]
```

## 消耗品配置(.stk文件)
```
#PVF_File

[name]
    `进阶宠物的食物食物`

[name2]
    `name2_778866`

[explain]
    ``

[grade]
    1

[rarity]
    2

[usable job]
    `[all]`
[/usable job]

[attach type]
    `[trade]`

[minimum level]
    1

[cool time]
    10

[icon]
    `Item/stackable/consumption.img`    997

[field image]
    `Item/field_consumption.img`    68

[stackable type]
    `[creature expitem]`    0

[move wav]
    `FOOD_TOUCH`

[stack limit]
    1000
```

## 配置要点

### 必要条件
- 在.pet文件中添加上述代码
- 不可缺少任何一串才能显示
- 需要正确配置消耗品编码

### 参数详解
1. [using exp item]: 调用exe里的项目编码
2. [grow Atype item index]: 需要的消耗品编码
3. [item count for levelup]: 升级所需消耗品数量
4. [event evolute creature]: 进化等级要求

### 消耗品配置
- [stackable type]: `[creature expitem]` 0 (宠物经验物品类型)
- [name]/[name2]: 消耗品名称
- [icon]: 图标路径和编号
- [stack limit]: 堆叠上限

## 应用场景
- 为宠物添加等级显示功能
- 实现宠物升级系统
- 创建养成类宠物玩法
- 增强宠物收集乐趣
- 提升宠物系统深度

## 操作步骤
1. 打开宠物.cre文件
2. 在文件顶部添加等级显示代码
3. 确保所有必要参数都已填写
4. 创建对应的消耗品文件(.stk)
5. 配置消耗品相关参数
6. 测试宠物等级显示效果

## 重要说明
- 代码必须完整添加才能生效
- 消耗品编码需要与配置一致
- 升级所需物品数量可自定义
- 宠物进化功能可能需要额外配置
- 测试时注意编码的准确性

## 注意事项
- 备份原始宠物文件
- 确保消耗品文件配置正确
- 测试不同等级的显示效果
- 验证升级功能是否正常
- 注意编码和数值的合理性
