# 11516_宠物解读 - 内容总结

## 主要内容
本文详细解读了DNF宠物相关的各种配置参数和修改方法。

## 核心配置参数

### 宠物等级显示
```
[event evolute creature]
145 
[/event evolute creature]
```
- 活动编号103

### 宠物坐标调整
```
[character span]
-70
```
- 表示宠物位置处于角色后方x轴70坐标

### 宠物终极技能OBJ配置
```
[piercing]
1000 0 1000 0 
[/piercing]
```
- 碰触后OBJ消失是因为没有加穿透，OBJ同理

### 宠物动画配置
- [random motion]: 随机动作
  - `Animation/rin&len_03sing.ani`
- [basic motion]: 基本正常动作
  - `Animation/aquajello_stand.ani`
- [walk motion]: 步行行走动作
  - `Animation/aquajello_move.ani`
- [run motion]: 跑步动作
  - `Animation/aquajello_move.ani`
- [skill motion]: 小技能开始动作
  - `Animation/aquajello_skill1_body.ani`
- [over skill motion]: 终极技能动作
  - `Animation/aquajello_skill2_body.ani`
- [response motion]: 宠物响应动作
  - `Animation/aquajello_response_body.ani`
- [equip motion]: 装备动作在背包的显示
  - `Animation/equip_body.ani`

## 重要说明

### 动画路径注意事项
- 宠物调用空路径ANI会导致错误
- 需要确保动画文件存在且路径正确

### 各类动作说明
- basic motion: 基本正常动作（站立）
- walk motion: 步行动作（行走）
- run motion: 跑步动作（奔跑）
- skill motion: 小技能动作（技能释放）
- over skill motion: 终极技能动作（大招释放）
- response motion: 响应动作（互动反馈）
- equip motion: 装备动作（背包显示）

## 应用场景
- 修改宠物的动作表现
- 调整宠物的位置坐标
- 优化宠物技能特效
- 修复宠物动画显示问题
- 自定义宠物行为模式

## 修改要点
- 确保动画文件路径正确
- 合理设置宠物位置坐标
- 配置正确的技能穿透参数
- 区分不同状态下的动作
- 注意动画文件的兼容性

## 注意事项
- 避免使用空路径的ANI文件
- 检查动画文件是否存在
- 注意坐标值的正负意义
- 确保穿透参数设置合理
- 测试不同动作的效果
