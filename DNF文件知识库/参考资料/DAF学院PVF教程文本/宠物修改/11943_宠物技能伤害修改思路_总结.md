# 11943_宠物技能伤害修改思路 - 内容总结

## 主要内容
本文以2018年春节宠物技能伤害修改为示例，详细介绍了宠物技能伤害修改的思路和方法。

## 修改示例

### 文件路径
```
passiveobject/creature/chn_2018_spring_festival/powwow_half_fox/attackinfo/special_overskill_third_attack_fireground.atk
```

### 文件结构说明
- passiveobject/creature: 宠物被动对象技能路径
- attackinfo: 技能伤害值配置
- 可根据实际需要进行修改

### 核心配置代码
```
[absolute damage]#绝对伤害值
        300000

[damage]#基础伤害值
        100000

[attack type]

[magic]

[elemental property]

[fire element]

[damage reaction]

[down]

[hit wav]
        `OVERFREEZE_EXTENSION_HIT`

[duration]#技能持续时间
        1000
```

## 宠物文件路径结构

### 三大核心路径
1. creature/: 宠物动作相关
   - 配置动物站立、行走、奔跑、静止等动作

2. equipment/creature: 宠物装备存在形式
   - 游戏中获取的代码、宠物属性

3. passiveobject/creature/: 宠物技能被动对象
   - 技能特效伤害等

## 技能配置代码
```
[BEHAVIOR]
        [CREATE PASSIVEOBJECT]
                [INDEX]
                        200466#被动对象技能代码，在passiveobject.lst中可以搜索到具体调用位置
                [PARTICLE FILENAME]
                        ``
                [LEVEL]
                        0
                [POS]
                        0        -1        0
                [FOLLOWING TARGET]
        [/CREATE PASSIVEOBJECT]
[/BEHAVIOR]
```

### 技能详细配置
```
[piercing power]#穿透力
        1000

[piercing tolerance]
        1

[basic action]#调用技能动画，做出动作等
        `Action/overskill_third_attack_fireGround.act`

[attack info]#调用具体技能伤害
        `AttackInfo/overskill_third_attack_fireGround.atk`
```

## 修改要点

### 伤害参数
- [absolute damage]: 绝对伤害值（不受防御影响）
- [damage]: 基础伤害值（可被防御影响）
- [duration]: 技能持续时间（毫秒）

### 技能类型
- [attack type]: 攻击类型
- [magic]: 魔法攻击标识
- [elemental property]: 元素属性
- [fire element]: 火属性
- [damage reaction]: 伤害反应（如击倒、击飞等）
- [down]: 击倒效果

### 音效和持续
- [hit wav]: 命中音效
- [piercing power]: 穿透力
- [piercing tolerance]: 穿透容忍度

### 动作和攻击信息
- [basic action]: 调用技能动画文件
- [attack info]: 调用具体技能伤害配置文件

## 应用场景
- 调整宠物技能伤害数值
- 修改宠物技能特效表现
- 优化宠物技能平衡性
- 创建自定义宠物技能
- 调整技能持续时间和效果

## 操作步骤
1. 确定目标宠物相关文件路径
2. 找到对应的atk文件（attackinfo目录下）
3. 修改absolute damage和damage数值
4. 调整技能持续时间
5. 配置技能类型和属性
6. 设置技能动画和音效
7. 测试修改效果

## 重要说明
- 被动对象技能代码需要在passiveobject.lst中查找
- 技能动画和攻击信息需要分别配置
- 需要理解各参数的具体含义和作用
- 修改后需要充分测试确保平衡性

## 注意事项
- 备份原始文件以防出错
- 注意数值的合理性避免过高或过低
- 测试不同场景下的技能效果
- 确保技能动画文件存在且路径正确
- 验证技能伤害计算是否符合预期
