# PVF文件样板说明

本目录包含了从实际PVF包中提取的标准格式样板文件，用于参考和学习PVF文件的正确格式。

## 目录结构

### 装备文件样板 (equipment)
- **武器_戾波之尖啸.equ** - 武器装备样板，展示武器的完整属性结构
- **防具_苍穹之啸断刃胸甲.equ** - 防具装备样板，展示防具的完整属性结构  
- **饰品_秘技之境戒指.equ** - 饰品装备样板，展示饰品的完整属性结构

### 消耗品文件样板 (stackable)
- **药剂_特级生命秘药.stk** - 药剂类消耗品样板，展示药剂的完整属性结构
- **材料_渴望之魔石.stk** - 材料类消耗品样板，展示材料的完整属性结构
- **材料_食人魔的灵魂.stk** - 简化材料样板，展示基础材料属性结构

### 技能文件样板 (skill)
- **主动技能_鬼斩.skl** - 主动技能样板，展示主动技能的完整属性结构
- **魔法技能_黑洞.skl** - 魔法技能样板，展示复杂魔法技能的属性结构
- **被动技能_霸体护甲.skl** - 被动技能样板，展示被动技能的完整属性结构

## 使用说明

1. **格式参考** - 这些文件严格按照DNF PVF文件格式规范编写，可作为格式参考
2. **属性学习** - 通过这些样板可以学习各类文件的属性字段含义和取值范围
3. **模板使用** - 可以复制这些样板作为新文件的模板，修改相应属性值
4. **格式验证** - 当遇到格式问题时，可以对比这些样板进行格式纠正

## 重要提醒

- 所有字符串使用反引号 `` ` `` 包围，禁用双引号 `"`
- 参数层级使用 **Tab** 缩进，禁止使用空格
- 严格遵循PVF文件格式规范，任何微小错误都可能导致游戏崩溃
- 修改时请参考《PVF文件格式规范.md》文档
