## 🚀 主要功能

### 格式检查功能
- 检查缩进格式（使用制表符而非空格）
- 验证字符串引号（使用反引号`` ` ``而非双引号）
- 检查参数分隔（使用制表符而非空格）
- 验证数值格式（数值不加引号）
- 检查行尾符（使用CRLF而非LF）
- 文件编码检查（UTF-8）
- 标签配对检查

### 格式转换功能
- 自动修复引号格式（双引号/单引号→反引号）
- 自动转换参数分隔符（空格→制表符）
- 自动修复缩进格式（空格→制表符）
- 自动移除数值的引号
- 统一行尾符为CRLF
- 自动备份原文件

## 🔧 使用方法

### 1. 格式检查
```bash
# 使用Python增强版检查工具
python "PVF格式检查增强版.py" "文件名.equ"

# 使用PowerShell检查工具
powershell -Command "& 'Check-PVFFormat.ps1' -Path '文件名.equ' -ShowDetails"
```

### 2. 格式转换
```bash
# 预览将要进行的更改
python "PVF格式转换工具.py" "文件名.equ" --dry-run

# 执行转换（带备份）
python "PVF格式转换工具.py" "文件名.equ" --backup

# 批量转换目录
python "PVF格式转换工具.py" "目录路径/" --recursive --backup
```

### 3. 交互式使用
```bash
# 启动交互式工具
python "启动器.py"
```

### 4. 使用批处理脚本
```bash
# 双击运行快速检查.bat
# 或在命令行运行
快速检查.bat
```

## ⚠️ 注意事项

1. **自动修复前会创建备份** - 所有自动修复操作都会创建`.backup`文件
2. **编码问题** - 工具会自动处理UTF-8和GBK编码
3. **格式规范** - 基于真实PVF文件观察的格式规范
4. **行尾符** - PVF文件应使用CRLF行尾符

## ✅ 格式规范摘要

1. **字符串格式**：使用反引号包围，如 `` `字符串内容` ``
2. **参数分隔**：使用制表符（Tab）分隔，如 `[icon mark]	`item.img`	14`
3. **缩进**：使用制表符（Tab）进行缩进
4. **数值格式**：直接写数字，不加引号，如 `[level]	85`
5. **行尾符**：使用CRLF（\r\n）
6. **标签格式**：正确的开始和结束标签配对
7. **文件头**：以 `#PVF_File` 开头
