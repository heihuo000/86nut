# DNF装备动画参数配置指南

## 📖 概述

本指南基于实际的武器样板文件，详细说明装备动画参数的正确配置方法，避免常见的格式错误和配置问题。

---

## 🎯 核心动画标签组合

### 基本动画配置结构

装备的动画配置通常包含以下四个核心标签，它们必须按照特定的顺序和格式组合使用：

1. `[animation job]` - 指定适用职业
2. `[variation]` - 设置动画变化
3. `[layer variation]` - 设置层级变化
4. `[equipment ani script]` - 指定动画脚本

### 标准配置模板

```
[animation job]
	`[职业代码]`

[variation]
	<主变化>	<次变化>

[layer variation]
	<层级编号>
	`<层级名称>`

[equipment ani script]
	`<脚本路径>`

[layer variation]
	<层级编号>
	`<层级名称>`

[equipment ani script]
	`<脚本路径>`
```

## 🔧 详细参数说明

### [animation job] 职业设定

**格式要求**:
- 必须使用反引号 `` ` `` 包围职业代码
- 每个职业需要独立的 `[animation job]` 块
- 职业代码前后需要方括号

**常用职业代码**:
```
`[swordman]`          // 鬼剑士
`[demonic swordman]`  // 暗帝
`[fighter]`           // 格斗家
`[gunner]`            // 神枪手
`[mage]`              // 魔法师
`[creator mage]`      // 创造者
`[priest]`            // 圣职者
`[thief]`             // 盗贼
`[knight]`            // 骑士
```

**错误示例**:
```
[animation job] "[swordman]"     // 错误：使用了双引号
[animation job] [swordman]       // 错误：缺少反引号
[animation job] `[swordman]` `[fighter]`  // 错误：一个块中包含多个职业
```

### [variation] 动画变化

**格式要求**:
- 通常包含两个数值
- 数值之间用Tab分隔
- 第一个数值为主变化，第二个为次变化

**示例**:
```
[variation]
	5	6
```

**常见数值组合**:
- `5 6` - 常用于武器装备
- `1 2` - 常用于防具装备
- `12 2` - 常用于时装装备

### [layer variation] 层级变化

**格式要求**:
- 包含层级编号和层级名称
- 层级编号为数值（通常3-4位）
- 层级名称必须用反引号包围
- 编号和名称之间用Tab分隔

**示例**:
```
[layer variation]
	2790
	`clubc`
```

**常见层级编号**:
- `2790` - 武器主层级
- `650` - 武器次层级
- `1800` - 上衣主层级
- `900` - 上衣次层级

**常见层级名称**:
- `clubc` - 钝器主层
- `clubb` - 钝器次层
- `coat_a` - 上衣A层
- `coat_b` - 上衣B层

### [equipment ani script] 动画脚本

**格式要求**:
- 脚本路径必须用反引号包围
- 路径通常指向 `.lay` 文件
- 每个 `[layer variation]` 后跟随对应的脚本

**示例**:
```
[equipment ani script]
	`equipment/character/swordman.lay`
```

**常见脚本路径**:
```
`equipment/character/swordman.lay`     // 鬼剑士
`equipment/character/dsswordman.lay`   // 暗帝
`equipment/character/fighter.lay`      // 格斗家
`equipment/character/atfighter.lay`    // 街霸
`equipment/character/gunner.lay`       // 神枪手
`equipment/character/mage.lay`         // 魔法师
```

## ⚠️ 常见错误和解决方案

### 错误1：格式不正确

**错误示例**:
```
[animation job] [swordman]  // 缺少反引号
[variation] 5,6             // 使用逗号分隔
[layer variation] 2790 clubc  // 层级名称缺少反引号
```

**正确格式**:
```
[animation job]
	`[swordman]`
[variation]
	5	6
[layer variation]
	2790
	`clubc`
```

### 错误2：缩进不正确

**错误示例**:
```
[animation job]
`[swordman]`  // 缺少Tab缩进
```

**正确格式**:
```
[animation job]
	`[swordman]`  // 使用Tab缩进
```

### 错误3：标签顺序错误

**错误示例**:
```
[variation]
	5	6
[animation job]
	`[swordman]`  // 顺序颠倒
```

**正确顺序**:
```
[animation job]
	`[swordman]`
[variation]
	5	6
```

### 错误4：缺少必要的标签组合

**错误示例**:
```
[animation job]
	`[swordman]`
[variation]
	5	6
// 缺少 layer variation 和 equipment ani script
```

**完整配置**:
```
[animation job]
	`[swordman]`
[variation]
	5	6
[layer variation]
	2790
	`clubc`
[equipment ani script]
	`equipment/character/swordman.lay`
```

## 🎯 最佳实践

### 1. 严格遵循格式规范
- 所有字符串参数使用反引号 `` ` `` 包围
- 使用Tab进行缩进，不要使用空格
- 保持标签的正确顺序

### 2. 参考官方样板
- 优先参考 `测试样例` 目录中的实际文件
- 对比同类型装备的配置方式
- 验证层级编号和名称的对应关系

### 3. 逐步测试
- 先配置单个职业，确认无误后再添加其他职业
- 每次修改后进行游戏内测试
- 记录有效的配置组合供后续使用

### 4. 备份和版本控制
- 修改前备份原始文件
- 记录每次修改的内容和原因
- 建立有效配置的模板库
