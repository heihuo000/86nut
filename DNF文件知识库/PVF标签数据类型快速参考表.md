# PVF标签数据类型快速参考表

## 📖 使用说明

本参考表基于真实PVF文件分析和标准样板文件，详细列出了各种标签的正确数据类型格式。

**格式约定：**
- 🔤 **字符串**：使用反引号 `` `内容` ``
- 🔢 **数值**：直接写数字，无引号
- 📊 **范围**：两个数值用Tab分隔
- 🔗 **复合**：多个参数用Tab分隔

## ⚠️ 常见错误示例

### ❌ 错误格式
```
[name]          "装备名称"        // 错误：使用双引号
[rarity]        `3`              // 错误：数值使用反引号
[price] 1000000                  // 错误：使用空格分隔
[icon mark]     `item.img`  14   // 错误：使用空格分隔
```

### ✅ 正确格式
```
[name]          `装备名称`        // 正确：字符串使用反引号
[rarity]        3                // 正确：数值直接写
[price]         1000000          // 正确：使用Tab分隔
[icon mark]     `item.img`	14   // 正确：使用Tab分隔
```

## 🔍 快速检查清单

- [ ] 所有字符串都使用反引号 `` ` `` 包围
- [ ] 所有数值都直接写，不使用引号
- [ ] 参数之间使用Tab分隔，不使用空格
- [ ] 缩进使用Tab，不使用空格
- [ ] 嵌套结构正确使用开始和结束标签
- [ ] 文件编码为UTF-8
- [ ] 行尾符为CRLF（\r\n）
