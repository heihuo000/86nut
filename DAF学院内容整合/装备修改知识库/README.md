# DNF装备修改知识库

## 📚 简介

本知识库整理了DAF学院关于DNF装备修改的教程和资料，涵盖从基础的装备属性调整到高级的装备技能添加、特效修改等内容。通过本知识库，您可以深入了解DNF装备系统的内部机制和修改方法。

## 🎯 核心功能

根据DAF学院的教程，DNF装备修改主要包含以下几个方面：

1. **DIY装备属性实现** - 自定义装备的基本属性和特殊效果
2. **技能添加** - 给装备或称号添加特定技能
3. **特效修改** - 修改装备外观和战斗特效
4. **属性赋予** - 实现攻击时属性赋予效果
5. **属性提取** - 从现有装备中提取特定属性
6. **指令系统** - 通过装备触发特殊指令

## 🏗️ 装备文件结构

### 核心文件类型
- `*.equ` - 装备参数文件
- `equipment.lst` - 装备列表文件
- `*.kor.str` - 装备名称显示文件

### 装备分类目录
- `/equipment/character/common/` - 通用装备
- `/equipment/character/[职业名]/` - 职业专属装备
  - `jacket` - 上衣
  - `ring` - 戒指
  - `weapon` - 武器
  - 等等...

## 🔧 修改技巧与方法

### 1. DIY装备属性实现思路

#### 基础属性
- 直接添加基础属性，如力量、智力、体力、精神等

#### 无敌和霸体
- 从无轩系列武器提取无敌和霸体效果

#### 属性赋予
- 可以选择攻击时一定几率赋予属性攻击
- 将几率改为100%达到持续效果，避免冲突

#### 技能提升
- 可以通过修改百战老将类装备的技能提升效果
- 实现1-70级全职业技能提升1-100级

#### 范围攻击
- 提取精良黄龙黑炮等装备的特效
- 修改效果、几率和伤害数值

#### 直接扣除HP
- 提取裂创或十字斩-者等装备的特效
- 自定义数值

#### 命中回复、附加伤害
- 查找对应特效进行提取和修改

### 2. 装备/称号添加技能方法

#### 所需工具
1. `Decrypt.exe` - PVF专业工具
2. 台服物品代码
3. `notepad++` - 用于修改和定位文件

#### 修改步骤
1. 将工具和PVF放在同一目录
2. 找到目标装备并获取其代码
3. 用notepad++搜索装备所在文件
4. 在文件中找到`icon`标签
5. 在其前插入技能代码

#### 技能代码格式
```
[skill levelup]
'[职业名]' 技能ID 等级
[/skill levelup]
```

示例：
```
[skill levelup]
'[priest]' 35 2
[/skill levelup]
```

### 3. 指令系统实现

#### 基础指令格式
```
[@05][command]
[@06](UP)
[@08],
[@06](DOWN)
[@08],
// ... 更多指令
[@05][/command]
```

#### 触发条件
```
[@05][if]
[@05][use command]
[@02]1
[@05][cooltime]
[@02]CD时间
[@05][/if]
```

#### 执行事件
```
[@05][then]
// 触发事件内容
[@05][/then]
```

## 📋 常用属性效果

### 基础属性
- **无敌和霸体**: 从特定武器提取
- **属性赋予**: 攻击时赋予属性攻击
- **技能提升**: 全职业技能等级提升
- **范围攻击**: 攻击范围扩大效果
- **直接扣除HP**: 直接减少敌人HP
- **命中回复**: 命中时回复HP/MP
- **附加伤害**: 附加额外伤害
- **范围异常状态**: 使范围内敌人进入异常状态
- **获得道具几率**: 增加获得道具的几率
- **祝福效果**: 增加特定状态效果

### 特效提取来源
- **范围攻击**: 精良黄龙黑炮特效
- **直接扣除HP**: 裂创或十字斩-者特效
- **范围异常状态**: 天霜等装备特效
- **获得道具几率**: 贪婪系列饰品
- **祝福效果**: 称号类装备

## ⚠️ 注意事项

1. **ID冲突**: 一个装备只能添加一个指令，避免与其他装备指令重复
2. **文件备份**: 修改前备份原始文件
3. **路径结构**: 了解装备目录结构以便快速定位文件
4. **语法正确**: 确保所有标签和参数格式正确
5. **平衡性**: 合理设置属性参数，避免数值失衡

## 🔍 装备修改技巧

### 1. 快速定位文件
- 使用notepad++的"文件查找"功能
- 根据装备类型确定搜索路径：
  - 通用装备: `xxxxxxx\\equipment\\character\\common\\[分类]`
  - 职业装备: `xxxxxxx\\equipment\\character\\[职业名]\\[分类]`

### 2. 属性提取技巧
- 从效果相似的装备中提取所需属性
- 修改参数值以适应目标装备
- 测试修改效果确保正常工作

### 3. 技能等级设置
- 合理设置技能提升等级
- 避免等级过高导致游戏失衡
- 可以同时添加多个技能
