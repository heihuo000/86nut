# DNF装备修改核心标签参考

## 🏷️ 装备属性标签

### 基础属性标签
- **[width]** 
  - 功能作用: 定义物品在背包中的显示宽度
  - 参数详解: 
    - 类型: 数值型
    - 作用: 控制背包格子占用
    - 取值范围: 通常为1-10
    - 默认值: 根据物品类型确定
  - 实际应用: 控制背包界面布局
  - 依赖关系: 与背包界面系统关联

- **[ability category]**
  - 功能作用: 定义装备的属性类别
  - 参数详解: 
    - 类型: 复合型
    - 作用: 包含各类属性加成
    - 结构: 包含STR/DEX/INT/LUK/HP/MP等属性
    - 取值: 以"*"分隔属性名、操作符和数值
  - 实际应用: 给装备添加各种属性加成
  - 依赖关系: 与角色属性系统关联

- **[STR]**
  - 功能作用: 力量属性加成
  - 参数详解: 
    - 类型: 数值型
    - 作用: 增加角色力量值
    - 取值范围: 通常为1-200
    - 默认值: 0
  - 实际应用: 提升物理职业伤害
  - 依赖关系: 与物理伤害计算系统关联

- **[DEX]**
  - 功能作用: 体力（敏捷）属性加成
  - 参数详解: 
    - 类型: 数值型
    - 作用: 增加角色体力值
    - 取值范围: 通常为1-200
    - 默认值: 0
  - 实际应用: 影响命中率和物理伤害
  - 依赖关系: 与命中率和物理伤害系统关联

- **[INT]**
  - 功能作用: 智力属性加成
  - 参数详解: 
    - 类型: 数值型
    - 作用: 增加角色智力值
    - 取值范围: 通常为1-200
    - 默认值: 0
  - 实际应用: 提升魔法职业伤害
  - 依赖关系: 与魔法伤害计算系统关联

- **[LUK]**
  - 功能作用: 精神（幸运）属性加成
  - 参数详解: 
    - 类型: 数值型
    - 作用: 增加角色精神值
    - 取值范围: 通常为1-200
    - 默认值: 0
  - 实际应用: 影响暴击率等属性
  - 依赖关系: 与暴击率计算系统关联

- **[HP MAX]** 
  - 功能作用: 最大生命值加成
  - 参数详解: 
    - 类型: 数值型
    - 作用: 增加角色最大生命值
    - 取值范围: 通常为1-2000
    - 默认值: 0
  - 实际应用: 提升角色生存能力
  - 依赖关系: 与角色生命值系统关联

- **[MP MAX]**
  - 功能作用: 最大魔法值加成
  - 参数详解: 
    - 类型: 数值型
    - 作用: 增加角色最大魔法值
    - 取值范围: 通常为1-2000
    - 默认值: 0
  - 实际应用: 提升技能释放能力
  - 依赖关系: 与技能消耗系统关联

- **[EQUIPMENT_PHYSICAL_ATTACK]**
  - 功能作用: 物理攻击力加成
  - 参数详解:
    - 类型: 数值型
    - 作用: 增加角色物理攻击力
    - 取值范围: 根据装备等级确定
    - 默认值: 0
  - 实际应用: 提升物理职业伤害
  - 依赖关系: 与物理伤害计算系统关联

- **[EQUIPMENT_MAGICAL_ATTACK]**
  - 功能作用: 魔法攻击力加成
  - 参数详解:
    - 类型: 数值型
    - 作用: 增加角色魔法攻击力
    - 取值范围: 根据装备等级确定
    - 默认值: 0
  - 实际应用: 提升魔法职业伤害
  - 依赖关系: 与魔法伤害计算系统关联

- **[EQUIPMENT_PHYSICAL_DEFENSE]**
  - 功能作用: 物理防御力加成
  - 参数详解:
    - 类型: 数值型
    - 作用: 增加角色物理防御力
    - 取值范围: 根据装备等级确定
    - 默认值: 0
  - 实际应用: 减少受到的物理伤害
  - 依赖关系: 与伤害减免系统关联

- **[EQUIPMENT_MAGICAL_DEFENSE]**
  - 功能作用: 魔法防御力加成
  - 参数详解:
    - 类型: 数值型
    - 作用: 增加角色魔法防御力
    - 取值范围: 根据装备等级确定
    - 默认值: 0
  - 实际应用: 减少受到的魔法伤害
  - 依赖关系: 与伤害减免系统关联

### 装备要求标签
- **[level]**
  - 功能作用: 装备基础等级
  - 参数详解:
    - 类型: 数值型
    - 作用: 定义装备的基本等级
    - 取值范围: 通常1-100+
    - 默认值: 根据装备类型确定
  - 实际应用: 与角色等级要求相关
  - 依赖关系: 与装备系统关联

- **[required level]**
  - 功能作用: 装备使用等级要求
  - 参数详解:
    - 类型: 数值型
    - 作用: 限制使用装备的角色等级
    - 取值范围: 通常1-100+
    - 默认值: 0
  - 实际应用: 控制装备使用门槛
  - 依赖关系: 与角色等级系统关联

- **[required STR/DEX/INT/LUK]**
  - 功能作用: 装备使用属性要求
  - 参数详解:
    - 类型: 数值型
    - 作用: 限制使用装备的属性要求
    - 取值范围: 通常1-200
    - 默认值: 0
  - 实际应用: 控制装备使用门槛
  - 依赖关系: 与角色属性系统关联

- **[required job]**
  - 功能作用: 装备职业要求
  - 参数详解:
    - 类型: 数值型
    - 作用: 限制使用装备的职业
    - 取值范围: 根据职业编码确定
    - 默认值: 0
  - 实际应用: 控制职业使用权限
  - 依赖关系: 与职业系统关联

- **[required gender]**
  - 功能作用: 装备性别要求
  - 参数详解:
    - 类型: 数值型
    - 作用: 限制使用装备的性别
    - 取值范围: 0-2 (0=男, 1=女, 2=通用)
    - 默认值: 2
  - 实际应用: 控制性别使用权限
  - 依赖关系: 与角色系统关联

## 🏷️ 特殊效果标签

### 技能相关标签
- **[skill levelup]**
  - 功能作用: 给装备添加技能等级提升
  - 参数详解:
    - 类型: 复合型
    - 作用: 在装备上添加特定职业的技能等级提升
    - 格式: '[职业名]' 技能ID 等级
    - 示例: '[priest]' 35 2 (给神职35号技能+2级)
  - 实际应用: 通过装备提升特定技能等级
  - 依赖关系: 与技能系统关联

- **[category]**
  - 功能作用: 定义装备类别
  - 参数详解:
    - 类型: 字符串型
    - 作用: 分类装备类型
    - 取值: [equipment_weapon], [equipment_armor]等
    - 默认值: 根据装备类型确定
  - 实际应用: 确定装备类型和功能
  - 依赖关系: 与装备系统关联

## 🏷️ 指令系统标签

### 特殊指令标签
- **[command]**
  - 功能作用: 定义按键指令序列
  - 参数详解:
    - 类型: 复合型
    - 作用: 在装备上绑定特定按键序列
    - 格式: [@06](UP/DOWN/LEFT/RIGHT/CREATURE)等
    - 示例: 上上下下左右左右V
  - 实际应用: 通过装备触发特殊指令
  - 依赖关系: 与指令系统关联

- **[use command]**
  - 功能作用: 触发指令的条件
  - 参数详解:
    - 类型: 数值型
    - 作用: 定义触发指令的条件ID
    - 取值: 通常为1
    - 默认值: 1
  - 实际应用: 控制指令触发条件
  - 依赖关系: 与指令系统关联

- **[cooltime]**
  - 功能作用: 指令冷却时间
  - 参数详解:
    - 类型: 数值型
    - 作用: 设置指令使用间隔
    - 取值范围: 通常毫秒为单位
    - 默认值: 无
  - 实际应用: 控制指令使用频率
  - 依赖关系: 与冷却系统关联

- **[if] / [then]**
  - 功能作用: 条件执行结构
  - 参数详解:
    - 类型: 结构型
    - 作用: 定义条件触发执行
    - 格式: [if]条件[/if][then]执行内容[/then]
    - 默认值: 无
  - 实际应用: 实现条件触发效果
  - 依赖关系: 与逻辑执行系统关联

## ⚠️ 使用建议

1. **参数关联**: 修改属性参数时，检查是否会影响角色平衡
2. **数值平衡**: 确保参数值在合理范围内，避免数值失衡
3. **语法格式**: 保持正确的标签格式和结束标签
4. **测试验证**: 修改后进行全面功能测试
