# DNF APC修改知识库

## 📚 简介

本知识库整理了DAF学院关于DNF APC（AI Character）修改的教程和资料，涵盖从基础的APC属性调整到高级的APC技能、AI行为修改等内容。通过本知识库，您可以深入了解DNF APC系统的内部机制和修改方法。

## 🎯 核心功能

根据DAF学院的教程，DNF APC修改主要包含以下几个方面：

1. **APC基础属性修改** - 调整APC的生命值、攻击力、防御力等基础属性

6. **APC属性比例解析** - 理解APC各属性的比例关系

## 🏗️ APC文件结构

### 核心文件类型
- `*.aic` - APC参数文件（主文件）
- `aicharacter.lst` - APC列表文件
- `*.ani` - 动画文件
- `*.act` - 行为文件
- `*.str` - 字符串文件

### APC文件路径
- `aicharacter/aicharacter.lst` - APC列表信息文件
- `aicharacter/[分类]/[编号]/[编号].aic` - APC主配置文件

## 🔧 修改技巧与方法

### 1. APC召唤修改方法

#### 修改召唤APC的方法
1. 找到召唤道具的配置文件（在stackable目录下）
2. 打开对应的职业召唤道具文件
3. 找到`summon apc`参数
4. 将第一个数值替换为目标APC的编号

示例：
```
[summon apc]
1511  // 西岚APC的编号
90      // 等级
90      // 等级
[/summon apc]
```

#### 获取APC编号的方法
- 打开 `aicharacter/aicharacter.lst` 文件
- 查找所需APC的编号
- 将其用于召唤道具配置

### 3. APC人偶修改详细教程

#### APC文件组成
一般APC包含以下几个文件：
- `[name].aic` - 人偶主文件，其他文件都要在这里声明
- `[name].ani` - 动画文件
- `[name].act` - 行为文件
- 相关贴图和资源文件

#### .aic 文件详解
- `action` - 用来调用animation显示各种贴图
- 各种参数定义APC的行为和属性

### 4. APC召唤次数修改
- 通过修改`cooltime`参数可以控制APC召唤频率
- 将`cooltime`设置为0可实现无限制召唤
- 注意召唤过多APC可能影响游戏性能

## 📋 核心标签详解

### 召喚相關標籤
- `summon apc` - 召喚APC參數
  - 第一個數值：APC編號
  - 後續數值：等級參數

### 屬性相關標籤
- `[character status rate]` - 角色狀態比例
  - 定義APC各項屬性的比例值
  - 37個參數對應不同屬性

### AI行為參數
- 移動速度參數
- 攻擊速度參數
- 施放速度參數
- 各種抗性參數

## ⚠️ 注意事项

1. **性能影响**: 召喚過多APC可能導致遊戲卡頓
2. **文件備份**: 修改前備份原始文件
3. **測試驗證**: 修改後進行充分測試
4. **數值平衡**: 合理設置APC屬性，避免數值失衡
5. **路徑正確**: 確保所有引用路徑正確
