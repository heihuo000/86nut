# DNF高级教程核心标签参考

## 🏷️ ACT行为系统标签

### ACT基础标签
- **[MOTION]** 
  - 功能作用: 定义动作行为
  - 参数详解: 
    - 类型: 容器型
    - 作用: 包含动作相关的配置
    - 结构: 包含动画、音效、说话等子标签
    - 示例: `[MOTION]...[/MOTION]`
  - 实际应用: 控制动作播放和效果
  - 依赖关系: 与ANI动画系统关联

- **[BASE ANI]**
  - 功能作用: 定义基础动画文件
  - 参数详解:
    - 类型: 字符串型
    - 作用: 指定调用的动画文件路径
    - 格式: `相对路径/动画文件.ani`
    - 示例: `../animation/Throw.ani`
  - 实际应用: 关联具体动画文件
  - 依赖关系: 与动画文件关联

### ACT音效标签
- **[SOUND]**
  - 功能作用: 定义动作音效
  - 参数详解:
    - 类型: 复合型
    - 作用: 设置动作触发时的音效
    - 格式: `音频名称` [延迟时间]
    - 示例: `THROW_STONE` 0
  - 实际应用: 动作音效播放
  - 依赖关系: 与音频系统关联

- **[/SOUND]**
  - 功能作用: 结束音效定义
  - 参数详解:
    - 类型: 结束标签
    - 作用: 标记音效定义结束
    - 示例: `[/SOUND]`
  - 实际应用: 结束音效配置
  - 依赖关系: 与音频系统关联

### ACT说话标签
- **[SPEECH]**
  - 功能作用: 定义角色说话内容
  - 参数详解:
    - 类型: 复合型
    - 作用: 设置角色说话的文字和参数
    - 格式: `说话内容` [参数1] [参数2]
    - 示例: `打死你個白嫖怪！` 1 33
  - 实际应用: 角色对话功能
  - 依赖关系: 与文字显示系统关联

- **[/SPEECH]**
  - 功能作用: 结束说话定义
  - 参数详解:
    - 类型: 结束标签
    - 作用: 标记说话定义结束
    - 示例: `[/SPEECH]`
  - 实际应用: 结束说话配置
  - 依赖关系: 与文字显示系统关联

### ACT触发器标签
- **[TRIGGER]**
  - 功能作用: 定义行为触发器
  - 参数详解:
    - 类型: 容器型
    - 作用: 包含触发条件和行为
    - 结构: 包含帧数检查、行为执行等
    - 示例: `[TRIGGER]...[/TRIGGER]`
  - 实际应用: 控制行为触发时机
  - 依赖关系: 与行为系统关联

- **[FRAME]**
  - 功能作用: 定义帧数检查
  - 参数详解:
    - 类型: 数值型
    - 作用: 设置检查帧数范围
    - 格式: [开始帧] [结束帧]
    - 示例: `2 2` (第2帧执行)
  - 实际应用: 精确控制触发时机
  - 依赖关系: 与动画帧数关联

- **[DO BEHAVIOR]**
  - 功能作用: 定义行为执行
  - 参数详解:
    - 类型: 容器型
    - 作用: 标记行为执行开始
    - 示例: `[DO BEHAVIOR]`
  - 实际应用: 触发行为执行
  - 依赖关系: 与行为系统关联

- **[ME]**
  - 功能作用: 定义触发器序列号
  - 参数详解:
    - 类型: 数值型
    - 作用: 设置触发器的序列号
    - 示例: `0`
  - 实际应用: 标识触发器实例
  - 依赖关系: 与触发器系统关联

## 🏷️ NUT脚本系统标签

### NUT基础标签
- **function**
  - 功能作用: 定义函数
  - 参数详解:
    - 类型: 容器型
    - 作用: 创建可调用的函数
    - 格式: `function 函数名(参数)`
    - 示例: `function checkExecutableSkill_IceCrash(obj)`
  - 实际应用: 实现技能逻辑
  - 依赖关系: 与脚本引擎关联

- **local**
  - 功能作用: 定义局部变量
  - 参数详解:
    - 类型: 变量声明型
    - 作用: 声明局部变量
    - 格式: `local 变量名 = 值`
    - 示例: `local level = sq_GetSkillLevel(obj, SKILL_ICE_CRASH)`
  - 实际应用: 存储临时数据
  - 依赖关系: 与变量系统关联

### NUT对象方法标签
- **obj.sq_IsUseSkill()**
  - 功能作用: 检查技能是否正在使用
  - 参数详解:
    - 类型: 方法调用型
    - 作用: 判断指定技能是否处于使用状态
    - 格式: `obj.sq_IsUseSkill(技能ID)`
    - 示例: `obj.sq_IsUseSkill(SKILL_ICE_CRASH)`
  - 实际应用: 技能状态检测
  - 依赖关系: 与技能系统关联

- **obj.sq_IntVectClear()**
  - 功能作用: 清空整数向量
  - 参数详解:
    - 类型: 方法调用型
    - 作用: 清空对象的整数向量数组
    - 格式: `obj.sq_IntVectClear()`
    - 示例: `obj.sq_IntVectClear()`
  - 实际应用: 初始化数组
  - 依赖关系: 与数组系统关联

- **obj.sq_AddSetStatePacket()**
  - 功能作用: 添加状态设置包
  - 参数详解:
    - 类型: 方法调用型
    - 作用: 设置对象的状态
    - 格式: `obj.sq_AddSetStatePacket(状态ID, 优先级, 是否重置)`
    - 示例: `obj.sq_AddSetStatePacket(STATE_ICE_CRASH, STATE_PRIORITY_USER, true)`
  - 实际应用: 改变对象状态
  - 依赖关系: 与状态系统关联

### NUT数据获取标签
- **sq_GetSkillLevel()**
  - 功能作用: 获取技能等级
  - 参数详解:
    - 类型: 函数调用型
    - 作用: 获取指定技能的当前等级
    - 格式: `sq_GetSkillLevel(对象, 技能ID)`

  - 依赖关系: 与技能系统关联

- **sq_GetIntData()**
  - 功能作用: 获取整数数据
  - 参数详解:
    - 类型: 函数调用型
    - 作用: 获取技能的静态整数数据
    - 格式: `sq_GetIntData(对象, 技能ID, 数据索引, 等级)`

### NUT脚本配置示例
```
// 寒冰穿刺技能定义
ENUM_ICE_CRASH_SUBSTATE_START <- 0;
ENUM_ICE_CRASH_SUBSTATE_LOOP  <- 1;
ENUM_ICE_CRASH_SUBSTATE_END   <- 3;

function checkExecutableSkill_IceCrash(obj)
{
    if(!obj) return false;
    
    local b_useskill = obj.sq_IsUseSkill(SKILL_ICE_CRASH);
    if(b_useskill) {
        obj.sq_IntVectClear();
        obj.sq_IntVectPush(ENUM_ICE_CRASH_SUBSTATE_START);
        obj.sq_AddSetStatePacket(STATE_ICE_CRASH , STATE_PRIORITY_USER, true);
        return true;
    }    
    return false;
}

function onSetState_IceCrash(obj, state, datas, isResetTimer)
{
    if(!obj) return;
    
    local level = sq_GetSkillLevel(obj, SKILL_ICE_CRASH);
    local spinDistance = sq_GetIntData(obj, SKILL_ICE_CRASH, 0, level);
    local spinSpeed = sq_GetIntData(obj, SKILL_ICE_CRASH, 1, level);
    local spinTime = (spinDistance.tofloat()/spinSpeed.tofloat()) * 1000.0;
}
```
