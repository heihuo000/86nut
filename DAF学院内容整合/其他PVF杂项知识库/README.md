### 3. APD效果系统详解

#### APD文件类型
APD (Appendage) 文件是一种宏或模块，可以改变状态、武器颜色等：

```
[type]
`skill data up`

[duration]
10000

[buff]
0

[icon image]
`` 0

[max overlap]
1

[string data]
`[swordman]` `174` `[all]` `[level]` `0` `%` `300`
[/string data]
```

#### APD类型详解
1. **技能静态数据改变**
   - 类型: `skill data up`
   - 格式: `[职业] [技能ID] [场景] [属性] [数值] [运算符] [倍数]`

2. **状态改变**
   - 类型: `change status`
   - 修改角色状态参数
