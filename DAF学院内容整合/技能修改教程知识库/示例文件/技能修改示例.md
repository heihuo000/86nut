## 🛠️ 基础技能修改示例

### 示例1: 简单技能数值调整

```
// 技能基础属性修改示例
[basemagicid] 1000001
[level] 1
[attackpower] 150
[splevel] 1
[skillclass] 0
[fitnessclass] 0
[maximumlevel] 20
[needweapon] 0x00000000

// 技能学习条件
[skill fitness growtype] 1 0 0 0 0
[growtype maximum level] 20 20 0 0 0 0
```

#### 功能拆解
- `[attackpower]` - 调整技能攻击力
- `[maximumlevel]` - 设置技能最高等级
- `[skill fitness growtype]` - 定义职业适配性

#### 扩展指导
- 增加更多数值参数来调整技能效果
- 添加特殊效果参数实现高级功能

## 👥 职业适配修改示例

### 示例3: 多职业技能适配

```
// 允许多个职业学习同一技能
[skillclass] 2
[fitnessclass] 1
[maximumlevel] 15

// 定义各职业可学习最高等级
[growtype maximum level] 15 15 10 15 15 0

// 设置哪些职业可以学习
[skill fitness growtype] 1 1 1 1 1
```

#### 功能拆解
- `growtype maximum level` - 为不同职业设置不同最高等级
- `skill fitness growtype` - 控制职业适配性

---

### 示例4: 限制特定职业技能

```
// 限制只有特定职业可学习的技能
[skillclass] 5
[fitnessclass] 2
[maximumlevel] 20

// 只允许鬼泣学习
[growtype maximum level] 0 0 20 0 0 0
[skill fitness growtype] 0 0 1 0 0
```

## 🚀 性能优化技巧

### 1. 参数精简
- 移除不必要的参数配置
- 使用默认值代替重复定义
- 压缩参数空间以提高加载速度

### 2. 逻辑优化
- 合理安排参数顺序
- 优化数值计算逻辑
- 减少跨文件引用

### 3. 测试验证
- 在独立环境中测试修改
- 逐步增加参数复杂度
- 监控系统性能变化
