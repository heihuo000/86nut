# DNF任务修改知识库

## 📚 简介

本知识库整理了DAF学院关于DNF任务修改的教程和资料，涵盖从基础的任务条件调整到高级的任务类型、奖励、触发条件等内容。通过本知识库，您可以深入了解DNF任务系统的内部机制和修改方法。

## 🎯 核心功能

根据DAF学院的教程，DNF任务修改主要包含以下几个方面：

1. **任务条件修改** - 调整任务完成条件，如杀怪数量、物品收集等
2. **任务类型修改** - 修改任务类型，如杀怪任务、收集任务、对话任务等
3. **任务奖励修改** - 调整任务完成后的奖励内容
4. **任务触发条件** - 修改任务接受和完成的触发条件
5. **批量任务修改** - 使用工具进行大量任务的批量修改

## 🏗️ 任务文件结构

### 核心文件类型
- `*.qst` - 任务配置文件
- `quest.lst` - 任务列表文件
- `*.str` - 任务名称和描述文件

## 🔧 修改技巧与方法

### 1. 任务文件基础结构

#### 任务基础属性
```
[grade] * 
`[normaly repeat]`  // 任务类型：每日[daily] 或 重复[normaly repeat]

[npc index]
336  // 接受任务的NPC编号

[job]
`[all]`  // 适用职业

[grow type]
-1  // 成长型（未知）

[level]
85 99    // 显示任务的等级范围

[quest point]
0        // 奖励QP点数
```

### 2. 任务类型详解

#### 任务类型标签
```
[type]   // 任务类型
`[hunt monster]`        // 杀怪类型
`[seeking]`             // 物品收集类型
`[condition under clear]` // 通关类型
`[meet npc]`            // 与NPC对话类型
```

#### 子类型说明
```
[sub type]
-1  // 默认附加类型
5   // 组队附加类型
```

### 3. 任务条件设置

#### 杀怪任务条件
```
[int data]
怪物ID 数量  // 例如：313 2 表示击杀313号怪物2只
```

#### 物品收集任务条件
```
[int data]
物品ID 数量  // 例如：1000001 5 表示收集5个指定物品
```

### 4. 任务奖励系统

#### 任务奖励标签
```
[clear reward item]
1 0 1002 3 -1     // 副本索引，副本难度，道具索引，最大道具数，登场概率（%）
2 0 1003 2 100 30 // 副本难度-1表示所有难度，0:普通 1:冒险 2:王者 3:地狱
[/clear reward item]
```

#### 怪物奖励标签
```
[monster reward item]
50 1 0 10001 2 30 3  // 怪物ID，地图ID，未知，道具ID，数量，概率，最大值
51 2 0 10002 3 30 6
[/monster reward item]
```

### 5. 任务PVP等级要求

#### PVP等级限制
```
[PVP RANK]
0  // 接受任务的最低PVP等级
```

PVP等级对应表：
- 0-9级: 10级、9级、8级、7级、6级、5级、4级、3级、2级、1级
- 10-19段: 1段至10段
- 20-29至尊: 至尊1至至尊10
- 30-34: 达人、名人、小霸王、霸王、斗神

### 6. 特殊任务类型

#### 活动任务
```
[event]
1  // 标记为活动任务
```

### 7. 批量任务修改

#### 批量修改方法
使用PVFtool 1.6和Notepad++进行批量修改：

1. **查找模式**: 正则表达式
2. **查找目标**: `\\[type\\]\\r\\n.*\\r\\n\\[/int data\\]`
3. **替换内容**: 
```
\\[type\\]\\r\\n(`\\[meet npc\\]`\\r\\n\\r\\n\\[sub type\\]\\r\\n-1\\r\\n\\[int data\\]\\r\\n2\\r\\n)\\[/int data\\]
```

## 📋 任务类型详解

### 通关类任务写法
- 通关副本类任务
- 需要完成特定副本

### 杀怪类任务写法
- 需要击杀指定数量的怪物
- 配置怪物ID和数量

### 收集类任务写法
- 需要收集指定物品
- 配置物品ID和数量

### 对话类任务写法
- 需要与NPC对话完成
- 配置NPC相关的参数

### 定时任务写法
- 具有时间限制的任务
- 配置时间相关参数

## ⚠️ 注意事项

1. **数值验证** - 确保所有ID值在有效范围内
2. **文件备份** - 修改前备份原始文件
3. **测试验证** - 修改后进行充分测试
4. **格式检查** - 确保所有标签格式正确
5. **依赖关系** - 注意任务间的依赖关系
