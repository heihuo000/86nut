# DNF任务修改核心标签参考

## 🏷️ 任务基础属性标签

### 任务类型标签
- **[grade]** 
  - 功能作用: 定义任务的重复类型
  - 参数详解: 
    - 类型: 字符串型
    - 作用: 设置任务是每日任务还是可重复任务
    - 取值: `[daily]` (每日任务), `[normaly repeat]` (可重复任务)
    - 默认值: 根据任务类型确定
  - 实际应用: 控制任务接取频率
  - 依赖关系: 与任务系统关联

- **[type]** 
  - 功能作用: 定义任务的主要类型
  - 参数详解:
    - 类型: 字符串型
    - 作用: 设置任务的基本类型
    - 取值: `[hunt monster]` (杀怪), `[seeking]` (收集), `[condition under clear]` (通关), `[meet npc]` (对话)
    - 默认值: 根据任务内容确定
  - 实际应用: 确定任务完成条件类型
  - 依赖关系: 与条件检测系统关联

### 任务条件标签
- **[sub type]**
  - 功能作用: 定义任务的附加类型
  - 参数详解:
    - 类型: 数值型
    - 作用: 设置任务的附加特性
    - 取值: -1 (默认), 5 (组队)
    - 默认值: -1
  - 实际应用: 控制任务执行方式
  - 依赖关系: 与组队系统关联

- **[int data]**
  - 功能作用: 定义任务的具体条件数据
  - 参数详解:
    - 类型: 复合数值型
    - 作用: 包含任务完成所需的ID和数量
    - 格式: 
      - 杀怪任务: `[怪物ID] [数量]`
      - 收集任务: `[物品ID] [数量]`
      - 通关任务: `[地图ID] [难度]`
    - 示例: `313 2` (击杀313号怪物2只)
  - 实际应用: 设定任务完成条件
  - 依赖关系: 与怪物/物品系统关联

### 任务触发标签
- **[npc index]**
  - 功能作用: 定义任务的NPC索引
  - 参数详解:
    - 类型: 数值型
    - 作用: 指定任务相关的NPC编号
    - 取值范围: 根据NPC列表确定
    - 默认值: 根据任务流程确定
  - 实际应用: 控制任务接取和提交NPC
  - 依赖关系: 与NPC系统关联

- **[job]**
  - 功能作用: 定义任务适用的职业
  - 参数详解:
    - 类型: 字符串型
    - 作用: 限制任务可接取的职业
    - 取值: `[all]` (所有职业) 或具体职业代码
    - 默认值: `[all]`
  - 实际应用: 控制任务接取权限
  - 依赖关系: 与职业系统关联

## 🏷️ 任务限制标签

### 等级限制标签
- **[level]**
  - 功能作用: 定义任务的等级范围
  - 参数详解:
    - 类型: 数值型（双参数）
    - 作用: 设置任务显示的最低和最高等级
    - 格式: `[最低等级] [最高等级]`
    - 示例: `85 99` (85-99级可见)
  - 实际应用: 控制任务接取等级范围
  - 依赖关系: 与角色等级系统关联

- **[grow type]**
  - 功能作用: 定义成长类型
  - 参数详解:
    - 类型: 数值型
    - 作用: 设置任务成长相关参数
    - 取值: 通常为-1
    - 默认值: -1
  - 实际应用: 与角色成长系统关联
  - 依赖关系: 与角色系统关联

### PVP限制标签
- **[PVP RANK]**
  - 功能作用: 定义PVP等级要求
  - 参数详解:
    - 类型: 数值型
    - 作用: 设置接受任务的最低PVP等级
    - 取值: 0-34 (对应不同PVP等级)
    - 对应关系:
      - 0-9: 10级至1级
      - 10-19: 1段至10段
      - 20-29: 至尊1至至尊10
      - 30-34: 达人、名人、小霸王、霸王、斗神
  - 实际应用: 控制PVP相关任务权限
  - 依赖关系: 与PVP系统关联

## 🏷️ 任务奖励标签

### 奖励相关标签
- **[quest point]**
  - 功能作用: 定义任务奖励的QP点数
  - 参数详解:
    - 类型: 数值型
    - 作用: 设置任务完成奖励的QP数量
    - 取值范围: 通常为0-100
    - 默认值: 0
  - 实际应用: 给予任务完成奖励
  - 依赖关系: 与QP系统关联

- **[clear reward item]**
  - 功能作用: 定义任务完成奖励物品
  - 参数详解:
    - 类型: 复合数值型
    - 作用: 设置副本通关奖励道具
    - 格式: `[副本索引] [副本难度] [道具索引] [最大道具数] [登场概率] [最大所有值]`
    - 示例: `1 0 1002 3 -1` (普通难度副本1，奖励1002号道具，最多3个，100%概率)
    - 难度对应: -1(所有难度), 0(普通), 1(冒险), 2(王者), 3(地狱)
  - 实际应用: 设置通关奖励
  - 依赖关系: 与物品和奖励系统关联

- **[monster reward item]**
  - 功能作用: 定义击杀怪物的奖励物品
  - 参数详解:
    - 类型: 复合数值型
    - 作用: 设置击杀特定怪物的奖励
    - 格式: `[怪物ID] [地图ID] [预留] [道具ID] [数量] [概率] [最大值]`
    - 示例: `50 1 0 10001 2 30 3` (击杀50号怪，奖励10001号道具2个，30%概率，最多3个)
  - 实际应用: 设置击杀奖励
  - 依赖关系: 与怪物和奖励系统关联

## 🏷️ 特殊功能标签

### 活动任务标签
- **[event]**
  - 功能作用: 标记为活动任务
  - 参数详解:
    - 类型: 数值型
    - 作用: 将任务标记为特殊活动任务
    - 取值: 1 (是活动任务)
    - 默认值: 无此标签表示普通任务
  - 实际应用: 区分普通任务和活动任务
  - 依赖关系: 与活动系统关联

### 条件相关标签
- **[hunt monster]** - 杀怪条件
- **[seeking]** - 收集条件
- **[condition under clear]** - 通关条件
- **[meet npc]** - 对话条件

## 📊 任务配置模板

### 完整任务配置示例
```
[grade] * 
`[normaly repeat]`

[npc index]
336

[job]
`[all]`

[grow type]
-1

[level]
85 99

[quest point]
10

[type]
`[hunt monster]`

[sub type]
-1

[int data]
313 5  // 击杀313号怪物5只

[clear reward item]
1 0 2000001 1 100 -1
[/clear reward item]
```

### 收集任务配置示例
```
[grade] * 
`[daily]`

[npc index]
402

[job]
`[all]`

[level]
1 10

[type]
`[seeking]`

[int data]
1000001 10  // 收集1000001号物品10个
```

### 对话任务配置示例
```
[grade] * 
`[normaly repeat]`

[npc index]
205

[job]
`[all]`

[level]
50 100

[type]
`[meet npc]`

[sub type]
-1

[int data]
2  // 与NPC对话完成
```

## ⚠️ 使用建议

1. **参数验证**: 确保所有ID值在有效范围内
2. **格式规范**: 保持正确的标签格式和参数结构
3. **数值平衡**: 合理设置任务难度和奖励
4. **测试验证**: 修改后进行全面功能测试
