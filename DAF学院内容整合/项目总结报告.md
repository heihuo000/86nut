## 🏗️ 知识库架构

### 统一结构设计
每个知识库都遵循相同的目录结构：
```
[知识库名称]知识库/
├── README.md                 # 主文档
├── 依赖文件简介.md           # 文件依赖关系
├── 标签参考.md               # 核心标签详解
├── 问题解答.md               # 常见问题解决
└── 示例文件/
    └── [类型]修改示例.md     # 实际示例模板
```

### 内容组织原则
1. **系统性** - 从基础概念到高级应用
2. **实用性** - 提供可直接使用的示例和模板
3. **完整性** - 覆盖所有关键知识点
4. **易用性** - 清晰的结构和导航
