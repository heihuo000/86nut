# DNF物品修改知识库

## 📚 简介

本知识库整理了DAF学院关于DNF物品修改的教程和资料，涵盖从基础的物品属性调整到高级的礼包系统、魔盒系统、消耗品限制修改等内容。通过本知识库，您可以深入了解DNF物品系统的内部机制和修改方法。

## 🎯 核心功能

根据DAF学院的教程，DNF物品修改主要包含以下几个方面：

1. **物品基础属性修改** - 调整物品的名称、说明、等级、稀有度等
2. **物品绑定类型修改** - 修改物品的交易限制（账号绑定、不可交易等）
3. **礼包系统修改** - 创建和管理礼包内容
4. **魔盒系统** - 修改魔盒的随机内容和概率
5. **消耗品限制修改** - 解除消耗品的使用限制
6. **物品堆叠数量修改** - 调整物品的堆叠上限

## 🏗️ 物品文件结构

### 核心文件类型
- `*.stk` - 消耗品/材料物品参数文件
- `stackable.lst` - 物品列表文件
- `*.str` - 物品名称显示文件
- `*.etc` - 配置文件

### 物品类别
- **消耗品** - 药水、卷轴等一次性使用物品
- **材料** - 制作、升级所需的材料
- **礼包** - 包含多个物品的容器
- **魔盒** - 随机获得物品的系统
- **任务物品** - 用于任务的特殊物品

## 🔧 修改技巧与方法

### 1. 物品基础属性修改

#### 物品基础配置
```
[name]
`物品名称`

[explain]
`物品说明文字，显示在物品描述中`

[grade]
99  // 物品等级

[rarity]
2   // 稀有度（影响颜色显示）

[minimum level]
1   // 最低使用等级

[usable job]
`[all]`  // 适用职业
[/usable job]

[attach type]
`[account]`  // 绑定类型（account=账号绑定）

[icon]
`Item/stackable/material_cn.img` 18  // 图标路径和索引

[stackable type]
`[material]` 0  // 可堆叠类型和参数

[move wav]
`BONE_TOUCH`  // 移动声音效果
```

#### 绑定类型说明
- `[free]` - 自由交易
- `[account]` - 账号绑定
- `[trade]` - 交易受限
- `[none]` - 不可交易

### 2. 礼包添加教程

#### 添加礼包的步骤
1. 找到要修改的礼包文件
2. 解压礼包文件
3. 用文本编辑器打开解压的文件
4. 添加礼包内容代码
5. 格式：使用Tab键分隔参数
6. 修改文件名和代码
7. 更新对应的lst和str文件
8. 重新打包文件

#### 礼包内容格式
```
[item function]
[random select]
// 礼包内容配置
[/random select]
```

### 3. 魔盒系统详解

#### 魔盒配置文件
台服可用魔盒代码：
- `stackable/event/atmage/randomcerabox_event3.stk`
- `stackable/cash/randomcerabox_1.stk`
- `stackable/cash/randomcerabox_2.stk`
- `stackable/cash/randomcerabox_event1.stk`
- `stackable/cash/randomcerabox_event2.stk`

#### 魔盒类型
```
[stackable type]
`[multi upgradable legacy]` 0
```

#### 随机内容配置
```
[random]
[default list]
1 1085 10 0 1085  // 参数格式说明
// 更多随机内容
[/default list]
[/random]
```

### 4. 消耗品无限制使用

#### 解除使用限制
通过修改物品中的冷却时间或使用次数限制实现无限制使用。

### 5. CD药修改

#### 全技能无CD实现
修改冷却药水的参数，使效果持续时间更长或永久生效。

### 6. 物品堆叠数量修改

#### 调整堆叠上限
修改物品的堆叠类型和数量限制参数。

## 📋 核心标签详解

### 基础属性标签
- `[name]` - 物品名称
- `[explain]` - 物品说明
- `[grade]` - 物品等级
- `[rarity]` - 稀有度
- `[minimum level]` - 最低使用等级
- `[usable job]` - 适用职业
- `[attach type]` - 绑定类型
- `[icon]` - 图标路径
- `[stackable type]` - 堆叠类型
- `[move wav]` - 移动音效

### 特殊功能标签
- `[item function]` - 物品功能定义
- `[random select]` - 随机选择功能
- `[random]` - 随机系统
- `[default list]` - 默认列表
- `[cooltime]` - 冷却时间
- `[use limit]` - 使用限制

### 背包扩展相关
- `[max count]` - 最大堆叠数量
- `[storage max count]` - 仓库最大数量

## ⚠️ 注意事项

1. **ID唯一性** - 确保物品ID唯一，避免冲突
2. **文件备份** - 修改前备份原始文件
3. **测试验证** - 修改后进行充分测试
4. **格式检查** - 确保所有标签格式正确
5. **列表更新** - 修改物品后更新相应的.lst文件
