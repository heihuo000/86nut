## 🎁 礼包系统配置示例

### 示例5: 初级礼包

```
[name]
`新春豪华礼包`

[explain]
`打开后随机获得以下物品之一`

[grade]
4

[rarity]
4

[minimum level]
1

[usable job]
`[all]`
[/usable job]

[attach type]
`[trade]`

[icon]
`Item/stackable/event/luxury_gift.img` 3

[stackable type]
`[gift box]` 0

[item function]
[random select]
// 礼包内容配置（格式：概率 Tab 物品ID Tab 数量）
1	`2000001`	10	// 红药水
2	`2000002`	8	// 蓝药水
5	`3000001`	1	// 卷轴
1	`4000001`	1	// 称号
10	`5000001`	50	// 金币
[/random select]
[/item function]

[max count]
1

[cooltime]
0

[move wav]
`GIFT_TOUCH`
```

#### 功能拆解
- 随机获得物品的礼包
- 不同物品有不同概率
- 仅可使用一次
- Tab分隔参数格式

## 🧩 配置最佳实践

### 物品平衡原则
1. 稀有度与功能匹配
2. 价格与价值平衡
3. 遵活性与专业性平衡

### 用户体验优化
1. 清晰的物品说明
2. 合理的使用限制
3. 明确的概率显示

### 系统性能考虑
1. 控制随机系统复杂度
2. 优化礼包内容数量
3. 合理设置堆叠限制

### 安全性考虑
1. 验证所有ID的有效性
2. 防止功能过强导致失衡
3. 合理设置使用权限
