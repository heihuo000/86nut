## 🛒 基础商店物品添加示例

### 示例1: 赛利亚商店物品添加

```
[sell item]
[@02]-1
[@02]1100001
[@02]1100002
[@02]1100003
[@02]2000001
[@02]2000002
[@02]2000003
[/sell item]
```

#### 功能拆解
- `[@02]-1` - 原有商品占位符
- `[@02]1100001` - 新增装备商品代码
- `[@02]2000001` - 新增消耗品商品代码
- 按类别组织商品列表

#### 扩展指导
- 可以继续添加更多商品代码
- 按功能分类组织商品

## 💰 高级商城配置示例

### 示例3: 商城普通商品配置

```
[item]
8001 1100001 50000 0 0 <13::name_1100001`强化+11神器上衣`>
[not stackable buy]
[cerapoint disallowance]

8002 1200001 100000 0 0 <13::name_1200001`增幅+10史诗武器`>
[gift disallowance]

8003 2000001 5000 0 0 <13::name_2000001`红药水(100个)`>
[max gift count] 3
```

#### 功能拆解
- 商品编码、物品代码、价格配置
- `[not stackable buy]` - 不可叠加购买
- `[cerapoint disallowance]` - 代币券不可购买
- `[gift disallowance]` - 不可赠送
- `[max gift count] 3` - 最大赠送次数为3次

---

## 📄 商店分页管理示例

### 示例6: 分页商店配置

```
[sell item]
// 第一页 - 武器装备
[@02]1200001
[@02]1200002
[@02]1200003
[@02]1200004
[@02]1200005
[@02]-2  // 分页标记
// 第二页 - 防具装备
[@02]1100001
[@02]1100002
[@02]1100003
[@02]1100004
[@02]1100005
[@02]-2  // 分页标记
// 第三页 - 消耗品
[@02]2000001
[@02]2000002
[@02]2000003
[@02]2000004
[@02]2000005
[/sell item]

// 分页名称配置（需要添加在文件末尾）
[@05][page name]
[@02]1 <3::page_1`武器装备`>
[@02]2 <3::page_2`防具装备`>
[@02]3 <3::page_3`消耗品`>
[@05][/page name]
```

#### 功能拆解
- 使用[@02]-2进行分页
- 按类别组织不同页面
- 为每页设置名称

## 🔒 购买限制设置示例

### 示例8: 账号唯一购买商品

```
[item]
9001 2500001 1000000 0 0 <13::name_2500001`账号唯一称号`>
[not stackable buy]

[item additional function]
[@05][function]
[@05][account unique item]
[@02]2500001
[@05][/account unique item]
[@05][/function]
```

#### 功能拆解
- 设置为不可叠加购买
- 添加账号唯一限制
- 确保每个账号只能购买一次

## 🧩 配置最佳实践

### 商品组织原则
1. 按功能或类型分类商品
2. 合理设置商品价格梯度
3. 适当设置购买限制

### 用户体验优化
1. 清晰的分页和分类
2. 合理的价格设置
3. 适当的购买限制

### 安全性考虑
1. 设置必要的购买限制
2. 防止恶意购买行为
3. 监控异常购买模式

### 性能优化建议
1. 控制商店商品数量
2. 合理组织商品列表
3. 优化文件结构
