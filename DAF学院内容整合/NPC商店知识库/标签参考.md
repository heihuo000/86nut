# DNF NPC商店修改核心标签参考

## 🏷️ 商店商品标签

### 基础商品标签
- **[sell item]** 
  - 功能作用: 定义NPC商店中的出售商品列表
  - 参数详解: 
    - 类型: 复合型
    - 作用: 包含所有可购买的商品代码
    - 结构: 使用[@02]格式的物品代码
    - 示例: `[@02]1100001` (装备代码), `[@02]2000001` (消耗品代码)
  - 实际应用: 控制商店中显示的商品
  - 依赖关系: 与物品系统中的商品代码关联

### 商品分类标签
- **[buy item]**
  - 功能作用: 定义NPC回收的物品列表
  - 参数详解:
    - 类型: 复合型
    - 作用: 设置NPC可回收的物品
    - 结构: 使用[@02]格式的物品代码
    - 默认值: 根据NPC功能确定
  - 实际应用: 控制NPC的回收功能
  - 依赖关系: 与物品系统关联

### 分页控制标签
- **[@02]-2**
  - 功能作用: 实现商店分页功能
  - 参数详解:
    - 类型: 特殊控制码
    - 作用: 将商品列表分页显示
    - 取值: 固定为-2
    - 位置: 放置在需要分页的位置
  - 实际应用: 组织商店商品布局
  - 依赖关系: 与界面显示系统关联

### 限制条件标签
- **[cart disallowance]**
  - 功能作用: 设置商品不可重复添加到购物车
  - 参数详解:
    - 类型: 限制标签
    - 作用: 防止商品重复添加
    - 位置: 在商品配置后
    - 默认值: 无此标签表示可重复添加
  - 实际应用: 控制购物车行为
  - 依赖关系: 与购物车系统关联

- **[gift disallowance]**
  - 功能作用: 设置商品不可赠送
  - 参数详解:
    - 类型: 限制标签
    - 作用: 防止商品赠送功能
    - 位置: 在商品配置后
    - 默认值: 无此标签表示可赠送
  - 实际应用: 控制商品赠送权限
  - 依赖关系: 与赠送系统关联

- **[cerapoint disallowance]**
  - 功能作用: 设置代币券禁止购买
  - 参数详解:
    - 类型: 限制标签
    - 作用: 阻止使用代币券购买
    - 位置: 在商品配置后
    - 默认值: 无此标签表示可使用代币券
  - 实际应用: 控制支付方式
  - 依赖关系: 与货币系统关联

- **[gift only]**
  - 功能作用: 设置商品仅可赠送
  - 参数详解:
    - 类型: 限制标签
    - 作用: 只能赠送，不能购买
    - 位置: 在商品配置后
    - 默认值: 无此标签表示可购买
  - 实际应用: 设置赠送专用商品
  - 依赖关系: 与赠送系统关联

- **[not stackable buy]**
  - 功能作用: 设置商品不可叠加购买
  - 参数详解:
    - 类型: 限制标签
    - 作用: 防止购买数量叠加
    - 位置: 在商品配置后
    - 默认值: 无此标签表示可叠加
  - 实际应用: 控制购买数量限制
  - 依赖关系: 与库存系统关联

### 赠送数量标签
- **[max gift count]**
  - 功能作用: 设置商品最大赠送次数
  - 参数详解:

## 🏷️ 价格与货币标签

### 价格设置标签
- **商品价格配置**
  - 格式: `编码 物品代码 所需金币 所需胜点 所需点券 名称注释`
  - 示例: `8000 976 100000 0 0 <13::name_976`大頭禮包A [女魔法師]`>`
  - 各位置含义:
    1. 编码: 商品在商城中的唯一编码
    2. 物品代码: 对应物品系统中的物品ID
    3. 所需金币: 购买此商品需要的金币数量
    4. 所需胜点: 购买此商品需要的胜点数量
    5. 所需点券: 购买此商品需要的点券数量
    6. 名称注释: 商品显示名称

## 📊 商店配置模板

### 基础商店配置示例
```
[sell item]
[@02]-1
[@02]1100001
[@02]2000001
[@02]-2  // 分页标记
[@02]1100002
[@02]2000002
[/sell item]
```

### 商城商品配置示例
```
[item]
8000 976 100000 0 0 <13::name_976`大頭禮包A [女魔法師]`>
[not stackable buy]
[cerapoint disallowance]
```

### 分页商店配置示例
```
[sell item]
[@02]1100001
[@02]1100002
[@02]1100003
[@02]-2  // 分页
[@02]2000001
[@02]2000002
[@02]2000003
[/sell item]
// 需要在文件末尾添加分页名称配置
```
