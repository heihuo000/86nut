## 🏗️ 商店文件结构

### 核心文件类型
- `*.shp` - NPC商店配置文件
- `etc/newcashshop.etc` - 商城主文件
- `etc/newcashshop_restrict.etc` - 商城限制文件
- `*.str` - 字符串显示文件
- `*.lst` - 列表文件

### 常用NPC商店文件路径
- `itemshop-equipmentshop3.shp` - 赛利亚商店
- `itemshop-npc-[名称].shp` - 其他NPC商店
- `itemshop-armor/weapon/accessory/` - 装备分类商店

## 🔧 修改技巧与方法

### 1. 商店物品添加与修改

#### 基础修改方法
1. 使用SuperPVF软件打开PVF文件
2. 找到对应的商店文件（如`itemshop-equipmentshop3.shp`）
3. 在`[sell item]`部分修改物品代码

示例：
```
[@02]-1  // 原有物品代码
[@02]1100001  // 新物品代码（装备）
[@02]2000001  // 新物品代码（消耗品）
```

#### 常用NPC商店代码
- 林纳斯: 1
- 卡坤: 11
- 雷诺: 42
- 歌兰蒂斯: 45
- 沙影贝利特: 57
- 泽丁施奈德: 58

### 2. 商城系统修改详解

#### 商城文件结构
- `etc/newcashshop.etc` - 商城主文件
- `etc/newcashshop_restrict.etc` - 限制补充文件

#### 商城项目类型
- `[coin]` - 复活币类
- `[item]` - 普通商品
- `[premium]` - 限时商品
- `[creature]` - 宠物物品
- `[package]` - 礼包

#### 商品代码格式
```
8000    976     100000    0    0    <13::name_976`大頭禮包A [女魔法師]`>
编码   物品代码  所需金币  所需胜点 所需点券  名称注释
```

#### 限制条件标签
- `[cart disallowance]` - 不可重复添加购物车
- `[gift disallowance]` - 不可赠送
- `[cerapoint disallowance]` - 代币券禁止购买
- `[gift only]` - 仅可赠送
- `[max gift count]` - 最大赠送次数
- `[not stackable buy]` - 不可叠加购买

### 3. 商店分页管理

#### 分页设置
- 使用 `[@02]-2` 代码实现分页
- 分页后需要为每页设置名称
- 在 `[/sell item]` 后添加分页名称代码

## 📋 核心标签详解

### 商店相关标签
- `[sell item]` - 出售物品列表
  - 包含所有可购买的物品代码
  - 支持分页和分类

- `[buy item]` - 回收物品列表
  - 定义NPC可回收的物品

### 商城相关标签
- `[coin]` - 复活币类别
- `[item]` - 普通商品类别
- `[premium]` - 限时商品类别
- `[creature]` - 宠物类别
- `[package]` - 礼包类别

### 限制相关标签
- `[cart disallowance]` - 购物车限制
- `[gift disallowance]` - 赠送限制
- `[cerapoint disallowance]` - 代币券限制
- `[not stackable buy]` - 叠加购买限制
