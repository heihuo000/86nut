# DNF地图城镇修改核心标签参考

## 🏷️ 城镇文件标签

### 城镇基础信息标签
- **[name]** 
  - 功能作用: 定义城镇/地图的显示名称
  - 参数详解: 
    - 类型: 字符串型
    - 作用: 设置城镇在游戏中的显示名称
    - 格式: `Type:9 Str:14 'name_编号>中文名称'`
    - 示例: `Type:9 Str:14 'name_18210>史拉烏工業區'`
  - 实际应用: 控制城镇名称显示
  - 依赖关系: 与字符串系统关联

- **[limit level]**
  - 功能作用: 定义访问城镇的等级限制
  - 参数详解:
    - 类型: 数值型
    - 作用: 设置角色到达该城镇的最低等级
    - 取值范围: 通常为1-100
    - 示例: `78` (需要78级才能进入)
  - 实际应用: 控制城镇访问权限
  - 依赖关系: 与角色等级系统关联

### 城镇内容标签
- **[area]**
  - 功能作用: 定义城镇内的地图区域
  - 参数详解:
    - 类型: 复合型
    - 作用: 包含地图路径和类型信息
    - 格式: `[序号] [地图路径] [类型] [参数]`
    - 示例: `0 'Slough/Slough_down_street.map' '[normal]'`
    - 类型选项:
      - `[normal]` - 普通地图
      - `[dungeon gate]` - 连接到选图界面
      - `[gate]` - 传送门类型
  - 实际应用: 管理城镇内多个地图区域
  - 依赖关系: 与地图系统关联

- **[entering title]**
  - 功能作用: 定义进入城镇时的标题动画
  - 参数详解:
    - 类型: 字符串型
    - 作用: 设置进入城镇时播放的标题动画
    - 格式: `'路径/文件名.ani'`
    - 示例: `'Title/Slough.ani'`
  - 实际应用: 增强城镇进入体验
  - 依赖关系: 与动画系统关联

- **[cutscene image]**
  - 功能作用: 定义城镇的过场动画图片
  - 参数详解:
    - 类型: 复合型
    - 作用: 设置城镇的背景图片或过场图
    - 格式: `'路径/文件名.img' [序号]`
    - 示例: `'Map/CutScene/Slough.img' 0`
  - 实际应用: 设置城镇视觉效果
  - 依赖关系: 与图像系统关联

### 访问限制标签
- **[dungeon what must be cleared]**
  - 功能作用: 定义访问城镇的前置副本要求
  - 参数详解:
    - 类型: 数值型
    - 作用: 设置进入城镇前需要完成的副本
    - 取值: -1表示无前置要求，其他数值对应副本ID
    - 示例: `-1` (无前置副本要求)
  - 实际应用: 控制剧情和访问顺序
  - 依赖关系: 与副本系统关联

## 🏷️ 地图相关标签

### 地图区域标签
- **[map area]**
  - 功能作用: 定义地图的具体区域
  - 参数详解:
    - 类型: 复合型
    - 作用: 设置地图内的具体功能区域
    - 包含坐标、功能等信息
    - 依赖关系: 与地图系统关联

### NPC相关标签
- **[npc]**
  - 功能作用: 定义地图中的NPC
  - 参数详解:
    - 类型: 复合型
    - 作用: 设置NPC的位置、类型等信息
    - 格式: 包含NPC编号、坐标、对话等
    - 依赖关系: 与NPC系统关联

## 🏷️ 副本接口标签

### 副本配置标签
- **[dungeon level requirement]**
  - 功能作用: 定义副本的等级要求
  - 参数详解:
    - 类型: 数值型
    - 作用: 设置进入副本的最低等级
    - 取值范围: 根据副本难度确定
    - 依赖关系: 与角色等级系统关联

- **[dungeon prerequisite]**
  - 功能作用: 定义副本的前置条件
  - 参数详解:
    - 类型: 数值型
    - 作用: 设置完成副本前需要满足的条件
    - 取值: 任务ID或副本ID
    - 依赖关系: 与任务和副本系统关联

## 🏷️ 区域管理标签

### 区域配置标签
- **[town list]**
  - 功能作用: 定义区域内的城镇列表
  - 参数详解:
    - 类型: 数值列表型
    - 作用: 包含该区域内可访问的城镇ID
    - 格式: 列出多个城镇ID
    - 依赖关系: 与城镇系统关联

## 🏷️ 选图界面标签

### 界面配置标签
- **[dungeon gate list]**
  - 功能作用: 定义选图界面中的副本入口
  - 参数详解:
    - 类型: 复合型
    - 作用: 设置副本入口显示和功能
    - 包含副本ID、显示位置、前置条件等
    - 依赖关系: 与UI和副本系统关联

## 📊 城镇配置模板

### 完整城镇配置示例
```
[entering title]
'Title/Slough.ani'

[cutscene image]
'Map/CutScene/Slough.img' 0

[dungeon what must be cleared]
-1

[area]
0 'Slough/Slough_down_street.map' '[normal]'
[/area]

[area]
1 'Slough/Slough_up_street.map' '[normal]'
[/area]

[area]
2 'Slough/Slough_powerstation.map' '[dungeon gate]' 19
[/area]

[area]
3 'Slough/Gate_Slough.map' '[gate]' 474 234
[/area]

[name]
Type:9 Str:14 'name_18210>史拉烏工業區'

[limit level]
78
```

```
[name]

[limit level]
50

[dungeon what must be cleared]
-1

[/area]

[entering title]

[cutscene image]
'Map/CutScene/NewTown.img' 0
```

## ⚠️ 使用建议

1. **ID一致性**: 确保所有ID在对应列表文件中存在
2. **格式规范**: 保持正确的标签格式和参数结构
3. **路径正确**: 确保所有文件路径正确存在
4. **测试验证**: 修改后进行全面功能测试
