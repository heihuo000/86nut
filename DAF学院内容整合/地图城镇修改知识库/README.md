# DNF地图城镇修改知识库

## 📚 简介

本知识库整理了DAF学院关于DNF地图城镇修改的教程和资料，涵盖从基础的地图结构理解到高级的城镇添加、副本区域提取等内容。通过本知识库，您可以深入了解DNF地图系统的内部机制和修改方法。

## 🎯 核心功能

根据DAF学院的教程，DNF地图城镇修改主要包含以下几个方面：

1. **地图结构理解** - 掌握地图文件夹结构和关联关系
2. **城镇添加** - 新增城镇和城镇地图
3. **副本区域提取** - 从现有地图提取副本区域
4. **选图界面修改** - 调整副本入口选图界面
5. **地图依赖管理** - 管理地图间的依赖关系

## 🏗️ 地图文件结构

### 核心文件夹说明
- **region** - 大区文件夹，管理整个区域
- **town** - 城镇文件夹，管理城镇地图
- **worldmap** - 选图界面文件夹，管理副本入口界面
- **dungeon** - 副本接口文件夹，管理副本连接
- **map** - 地图文件夹，包含所有地图房间
- **npc** - NPC文件夹，管理地图中的NPC
- **n_quest** - 任务系统文件夹

### 文件类型
- `*.twn` - 城镇文件
- `*.map` - 地图文件
- `*.lst` - 列表文件
- `*.dgn` - 副本文件
- `*.reg` - 区域文件

## 🔧 修改技巧与方法

### 1. 开启城镇的完整步骤

要成功开启一个新城镇或地图，需要按顺序完成以下步骤：

#### A. 副本接口等级要求检查
- 修改dungeon副本接口文件的等级要求
- 确保等级要求适合玩家

#### B. 地图房间ID验证
- 确保map副本房间ID在map.lst中存在
- 在map/map.lst中添加各个map副本房间的ID和路径

#### C. 选图界面配置
- 修改worldmap选图界面文件的dungeon副本接口ID
- 设置前置任务要求

#### D. 副本接口ID验证
- 确保dungeon副本接口ID在dungeon.lst中存在
- 在dungeon/dungeon.lst中添加各个dungeon副本接口的ID和路径

#### E. UI界面控件验证
- 确认worldmap/UI的UI文件是否包含相应控件内容

#### F. 城镇等级要求调整
- 修改town城镇文件的等级要求

#### G. 城镇地图ID验证
- 确保map城镇地图ID在map.lst中存在
- 在map/map.lst中添加各个map城镇地图的ID和路径

#### H. 选图界面ID验证
- 确认worldmap/worldmap.lst的ID是否齐全

#### I. 大区文件配置
- 修改region大区文件的town城镇ID

#### J. 城镇ID验证
- 确保town城镇ID在town.lst中存在
- 在town/town.lst中添加各个town城镇地图的ID和路径

#### K. 传送方式配置
- 确认传送方式（NPC传送或光圈传送）
- 设置等级需求和任务需求

#### L. 深渊配置
- 修改worldmap选图界面文件的深渊前置任务要求
- 确保深渊boss副本房间ID存在

### 2. Town文件详解

以史拉乌工业区的slough.twn文件为例：

```
[entering title]
'Title/Slough.ani'

[cutscene image]
'Map/CutScene/Slough.img' 0

[dungeon what must be cleared]
-1 （前置副本要求，-1为无要求）

[area]
0 'Slough/Slough_down_street.map' '[normal]' （城镇地图之一）
[/area]

[area]
1 'Slough/Slough_up_street.map' '[normal]' （城镇地图之一）
[/area]

[area]
2 'Slough/Slough_powerstation.map' '[dungeon gate]' 19 （连接到worldmap选图界面的ID19）
[/area]

[area]
3 'Slough/Gate_Slough.map' '[gate]' 474 234 （城镇地图之一）
[/area]

[name]
Type:9 Str:14 'name_18210>史拉烏工業區'

[limit level]
78（城镇等级要求）
```

### 3. 城镇副本区域提取添加教程

#### 第一步：town提取
- 以黑市和灰色坟墓为例
- 需要提取的文件有map、npc、town三个文件
- 确定town的代码然后使用相关工具提取

#### 第二步：map提取
- 提取相关的map文件
- 确保map文件与town文件匹配

#### 第三步：map修改
- 根据需要修改map文件内容
- 调整地图元素、NPC位置等

#### 第四步：lst文件修改
- 修改相关的.lst文件
- 添加新的地图和城镇ID

#### 第五步：UI修改
- 修改选图界面的UI文件
- 添加新地图的入口控件

## 📋 核心标签详解

### Town文件标签
- **[area]** - 定义地图区域
  - 格式: `[序号] [地图路径] [类型] [参数]`
  - 类型: `[normal]`, `[dungeon gate]`, `[gate]`

- **[limit level]** - 定义访问等级限制
  - 数值表示最低等级要求

- **[dungeon what must be cleared]** - 前置副本要求
  - -1表示无前置要求

### Worldmap标签
- 选图界面相关配置
- 管理副本入口和UI显示

### Dungeon标签
- 副本接口相关配置
- 管理副本连接和入口

## ⚠️ 注意事项

1. **依赖关系** - 确保所有文件间的依赖关系正确
2. **文件备份** - 修改前备份原始文件
3. **测试验证** - 修改后进行充分测试
4. **格式检查** - 确保所有文件格式正确
5. **ID连续性** - 确保ID分配连续且不冲突
