# DNF时装修改核心标签参考

## 🏷️ 时装基础属性标签

### 时装描述标签
- **[name]** 
  - 功能作用: 定义时装的主显示名称
  - 参数详解: 
    - 类型: 字符串型
    - 作用: 设置时装在游戏中的主名称
    - 格式: `<3::name_编号``>`
    - 示例: `<3::name_2050009``>`
  - 实际应用: 控制时装名称显示
  - 依赖关系: 与字符串系统关联

- **[name2]**
  - 功能作用: 定义时装的副显示名称
  - 参数详解:
    - 类型: 字符串型
    - 作用: 设置时装的副标题或描述
    - 格式: `<3::name2_编号``>`
    - 示例: `<3::name2_2050009``>`
  - 实际应用: 提供更多时装信息
  - 依赖关系: 与字符串系统关联

- **[explain]**
  - 功能作用: 定义时装的说明描述
  - 参数详解:
    - 类型: 字符串型
    - 作用: 设置时装的详细说明
    - 格式: `<3::basic_explain_编号``>`
    - 示例: `<3::basic_explain_2050009``>`
  - 实际应用: 显示时装详细信息
  - 依赖关系: 与字符串系统关联

### 时装分类标签
- **[grade]**
  - 功能作用: 定义时装的掉落等级
  - 参数详解:
    - 类型: 数值型
    - 作用: 设置时装的稀有等级
    - 取值范围: 通常为1-10
    - 示例: `3`
  - 实际应用: 控制时装稀有度显示
  - 依赖关系: 与装备系统关联

- **[rarity]**
  - 功能作用: 定义时装的稀有度
  - 参数详解:
    - 类型: 数值型
    - 作用: 设置时装的稀有程度
    - 取值范围: 通常为1-5
    - 示例: `2`
  - 实际应用: 控制时装外观效果
  - 依赖关系: 与装备系统关联

- **[part set index]**
  - 功能作用: 定义时装的套装索引
  - 参数详解:
    - 类型: 数值型
    - 作用: 关联时装套装效果
    - 取值: 套装代码（1=上级时装, 2=上级时装, 3=稀有时装等）
    - 示例: `3`
  - 实际应用: 管理套装效果
  - 依赖关系: 与套装系统关联

### 使用限制标签
- **[usable job]**
  - 功能作用: 定义时装的适用职业
  - 参数详解:
    - 类型: 字符串列表型
    - 作用: 限制时装可使用的职业
    - 格式: `[/usable job]`包围多个职业
    - 示例: `[swordman]`, `[demonic swordman]`
  - 实际应用: 设置职业限制
  - 依赖关系: 与职业系统关联

- **[minimum level]**
  - 功能作用: 定义时装的最低使用等级
  - 参数详解:
    - 类型: 数值型
    - 作用: 设置使用时装的最低等级
    - 取值范围: 1-100
    - 示例: `1`
  - 实际应用: 控制时装使用权限
  - 依赖关系: 与等级系统关联

- **[attach type]**
  - 功能作用: 定义时装的交易类型
  - 参数详解:
    - 类型: 字符串型
    - 作用: 设置时装的交易限制
    - 取值: `[free]` (自由交易), `[trade]` (交易受限)
    - 示例: `[free]`
  - 实际应用: 控制时装交易权限
  - 依赖关系: 与交易系统关联

## 🏷️ 时装外观标签

### 图标标签
- **[icon]**
  - 功能作用: 定义时装的图标
  - 参数详解:
    - 类型: 复合型
    - 作用: 设置时装在背包中的显示图标
    - 格式: `路径/文件名.img` [索引]
    - 示例: `item/avatar/common/IconClone.img` 13
  - 实际应用: 时装图标显示
  - 依赖关系: 与图像系统关联

### 装备类型标签
- **[equipment type]**
  - 功能作用: 定义时装的装备类型
  - 参数详解:
    - 类型: 字符串型
    - 作用: 指定时装属于哪个装备槽
    - 取值: `[coat avatar]`, `[face avatar]`, `[aurora avatar]`等
    - 示例: `[coat avatar] 0`
  - 实际应用: 确定时装装备位置
  - 依赖关系: 与装备系统关联

## 🏷️ 时效与价格标签

### 时效价格配置标签
- **[avatar type select]**
  - 功能作用: 定义时装的时效和价格选项
  - 参数详解:
    - 类型: 多参数复合型
    - 作用: 设置不同时效和价格选项
    - 格式: `[时效天数] [未知] [未知] [价格] [徽章槽数]` (多组)
    - 示例: `7 0 0 1500 0 30 0 0 3000 0 0 0 0 6000 0`
    - 参数说明:
      - 第1个: 时效天数（0为永久）
      - 第2-3个: 未知参数
      - 第4个: 价格（D币或D点）
      - 第5个: 徽章插槽数量
  - 实际应用: 管理不同时效选项
  - 依赖关系: 与交易和货币系统关联

## 🏷️ 属性与技能标签

### 属性能力标签
- **[avatar select ability]**
  - 功能作用: 定义时装的属性加成能力
  - 参数详解:
    - 类型: 复合型
    - 作用: 设置时装的属性提升
    - 格式: `属性类型` `运算符` `数值`
    - 示例: 
    ```
    [avatar select ability]
    `[EQUIPMENT_MAGICAL_DEFENSE]` `+` 900
    `[ATTACK_SPEED]` `+` 60
    [/avatar select ability]
    ```
  - 实际应用: 设置时装属性加成
  - 依赖关系: 与属性系统关联

### 技能提升标签
- **[skill levelup]**
  - 功能作用: 定义时装的技能等级提升
  - 参数详解:
    - 类型: 复合型
    - 作用: 提升特定职业的技能等级
    - 格式: `[职业]` [技能ID] [提升等级]
    - 示例: `[at fighter]` 36 1
  - 实际应用: 增强职业技能
  - 依赖关系: 与技能系统关联

## 🏷️ 光环特有标签

### 光环能力标签
- **[aura ability]**
  - 功能作用: 定义光环保有的特殊能力
  - 参数详解:
    - 类型: 复合型
    - 作用: 设置光环的特殊功能
    - 格式: `能力类型` [参数]
    - 取值: 
      - `[party teleport]` 10 (组队传送)
      - `[solo teleport]` 10 (个人传送)
    - 示例: `[party teleport]` 10
  - 实际应用: 设置光环特有能力
  - 依赖关系: 与传送系统关联

### 光环特效标签
- **[aurora graphic effects]**
  - 功能作用: 定义光环的图形特效
  - 参数详解:
    - 类型: 多行复合型
    - 作用: 设置光环的动画效果
    - 格式: `[优先级] [条件] `动画路径``
    - 示例:
    ```
    4 1 `Character/Common/Animation/Aura/aura02_front.ani`
    1 `Character/Common/Animation/Aura/aura02_front_dodge.ani`
    ```
  - 实际应用: 设置光环视觉效果
  - 依赖关系: 与特效系统关联

### 光环界面标签
- **[aura hud icon]**
  - 功能作用: 定义光环的HUD图标
  - 参数详解:
    - 类型: 数值型
    - 作用: 设置光环在界面中的显示图标
    - 取值: 图标索引号
    - 示例: `2`
  - 实际应用: 光环界面显示
  - 依赖关系: 与UI系统关联

### 徽章插槽标签
- **[emblem socket default]**
  - 功能作用: 定义默认的徽章插槽
  - 参数详解:
    - 类型: 字符串列表型
    - 作用: 设置时装的默认徽章孔类型
    - 取值: `[S socket]`, `[C socket]`, `[M socket]`
    - 示例: `[M socket]` `[M socket]`
  - 实际应用: 管理徽章插槽
  - 依赖关系: 与徽章系统关联

## 🏷️ 动画与外观标签

### 动画配置标签
- **[animation job]**
  - 功能作用: 定义时装的职业动画
  - 参数详解:
    - 类型: 字符串型
    - 作用: 设置时装在特定职业下的动画
    - 格式: `[职业名]`
    - 示例: `[swordman]`
  - 实际应用: 控制时装动画表现
  - 依赖关系: 与动画系统关联

- **[variation]**
  - 功能作用: 定义时装的变体
  - 参数详解:
    - 类型: 数值型
    - 作用: 设置时装外观的变体参数
    - 格式: `[编号] [值]`
    - 示例: `102 1`
  - 实际应用: 控制时装外观细节
  - 依赖关系: 与外观系统关联

- **[layer variation]**
  - 功能作用: 定义时装的层级变体
  - 参数详解:
    - 类型: 复合型
    - 作用: 设置时装图层的变体
    - 格式: `[层级编号] `变体名称``
    - 示例: `100 `face_b``
  - 实际应用: 管理时装图层
  - 依赖关系: 与外观系统关联

### 装备脚本标签
- **[equipment ani script]**
  - 功能作用: 定义时装的动画脚本
  - 参数详解:
    - 类型: 字符串型
    - 作用: 设置时装的动画脚本路径
    - 格式: `路径/脚本名.lay`
    - 示例: `equipment/character/swordman.lay`
  - 实际应用: 控制时装动画逻辑
  - 依赖关系: 与动画系统关联

## 🏷️ 特效关联标签

### 特效索引标签
- **[effect part set index]**
  - 功能作用: 定义时装的特效套件索引
  - 参数详解:
    - 类型: 数值型
    - 作用: 关联天空套等特效
    - 取值: 特效代码（1、2等）
    - 示例: `2`
  - 实际应用: 激活时装特效
  - 依赖关系: 与特效系统关联

- **[reference effect part set index]**
  - 功能作用: 定义特效冲突参考
  - 参数详解:
    - 类型: 数值型
    - 作用: 处理特效冲突
    - 取值: 冲突的特效代码
    - 示例: `1`
  - 实际应用: 管理特效冲突
  - 依赖关系: 与特效系统关联

## ⚠️ 使用建议

1. **参数验证**: 确保所有ID值在有效范围内
2. **格式规范**: 保持正确的标签格式和参数结构
3. **数值平衡**: 合理设置属性加成数值
4. **测试验证**: 修改后进行全面功能测试
