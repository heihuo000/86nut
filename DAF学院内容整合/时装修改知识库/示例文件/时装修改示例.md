## 👕 基础时装配置示例

### 示例1: 简单外观时装

```
[name]
<3::name_500001`简易时装`>

[name2]
<3::name2_500001`Simple Fashion`>

[explain]
<3::basic_explain_500001`简单的外观时装，只改变外观不影响属性`>

[grade]
1

[rarity]
1

[part set index]
0

[usable job]
`[all]`
[/usable job]

[attach type]
`[free]`

[minimum level]
1

[icon]
`item/avatar/common/default.img` 0

[equipment type]
`[coat avatar]` 0

[avatar type select]
0 0 0 500 0  // 永久，售价500
[/avatar type select]

[animation job]
`[swordman]`
[variation]
100 1
[layer variation]
100 `coat_a`
[equipment ani script]
`equipment/character/swordman.lay`

[animation job]
`[magician]`
[variation]
100 1
[layer variation]
100 `coat_a`
[equipment ani script]
`equipment/character/magician.lay`

[move wav]
`CLOTH_TOUCH`
```

#### 功能拆解
- 最简单的外观时装
- 适用于所有职业
- 只改变外观，无属性加成
- 永久时效

## 🧩 配置最佳实践

### 时装平衡原则
1. 属性加成与稀有度匹配
2. 价格与时效平衡
3. 遵活性与专业性平衡

### 用户体验优化
1. 清晰的属性说明
2. 合理的徽章插槽
3. 流畅的动画表现

### 系统性能考虑
1. 控制特效复杂度
2. 优化资源文件大小
3. 合理设置动画复杂度

### 安全性考虑
1. 验证所有ID的有效性
2. 防止属性过高导致失衡
3. 合理设置使用限制
