# DNF怪物修改核心标签参考

## 🏷️ 怪物基础属性标签

### 生命与防御标签
- **[HP MAX]** 
  - 功能作用: 定义怪物最大生命值
  - 参数详解: 
    - 类型: 数值型
    - 作用: 设置怪物生命值上限
    - 取值范围: 通常为1-数百万
    - 默认值: 根据怪物等级确定
  - 实际应用: 控制怪物生存能力
  - 依赖关系: 与战斗伤害计算系统关联

- **[EQUIPMENT_PHYSICAL_DEFENSE]**
  - 功能作用: 定义怪物物理防御力
  - 参数详解:
    - 类型: 数值型
    - 作用: 增加怪物物理防御
    - 取值范围: 通常为0-数万
    - 默认值: 根据怪物等级确定
  - 实际应用: 减少物理技能伤害
  - 依赖关系: 与伤害减免系统关联

- **[EQUIPMENT_MAGICAL_DEFENSE]**
  - 功能作用: 定义怪物魔法防御力
  - 参数详解:
    - 类型: 数值型
    - 作用: 增加怪物魔法防御
    - 取值范围: 通常为0-数万
    - 默认值: 根据怪物等级确定
  - 实际应用: 减少魔法技能伤害
  - 依赖关系: 与伤害减免系统关联

### 基础参数标签
- **[level]**
  - 功能作用: 定义怪物等级

    - 类型: 数值型
    - 作用: 控制怪物强度和经验值

    - 作用: 控制怪物发现玩家的距离
    - 取值范围: 通常200-400
    - 默认值: 300
  - 实际应用: 调整怪物警觉性
  - 依赖关系: 与怪物AI系统关联

## 🏷️ AI与行为标签

### AI行为标签
- **[attack delay]**
  - 功能作用: 攻击延迟时间
  - 参数详解:
    - 类型: 数值型
    - 作用: 控制怪物攻击间隔
    - 取值范围: 通常1000-3000
    - 默认值: 1500
  - 实际应用: 调整怪物攻击频率
  - 依赖关系: 与怪物AI系统关联

- **[targeting nearest]**
  - 功能作用: 锁定最近目标
  - 参数详解:
    - 类型: 数值型
    - 作用: 控制目标选择策略
    - 取值范围: 0或1
    - 默认值: 1
  - 实际应用: 调整怪物选敌策略
  - 依赖关系: 与怪物AI系统关联

- **[floating height]**
  - 功能作用: 怪物浮空高度
  - 参数详解:
    - 类型: 数值型
    - 作用: 控制怪物是否浮空及高度
    - 取值范围: 0为地面型，1以上为浮空型
    - 默认值: 0
  - 实际应用: 实现浮空怪物效果
  - 依赖关系: 与物理系统关联

### 怪物分类标签
- **[category]**
  - 功能作用: 定义怪物类别
  - 参数详解:
    - 类型: 字符串型
    - 作用: 分类怪物类型
    - 取值范围: [human], [goblin], [melee combat]等
    - 默认值: 根据怪物类型确定
  - 实际应用: 控制怪物属性类型
  - 依赖关系: 与怪物系统关联

## 🏷️ 显示与特效标签

### 显示标签
- **[name]**
  - 功能作用: 怪物名称
  - 参数详解:
    - 类型: 字符串型
    - 作用: 定义怪物显示名称
    - 格式: `<7::name_9035>`
    - 默认值: 根据怪物类型确定
  - 实际应用: 控制怪物名称显示
  - 依赖关系: 与monster.kor.str文件关联

- **[face image]**
  - 功能作用: 怪物脸部形象
  - 参数详解:
    - 类型: 字符串+数值型
    - 作用: 定义怪物脸部图像
    - 格式: `Monster/MonsterFace.img` 序号
    - 默认值: 根据怪物类型确定
  - 实际应用: 设置怪物脸部显示
  - 依赖关系: 与图像资源关联

- **[die effect]**
  - 功能作用: 怪物死亡特效
  - 参数详解:
    - 类型: 三参数数值型
    - 作用: 控制死亡时的特效效果
    - 格式: 参数1 参数2 参数3
    - 参数说明: 
      - 参数1: 固定为0
      - 参数2: 碎块颜色代码
      - 参数3: 光效类型
  - 实际应用: 自定义死亡特效
  - 依赖关系: 与特效系统关联

## 🏷️ 战斗与技能标签

### 技能相关标签
- **[throw attack]**
  - 功能作用: 投掷攻击技能
  - 参数详解:
    - 类型: 复合型
    - 作用: 定义怪物的投掷攻击
    - 结构: 包含攻击参数、目标对象、伤害等
    - 格式: 
    ```
    [throw attack]
    '[attack index]' 0 '[passive object number]' 8225 
    '[passive object filename]' 'Particle/ThrowStone.ptl' 
    '[passive object index]' 8225 '[power]' 0
    [/throw attack]
    ```
  - 实际应用: 实现怪物投掷攻击
  - 依赖关系: 与技能和特效系统关联

- **[ability table]**
  - 功能作用: 调用能力值表
  - 参数详解:
    - 类型: 数值型
    - 作用: 指定使用哪个参数表
    - 取值: 0-调用monsterbaseparameter.tbl
          1-调用summonmonsterbaseparameter.tbl
          2-调用warroommonsterbaseparameter.tbl
    - 默认值: 0
  - 实际应用: 控制参数表调用
  - 依赖关系: 与参数表系统关联

### 混合能力配置
- **[ability category]**
  - 功能作用: 定义怪物的属性类别
  - 参数详解: 
    - 类型: 复合型
    - 作用: 包含各类属性加成
    - 结构: 包含HP/ATT/DEF等属性
    - 格式: 使用`*`或`+`表示倍率或固定值
  - 实际应用: 给怪物添加各种能力属性
  - 依赖关系: 与战斗属性系统关联

## ⚠️ 使用建议

1. **安全修改**: 基础属性修改时，只修改[ability category]部分，避免修改其他配置
2. **数值平衡**: 确保参数值在合理范围内，避免数值失衡
3. **语法格式**: 保持正确的标签格式和结束标签
4. **测试验证**: 修改后进行全面战斗测试
